--- Description ---
LU-20426 added per-operation latency statistics to LNet. The put_egress, get_rtt and put_ack keys show the latency of each operation type. The "lnetctl set latency_stats" command and the lnet_latency_stats_enabled module parameter control the capture. The Lustre Operations Manual must document the statistics, the command and the parameter.
