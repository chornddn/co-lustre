I was on a Customer upgrade yesterday and we were following the F&P Guide (6.3.8-2026061600) for an online upgrade with an external BoO.  On page 245 Step 4 says to 'Load the updated configuration into EMF' from an EXAScaler server hosting MGS.  This is incorrect...these steps are being run up to this point are being run from the BoO and the edits in previous steps are being done to the exascaler.toml file on the BoO (not the Exascaler cluster).    Step 4 needs to be updated indicating this 'emf config load --sync' command needs to be run from the BoO.
