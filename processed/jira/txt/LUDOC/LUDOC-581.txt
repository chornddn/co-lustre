--- Description ---
LU-19797 changed kkfilnd to use memory pools for its transaction and message buffers. The new module parameters tn_reserve_min and msg_reserve_min set the reserve size of these pools. The Lustre Operations Manual must document the parameters, their defaults and the automatic size.
