--- Description ---
fld_cache_lookup() is a linear scan of the sorted fci_entries_head list under the global fci_lock, called on hot paths such as cross-MDT lock and getattr for every FLD resolution once patch https://review.whamcloud.com/69555 ("LU-20923 mdt: refuse new objects with non-MDT FIDs") is landed.  The cache holds sequence ranges [lsr_start, lsr_end) mapped to a target, so lookup is an interval (range-containing) query.

Replace the sorted linked list with a kernel interval tree (INTERVAL_TREE_DEFINE from , as lustre/obdclass/range_lock.c and lustre/ptlrpc/nodemap_range.c already use) for O(log n) lookup, insert and delete while keeping the merge/split-on-overlap semantics and the LRU shrink list.  A hash table is not suitable because the ranges are variable width (adjacent same-target ranges are merged) so there is no fixed key to hash.
