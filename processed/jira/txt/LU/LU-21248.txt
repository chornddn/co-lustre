--- Description ---
o2iblnd has its own link state handling (kiblnd_handle_link_state_change) and interface alias matching (kiblnd_dev_search), but the sanity-lnet tests for these behaviours (test_214, test_109) only run with tcp NETTYPE.

Soft-RoCE (rdma_rxe) provides an RDMA device on a veth, so o2iblnd can be tested on a tcp node without RDMA hardware.

Add o2ib counterparts of test_214 (NI down/up with the link) and test_109 (NI on an interface alias), using the o2ib interface on o2ib nodes where possible, otherwise Soft-RoCE, and skipping without either.
