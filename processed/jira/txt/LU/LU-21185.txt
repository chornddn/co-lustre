--- Description ---
When an admin marks a file "immutable" (chattr +i) or "append-only"

(chattr +a), normal users should not be able to change it unless they

have the special CAP_LINUX_IMMUTABLE permission.

But there's a loophole: the client sometimes sends a flag called

ATTR_FORCE with its request (for example, when clearing setuid/setgid

bits after a write, or during HSM import). Because the client controls

this flag, a normal user can set it and the MDS will let the change

through anyway, even though the file is marked immutable or

append-only and the user does not have the right permission.
