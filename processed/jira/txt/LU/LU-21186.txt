--- Description ---
Swapping the layouts (data placement) of two files should only be allowed after verifying that the user has permission to access both files.

The MDS already prevents clients from setting the internal flag SWAP_LAYOUTS_MDS_RELEASE, as it is reserved for server-side HSM release operations and bypasses normal permission checks.

However, a similar internal flag, SWAP_LAYOUTS_MDS_HSM, was not properly restricted. A modified client could set this flag directly and bypass the normal permission checks when swapping file layouts.

As a result, a user could swap layouts of files they are not authorized to modify, including immutable files or files owned by other users.

Expected Behavior: The MDS should prevent clients from setting internal-only flags and ensure that normal permission checks are always enforced for client-initiated layout swaps.
