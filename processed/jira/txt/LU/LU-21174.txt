--- Description ---
sanity-sec test_73 fails intermittently because the CREAT changelog record of a file in an fscrypt directory carries the raw encrypted name bytes, where the test expects the digested (base64) form that fid2path returns for the locked directory:

  name  in CREAT is not IMT_Mb4xI_N-ZEqs76nvOCBoKd4_3nKpc6V2zW9Hedg

In the failing log the CREAT for the touched file (j=touch.0) and the later RENME (j=mrename.0) both show a binary name, while fid2path gave the digest. The failure is rare (about 0.1% of runs) and spans configurations.
