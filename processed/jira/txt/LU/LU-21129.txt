--- Description ---
Problem

echo default > /sys/fs/lustre/llite//trash_can_projid
-bash: echo: write error: Invalid argument

The store handler compares the buffer with "default" without stripping the trailing newline. It should use sysfs_streq() or strip \n before parsing. Admins and lctl set_param both send newline-terminated values, so the documented "default" keyword cannot be set with echo.

Expected

echo default and echo  both work. The MDT-side mdd.*.trash_can_projid store needs the same check, but test_97 did not reach it because the client check failed first.
