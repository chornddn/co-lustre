--- Description ---
MDS crash (LBUG) while unmounting an MDT in sanity-sec test_27ac, DNE ldiskfs el8.10 (review-dne-selinux-ssk-part-2).

LustreError: 160972:0:(genops.c:431:class_free_dev()) ASSERTION( obd->obd_minor == 1 || class_num2obd(obd>obd_minor) == obd ) failed: obd ffff934bbc429638 != obd_devs[7] 0000000000000000

Trace (umount -d -f /mnt/lustre-mds2, i.e. lustre-MDT0001, while its osp connections to MDT0000 were already failing with -107):

class_free_dev class_unregister_device() erased the obd_devs entry and dropped the obd_device_list reference, and that dropped the last reference, so class_free_dev() ran with obd_minor still set and obd_devs[7] already empty. The "newdev" reference class_detach() drops afterwards must already have been gone, so some other path has put one reference too many on this obd (a refcount imbalance or race during MDT teardown).

Seen once: lustre-reviews build 134461 (change 67604 patchset 23, which touches only mdd/mdt/llite NO_APPEND handling and nothing in obdclass), test session 62f3ce76-122b-44d7-898c-463707bec595, master, 4.18.0-553.155.1.el8_10_lustre. The same test group passed 1345 of 1345 runs on other changes in the previous 30 days; no other crash with this signature in 30 days.
