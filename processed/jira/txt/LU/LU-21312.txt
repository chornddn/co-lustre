--- Description ---
Reserve one opcode in enum ost_cmd for an internal message channel between an MDS and an OSS:

OST_MDS_MSG = 24

The opcode is reserved for external services that run on MDS and OSS nodes and need their own data exchange, including vendor-specific services. Apart from a magic at the start of the request buffer, Lustre does not define the content of these messages, and no in-tree user is planned as part of this reservation.

Properties:

	Requests are sent only by an MDS (OBD_CONNECT_MDS export) to an OST. Data from the OSS travels back in the reply. Clients do not use this opcode.

	The request carries one buffer after ptlrpc_body that ptlrpc does not parse. Its first __u32 is a magic chosen by the service owner, so that several services can share the opcode and a receiver can reject a message that is not meant for it. The rest of the buffer is defined by the service.

	A server with no handler for the opcode answers -EOPNOTSUPP. This relies on LU-19916 ("target: size handler tables to their opcode range"); without it an OSS or MDT reads past the end of its OST handler table for this opcode.
