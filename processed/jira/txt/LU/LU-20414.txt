--- Description ---
At some point it will be useful to have a tool which can somewhat intelligently apply kernel mail list patches to lustre and lustre patches to the kernel for submission.

$ contrib/scripts/lustre-kernel-sync.py --lustre ~/w/lustre-release --linux ~/w/linux --mode linux-to-lustre -v -h
usage: lustre-kernel-sync.py [-h] [-r LUSTRE] [-l LINUX] [-m MODE] [-g] [-v] [-n]

Copy files between linux and lustre

options:
  -h, --help           show this help message and exit
  -r, --lustre LUSTRE  Output file name (default: /home/shaun/w/lreview/contrib/lustre-release)
  -l, --linux LINUX    Kernel kernel headers (default: /home/shaun/w/lreview/contrib/scripts)
  -m, --mode MODE      mode default: 'linux-to-lustre'
  -g, --debug          Enable extra debug messages, default: No
  -v, --verbose        Enable extra messages, default: No
  -n, --dryrun         Dry run make to changes to any files default: No
