--- Description ---
sanity test_119s returns 34 on review-ldiskfs-arm (EL8.10 x86_64 servers, Rocky9.8 aarch64 client). After raising OST brw_size and remounting, the test sets osc.*.max_pages_per_rpc=16M, then its EXIT trap attempts to restore the saved value 1024 and fails:

error: set_param: setting osc/.../max_pages_per_rpc=1024: Numerical result out of range

test_119s returned 34

Current failure: https://testing.whamcloud.com/sub_tests/5b9399ef-9760-4db8-a3aa-d095c7ae1827

Session: https://testing.whamcloud.com/test_sessions/baf30687-7768-407f-9a96-76206e1084d1

Change 69318 PS2, revision 53236866c207, only changes SSH command handling in test-framework.sh.

The same detailed sequence and ERANGE restoring 1024 occurred before this patch on change 68413 PS1 on 2026-08-27:

https://testing.whamcloud.com/sub_tests/0d62653d-f2d9-43dc-b0b0-f5f967da9e32

and change 67696 PS6 on 2026-08-30:

https://testing.whamcloud.com/sub_tests/8726d596-f570-41b4-a4db-a782e22f8b64

Both are review-ldiskfs-arm. Logs were compared, not just the generic returned-34 message.

Rainshadow shows 3 failures / 1075 non-skipped review-ldiskfs-arm runs over 120 days (1072 passes); 1 / 300 over the last 30 days. These rates cover this subtest's errors, not a controlled reproduction. No local guest reproduction was needed to establish that this predates the patch.

The test was added by 54431bbfc0 (LU-20520), already in the base. LU-20520 covers a bulk-write hang, not this parameter restoration failure. LU-18739 describes sizes below 1M, and LU-6421 describes persistent settings lost across remounts; neither covers this failure. Searches for the test name, max_pages_per_rpc with range, and max_pages_per_rpc with 1024 found no matching ticket.

On a 64KiB-page client, 1024 pages is 64MiB, above the 16MiB RPC bound. max_rpc_store treats bare numbers above PTLRPC_MAX_BRW_PAGES as byte values, which also makes 1024 invalid. The test saves the parameter after remount; investigate why it can read this value and ensure valid restoration. The precise source of the saved value has not been reproduced.
