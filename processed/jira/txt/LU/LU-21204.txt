--- Description ---
A plain component whose stripe count is larger than the number of OSTs is clamped to the OST count and flagged LOD_USES_DEFAULT_STRIPE, so only 3/4 of the count has to be found before allocation succeeds.  lod_ost_alloc_rr() keeps its first pass off the OSTs used by another component of the file and retried only while short of that minimum, so  a trailing PFL component could stop one OST short: -c 40 on an 8-OST file system, with one OST taken by an earlier component, allocated 7  stripes instead of 8 and capped the file at 112 TB, while -c 8 reused the OST and got all 8.
