--- Description ---
When "lfs trash unrm" (or "lfs trash mv") restores an entry from .Trash and a live file with the same name already exists at the destination, the command succeeds without any message and swaps the two files. The trashed file becomes live under the original name, and the previously live file is moved into .Trash.

The restore is done with rename(2), which replaces an existing target. The MDT then moves the replaced target into Trash Can like any other deleted file.

Reproducer:

D=/mnt/lustre/dir; mkdir $D
echo v1 > $D/f1; rm -f $D/f1
echo v2 > $D/f1
lfs trash unrm $D/.Trash/f1     # rc = 0
cat $D/f1                       # v1, the live v2 is now in $D/.Trash/f1

Expected: the restore fails with EEXIST and leaves the live file untouched.
