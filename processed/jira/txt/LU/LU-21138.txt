--- Description ---
Problem: DoM requests also pull DT LQA pools (qmt_pool.c:415). DoM grant only exists in global dt-0x0; DT LQA lqes are rebuilt from OST slaves, so granted=0 and qmt_lqes_can_rel() rejects the MDT release (-EINVAL).

Release too much! uuid:-MDT0000-lwp-MDT0000_UUID pool:dt-0x0; real failing entry is next line pool:lqa-dt-* granted:0.

Repro: quota+DoM; DoM writes as uid; add LQA range for uid (triggers recalc); delete files.

Fix: skip DT LQA pools for DoM (idx == QMT_POOL_IDX_GLB).
