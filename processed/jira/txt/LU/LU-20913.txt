--- Description ---
Currently lfs pool pin/unpin on a directory only sets the lustre.pin xattr on that directory itself, so new files created under it inherit the pin, but existing files and subdirectories are untouched. -recursive walks the target directory tree and applies the same pin/unpin (and only/-not-pool, where given) to every file and subdirectory found, so an existing tree can be pinned in one shot instead of applying the xattr to each file by hand.
