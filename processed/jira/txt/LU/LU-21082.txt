--- Description ---
Add an option like pcc=CACHEDIR to mount.lustre to automatically configure and enable PCC-RO on a client mountpoint.  This would depend on an in-tree PCC cache management utility that mount.lustre would start, but would simplify usage and configuration.

--- Comment (adilger, Tue, 3 Nov 2026 18:48:26 +0000) ---
It might be convenient to allow -o pcc without a specified $CACHEDIR to use some default like /var/cache/lustre/FSNAME so that it doesn't need to be specified explicitly on all the mountpoints?

This would do the PCC initial setup (pick a default archive ID?) instead of having to start this explicitly.
