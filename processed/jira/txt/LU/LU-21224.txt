--- Description ---
Two fixes for newer Linux 7.x kernels:

	osd-ldiskfs fails to build at modpost on kernels without CONFIG_CRC_T10DIF (for example mainline 7.0 from defconfig, which has no BLK_DEV_INTEGRITY): obdclass defines obd_dif_crc_fn() and obd_dif_ip_fn() only with CRC_T10DIF, but osd_integrity.c uses them unconditionally. osc already handles this case.

	lst new_session oopses with a NULL dereference in lst_sessions_cmd() on Linux 7.1 and later. Since upstream commit b93ec16310b4 ("genetlink: use maxattr of 0 for the reject policy"), genetlink fills info->attrs only for operations with a policy, and the lnet_selftest family has none.

Found while building and testing on mainline 7.0 and 7.3.4.
