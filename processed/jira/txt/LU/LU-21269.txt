--- Description ---
Add counters to track how many ptlrpc requests accumulate between updates to obd_last_committed. This helps diagnose commit latency issues where requests pile up before the last_committed transno advances.

We used it to compare the differences between the ldiskfs and zfs backends, and how many maximum requests would be sent during recovery. Since recovery is a single-threaded process with time limits, there is a maximum number of RPCs that can be handled during it. Therefore, the commit time and queue need to be tuned to ensure that recovery finishes on time.
