--- Description ---
sanity-lnet test_110 intermittently fails when recreating an o2ib NI using:

lnetctl net add --nid @o2ib

The failure is:

{{kiblnd_startup(): ko2iblnd: No matching interfaces

Error -100 starting up LNI o2ib}}

In kiblnd_startup(), the valid supplied NID is cleared while determining the default interface. Interface selection then depends on enumeration order and may select the wrong interface.
