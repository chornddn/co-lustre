--- Description ---
Running lfs migrate -m 0 -c 2  (or any migration requesting stripe_count > max_stripe_count, such as -c 2 without -C or -C 2 when lod_max_stripes_per_mdt=1, on a single-MDT filesystem) causes an immediate LBUG kernel panic on the MDS inside lod_prep_lmv_md():

LustreError: ...:(lod_object.c:...:lod_prep_lmv_md()) ASSERTION( lo->ldo_dir_striped != 0 ) failed:

Call path on the MDS:

lod_prep_lmv_md
 -> lod_xattr_set_lmv
 -> lod_dir_striping_create_internal
 -> lod_xattr_set
 -> mdo_xattr_set
 -> mdd_create_object
 -> mdd_migrate_create
 -> mdd_migrate_object
 -> mdd_migrate
 -> mdt_reint_migrate

Steps to Reproduce

 

	Mount a Lustre filesystem with a single MDT (MDSCOUNT=1)

	Create a directory with a file inside it.

mkdir /mnt/lustre/testdir touch /mnt/lustre/testdir/file

	 

	Run lfs migrate requesting 2 metadata stripes:

lfs migrate -m 0 -c 2 /mnt/lustre/testdir
