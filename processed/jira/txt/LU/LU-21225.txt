Error: "check_iam errcode does not fit with errors 0 N" (N varies, 53 to 71). The test counts corrupted IAM files by pdsh exit code 255 (rc_corrupted) and compares it with the number of "FINISHED WITH ERRORS" lines in the output. With b2_16 servers rc_corrupted stays 0 while check_iam reports errors for the LFSCK and nodemap files, so the exit status of the remote command is not seen as 255. The test also treats the files as present on 2.16.0+ servers (LU-18401), so b2_16 development version numbering may be a factor.
