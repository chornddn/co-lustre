lfs support to migrate a stripe to a different OST.

This will be useful for replacing a bad stripe for the data component in an EC protected file using degraded read.

For migrating away from an OST/rack/failure domain before a scheduled maintenance event

For re-balancing of OST usage

...

We do not yet support migration of parity stripes.  That will come later as a separate feature once we decide how that should work.
