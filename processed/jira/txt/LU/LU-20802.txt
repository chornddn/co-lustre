Summary

Implement OBJECT-scope direct pread and lseek (SEEK_DATA, SEEK_HOLE, SEEK_END).

Description

Replace the P1 -EOPNOTSUPP stub for OBJECT. OBJECT is its own entry path: the caller names one OST object, and pos is an offset on that object.

	One sub-I/O. The object offset is used as-is (identity mapping).

	No component-extent walk, and no file-offset to stripe-offset rewrite.

	O_DIRECT only.  mmap is rejected.

	ios_fid is the only identity, and it must be non-zero.

EOF is the target object's kms. This is a third EOF case, beside the file i_size and ci_parity_eof. OBJECT does not set ci_parity_io, so ci_parity_eof is unchanged.

	Uninstantiated component: -ENOENT.

	Dead object: -EIO. Do not fall back to CIT_EC_RD.

write, truncate, and fallocate on an OBJECT-scope fd stay -EOPNOTSUPP until P3. File-offset helpers are left unchanged.
