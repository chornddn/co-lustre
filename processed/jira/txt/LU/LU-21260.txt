--- Description ---
Rocky 9.9 was released on 15 Nov 2026 and we are unable to compile lustre source code with its stock shipped kernel version (5.14.0-741.22.1) .

Lustre client build failure on RHEL/Rocky 9.9 kernel (5.14.0-741.22.1.el9_9)
=============================================================================

SUMMARY
  lustre-2.16.0_ddn64 client fails to compile against kernel 5.14.0-741.22.1.el9_9.
  lustre/llite/dcache.c:204 (ll_prune_aliases) uses dentry->d_u.d_alias, but the
  el9_9 kernel made that union anonymous (there is no 'd_u' member anymore).
  Only this one site fails (6 x "'struct dentry' has no member named 'd_u'",
  all from dcache.c:204). Builds fine on el9_8 (5.14.0-687.x).

ENVIRONMENT
  OS            : Rocky Linux release 9.9 (Blue Onyx)
  Kernel        : 5.14.0-741.22.1.el9_9.x86_64
  kernel-devel  : kernel-devel-5.14.0-741.22.1.el9_9.x86_64
  Compiler      : gcc (GCC) 11.5.0 20240719 (Red Hat 11.5.0-17)
  Lustre        : 2.16.0_ddn64 (lustre-source.tar.gz shipped by EMF)
  OFED          : none (in-kernel IB stack)
  Install via   : emf client install client5   (flavor: source)
-> python3 exa_client_deploy.py --emf emf --install --yes
-> make rpms -j 2   (fails in %build)
