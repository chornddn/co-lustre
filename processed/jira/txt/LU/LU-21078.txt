--- Description ---
Debian now requires packages to be reproducible, so that anyone can

    rebuild a package and verify that it matches the published binary

    (https://lists.debian.org/debian-devel-announce/2026/05/msg00001.html).

    Lustre debs built from the same tree on the same machine did not

    match: each build produced files with different checksums.
