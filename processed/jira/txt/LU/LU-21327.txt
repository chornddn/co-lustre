--- Description ---
Add rustreapi::data_version(), a safe wrapper for llapi_get_data_version() / LL_IOC_DATA_VERSION.  It takes a BorrowedFd and a DataVersionFlags bitflags set, and returns the file's u64 data version.  The flags are ReadFlush (LL_DV_RD_FLUSH) and WriteFlush (LL_DV_WR_FLUSH).  DataVersionError gives separate variants for:

	a descriptor that is not a regular file on Lustre (ENOTTY, which includes a Lustre directory);

	an O_PATH descriptor (EBADF);

	any other errno.

Each call is a single ioctl, with no open, stat or allocation.  That makes it cheap enough to call on every request.

LL_DV_SZ_UPDATE is not exposed: ll_file_ioctl() masks it off LL_IOC_DATA_VERSION, so it has no effect from user space.

The change includes unit tests and a data_version_test integration test, which rustreapi-test.sh runs.  It depends on LU-21329 and LU-20663.
