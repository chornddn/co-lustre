--- Description ---
A pool name containing . injects a spurious level into the lctl parameter hierarchy, so tools like list_param/get_param can no longer tell where the pool name ends and a real sub-parameter begins.

# lctl list_param qmt.test-QMT0000.*.glb-usr
qmt.test-QMT0000.dt-local.glb-usr           pool "local"        OK
qmt.test-QMT0000.dt-local-1.glb-usr      pool "local-1"     OK
qmt.test-QMT0000.dt-local_1.glb-usr      pool "local_1"     OK
qmt.test-QMT0000.dt-local.abc.glb-usr       pool "local.abc"    BROKEN
