--- Description ---
sanity test_252 fails with:

Invalid number of mdtlov clients returned by /usr/sbin/lr_reader

The review-ldiskfs run has one MDT: tests requiring >= 2 MDTs skip

throughout the sanity suite. lr_reader -c on MDT0000 nevertheless

prints all three records:

  lustre-MDT0001-mdtlov_UUID (generation 7)

  lustre-MDT0003-mdtlov_UUID (generation 8)

  lustre-MDT0002-mdtlov_UUID (generation 9)

The test counts these records and requires MDSCOUNT - 1, which is zero.

The origin of the extra records needs investigation.
