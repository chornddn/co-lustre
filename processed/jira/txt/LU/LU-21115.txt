--- Description ---
lnet-selftest test_teardown_race crashed the console-session node (trevis-156vm241, el9.8 x86_64, ZFS, DNE) with an LBUG in the selftest RPC service worker:

LNetError: (rpc.c:1088:srpc_handle_rpc()) ASSERTION( rpc->srpc_bulk == ((void *)0) || bev->ev_fired ) failed:

Workqueue: lst_t swi_wi_action [lnet_selftest]

srpc_handle_rpc+0x311/0x3d0 [lnet_selftest] The crash came about 4 seconds after cycle 1 of the test started lst_setup, while the test was running 32-way bidirectional brw 1M read/write plus ping and then calling end_session. Just before it the node logged repeated "brw_server_rpc_done() Bulk transfer from 12345-@tcp has failed: -108" (ESHUTDOWN) messages.

In SWI_STATE_BULK_STARTED (and when falling through from NEWBORN after srpc_do_bulk() returned 0) the LASSERT requires the bulk event to have fired, but the worker can reach that state while the bulk MD event is still outstanding when teardown or abort races with it. The test is the one added for LU-20104 (teardown race).

Failure: https://testing.whamcloud.com/test_sets/138f45dd-df7f-4873-806a-5deb70b6b9fc (lustre-reviews build 135211, review-dne-zfs-part-2, patchset 4 of https://review.whamcloud.com/70169, which only touches lod and conf-sanity so cannot cause it).
