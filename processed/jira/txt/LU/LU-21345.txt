--- Description ---
llsom_sync in one-shot mode discards the return value of lsom_start_update() and treats an empty changelog (EOF) as success, so it exits 0 and nothing is synced.

If the MDD changelog GC force-deregisters the user (space or catalog pressure), it also turns the changelog off and purges it. llsom_sync then reads 0 records, LSOM stays stale, and sanity test 807a fails with

 "expected blocks: 2048, got: 0"

even though the tool reported success.
