--- Description ---
A general import for nodemaps and their properties would be beneficial, e.g., for backup, parsing, restore, etc. For exporting nodemap YAML definitions, the existing lctl nodemap_info was extended. For importing nodemap YAML definitions, a new command, e.g., lctl nodemap_import, can be added. In addition, the API should allow enough flexibility to restrict the import to specific nodemaps and their properties so that users are not required to manually modify the YAML definition, e.g., to remove unwanted nodemaps or properties before importing.

This issue targets YAML import:

The following API definition is possible:{}

(new) lctl nodemap_import [--name ] [-–property ] ./nodemap.yaml

    - Imports a YAML file generated by lctl nodemap_info. 

    - The command can be used to import multiple nodemaps and properties at once, depending on the input file.

    - lctl nodemap_import further allows restricting the import to specific nodemaps and/or properties. This is useful when the imported YAML file includes more information than needed. --property may be used multiple times to allow several properties to be imported.
