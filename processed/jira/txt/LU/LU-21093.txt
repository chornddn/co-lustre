--- Description ---
When an import is created, it records the pid of the reaper (init process) of the creator's pid namespace in imp_sec_refpid. The GSS keyring upcall uses this pid to find the mount namespace in which to retrieve root credentials (krb5.conf, keytab, etc.), which allows containers to use their own Kerberos configuration. For user credentials, the pid of the calling process is used instead.

Only the pid number is stored, and it is resolved through /proc by lgss_keyring at upcall time. Make it a proper reference on the struct pid in the import instead.
