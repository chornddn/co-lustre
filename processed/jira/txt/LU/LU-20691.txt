--- Description ---
Allow hsm coordinator to move timedout restores to ARS_WAITING. Today all these requests are marked as failed. We should be able to re-use the same mechanism as intentional retry since those do get reassigned. 

It need not be default behavior, can be enabled/disabled via policy flags.

--- Comment (eaujames, Wed, 9 Sep 2026 19:28:41 +0000) ---
Can you elaborate on...

This is the purpose of https://review.whamcloud.com/c/fs/lustre-release/+/59067. 

llapi_hsm_copytool_register() open a fd on the Lustre mountpoint to communicate with the kernel. If the copytool crash, llapi_hsm_copytool_deregister is not called but linux will cleanup the fd (it closes the fd). On close(), the patch checks if an agent is still registered. If true, the Lustre client will automatically deregister the agent by sending an MDS_HSM_CT_UNREGISTER RPC to the MDT coordinator.

--- Comment (eaujames, Wed, 9 Sep 2026 19:41:14 +0000) ---
Note: If the entire copytool node becomes unresponsive, the server will evict it and automatically deregister the agent.

This case is handle by: 59251: LU-18238 mdt: ghost hsm fix | https://review.whamcloud.com/c/fs/lustre-release/+/59251
