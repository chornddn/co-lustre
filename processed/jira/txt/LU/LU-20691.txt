--- Description ---
Allow hsm coordinator to move timedout restores to ARS_WAITING. Today all these requests are marked as failed. We should be able to re-use the same mechanism as intentional retry since those do get reassigned. 

It need not be default behavior, can be enabled/disabled via policy flags.
