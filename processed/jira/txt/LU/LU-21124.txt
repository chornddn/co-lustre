--- Description ---
The current implementation only fix linkEA for local object, which may cause a file's nlink too low after it adds a missing linkEA entry for a name on another MDT.  

The correct behavior should be

1. the parent MDT tell the child MDT to add missing linkEA, and also add an event to check the nlink. 

2. Then in second phase, the child MDT will scan the object again to fix the nlink.
