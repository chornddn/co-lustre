--- Description ---
Tools that run on a server, such as lfs find --device --fid2path (LU-20637), need a client mount on that node to turn a FID into a pathname. A client mount on a server node causes problems with HA failover and with module removal.

Add a device-level administrative interface on the target itself, so that basic operations such as OBD_IOC_FID2PATH can be called without a client mount. Possible forms (from review of https://review.whamcloud.com/68288):

	/mnt/testfs-MDT0000/.lustre/fid/ on the target mount

	an ioctl on the target mount point /mnt/testfs-MDT0000

	an ioctl on /dev/obd

lfs find --fid2path and llapi_scan_rec_path() would then use it when no client mount is given.
