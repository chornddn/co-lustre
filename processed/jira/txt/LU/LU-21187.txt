--- Description ---
When a client closes a file normally, the MDS temporarily grants extra permissions to avoid unnecessary permission checks.

However, these extra permissions should not be granted when closing a file also involves changes to its layout. This is already handled correctly for HSM release and layout swap operations.

The same restriction was missing for FLR mirror merge and split operations.

As a result, closing a file after merging or splitting FLR mirrors could receive extra permissions and bypass normal security checks, including the immutable file check.

Expected Behavior: The MDS should not grant extra permissions when closing a file after an FLR mirror merge or split, just as it does for HSM release and layout swap operations.
