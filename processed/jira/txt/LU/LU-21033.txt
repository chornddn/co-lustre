--- Description ---
By default, lctl dk uses the temporary file LIBCFS_DEBUG_FILE_PATH_DEFAULT (/tmp/lustre-log.) to store raw kernel dump. This allow a distinct file for any other calls to lctl dk.

There are some issue with this path:

	If the /tmp directory doesn't have enough space, the temporary raw file is truncated.

	If /tmp is colocated with another directory, it may fill up the filesystem with other consequences on the system.

	During the run of lctl dk /tmp/debugfile, it takes more than the amount of disk space specified in debug_mb.

	The user is not aware that it needs extra space to dump lustre kernel logs in the ASCII mode.

Suggested solution:

	Use TMPDIR variable to give users the ability to choose the temporary file location

	Display the path of the temporary file

	Improve lctl man page
