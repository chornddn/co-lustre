--- Description ---
runtests test_1 on a DNE review session (el9.7, review-dne-part-2, ldiskfs) restarts all servers and remounts the clients. The client mount then fails twice with "mount.lustre: mount ... failed: Connection timed out" (rc = -110) and runtests carries on against an unmounted /mnt/lustre, so the later checks report "Post remount. Files differ: rc=2" (or "statmany ... failed", "No such file or directory").

Client debug log: every MGS connect request (o250 to MGC10.240.23.246@tcp) expires after 1s with "Request sent has timed out for sent delay: [sent N/real 0]" and err -110, i.e. the request was never put on the wire. The MGS node's dmesg shows nothing for the attempt. The client console then logs "MGC10.240.23.246@tcp: Confguration from log lustre-client failed from MGS -110. Communication error between node & MGS".

The cluster stays unusable for the rest of the session: sanity-lfsck fails its setup with the same client mount timeout ("NAME=autotest_config not mounted"), and sanity-sec and pjdfstest then fail setup with "mountoss failed" because the OST5 to OST8 dm-flakey devices were never created after the aborted sanity-lfsck setup.
