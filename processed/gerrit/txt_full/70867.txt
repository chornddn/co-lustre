LU-20354 quota: complete per-stype qmt_sarr API

de71b51fad split pool membership into tgts[QMT_STYPE_CNT], but
the qmt_sarr_* helpers (lock, get_idx, count, rem, check_idx)
still cover only the primary array, so qmt_sum_lqe_usg() takes
qpi_sarr()->op_rw_sem and walks op_array directly, and the MD
usage cache would have to do the same.

Add per-stype lock macros, qmt_sarr_get_idx_stype() and
qmt_sarr_count_stype(), and build the primary helpers on them.
qmt_sarr_pool_rem() and qmt_sarr_check_idx() take a stype.  Add
qmt_sarr_for_each() to call a callback for each member of every
initialized array under that array's op_rw_sem, and use it in
qmt_sum_lqe_usg() so the sarr internals stay in qmt_pool.c.
