LU-20342 doc: flesh out lst.8 for check modes and discard

The lst.8 man page listed only --list-commands and gave no description
of the lst subcommands or of the brw test parameters, so there was
nowhere to properly document the new check=discard bulk mode.

Rewrite the page to list the common console commands, document the
add_test options and the ping/brw test parameters, and describe the
brw check= modes (none, simple, full). Document check=discard (aka
skip_rx_copy/skip-rx-copy) as a peak-throughput mode that performs no
data verification and only takes effect on the receiving (sink) side --
the client for brw read, the server for brw write -- and only over
socklnd (@tcp); it is silently a no-op on other LNDs. Fix the example
so the discard test's sink lands on the @tcp servers group and so
actually exercises the feature.
