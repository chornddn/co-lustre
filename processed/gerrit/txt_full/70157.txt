--- Commit Message ---
LU-21060 utils: add client jobstats selectors

- lljobstat has no OSC or MDC selector and does not know several
  client metadata counters.
- A record without a known operation has no operation total, so
  sorting the top jobs fails with a KeyError traceback.
- Add -O/--osc and -M/--mdc, recognize the client operation names,
  and start every job with an operation total of zero.
- MDTs already count readpage, so lljobstat output on an MDS now
  includes it in the totals and as rp.
- Extend sanity test_850: check both selector forms against an lctl
  fixture, the full and short operation names, and saved, empty and
  invalid input. It skips when PyYAML is missing, and accepts ENOENT
  from lctl on a node without any job_stats file.
- Also fix the program name in the lljobstat(8) SYNOPSIS.
- The kernel interfaces follow in the next LU-21060 patch.
