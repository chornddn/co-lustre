LU-7880 target: return target load in statfs

Clients and applications have no cheap way to see how busy each
OST or MDT is, so they cannot steer IO or file creation away
from busy targets, or delay a checkpoint while the filesystem
is loaded.

Return a coarse view of the target load in statfs replies when
the client asks for it with OBD_STATFS_PERFSTATS.  The request
flag is sent in mbo_flags of MDS_STATFS_NEW, or in o_flags of
the ost_body of OST_STATFS_NEW, only to servers that support
OBD_CONNECT2_PERFSTATS.  Other requests still get the original
144-byte reply.

tgt_perfstats_fill() samples the existing per-target stats from
the statfs handler, at most once per second and only as often as
statfs asks for them.  Otherwise tgt_request_handle() samples them
once a minute, so a burst of IO between statfs requests is not
missed.  The IO path only compares a timestamp.  This returns the
read and write bandwidth in KiB/s and the read and write RPCs/s,
as a decaying average and a slowly decaying peak of that average,
and sets OS_STATFS_PERFSTATS in os_state.  The average halves in
about 9s, so it shows 90% of a change in load after 30s.  The
peak follows the average rather than single samples, so it is a
rate the target sustained and not a burst absorbed by a cache.
It halves in about an hour, but never drops below half of the
highest average, since an idle target keeps its capacity.  The
first sample after the target is set up, or after its stats are
cleared, only sets where the counters start, and the target does
not return OS_STATFS_PERFSTATS until it has measured the rates.
On OSTs reads are BRW reads and getattr, and writes are
BRW writes and other modifying RPCs.  On MDTs, reads are open,
close, getattr, getxattr, readpage and DoM reads, and writes are
the namespace and attribute changes and DoM writes.

Use enum obd_statfs_req_flags for the flags of the statfs
methods.  The lmv and lov IOC_OBD_STATFS handlers now pass
OBD_STATFS_PERFSTATS from userspace down to mdc and osc, and clear
OS_STATFS_PERFSTATS in cached data when it was not asked for.
obd_statfs() refreshes cached data that lacks the requested stats.
