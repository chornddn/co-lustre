LU-21276 tests: fix sanityn/39 clock skew checks

Fix sanityn test_39a and test_39d to account for minor skew between
kernel and userspace clocks.  This extends the sanity.sh fix in
"LU-12105 tests: fix sanity/39 checks and style" to sanityn.sh,
which has the same problem but was not touched by that patch.

Both tests bracket a write with userspace "date +%s" reads and then
require d1 <= mtime <= d2.  When the kernel timestamp recorded for
the write falls just outside that window, the check fails even
though mtime was updated correctly, so sleep briefly on either side
of the write to widen the window.
