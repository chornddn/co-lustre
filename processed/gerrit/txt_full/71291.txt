LU-12187 flr: negotiate layout patterns without EC enabled

A client requested OBD_CONNECT2_FLR_EC and sent its layout pattern
mask only when lustre.enable_flr_ec was set, and the MDS granted the
flag only when parity was enabled in mdt.*.layout_pattern_types.
With erasure coding disabled on either end, as by default, no mask
was exchanged: an MDS could not tell a 2.18 client from an older one,
and 'lfs mirror extend --no-resync', which needs the flag only
because an older MDS ignores cd_merge_flags, would fail with
EOPNOTSUPP.

Always request OBD_CONNECT2_FLR_EC and send the pattern mask from the
client, with LOV_PATTERN_PARITY only when lustre.enable_flr_ec is set,
and always grant the flag on the MDS, which replies with the
intersection as before.  Parity is still used only when both ends
enable it.  Update the lfs error message, man pages and comments.

Add conf-sanity test_163e to check the negotiation at mount and on
reconnect, and a stale mirror merge, with erasure coding disabled.
