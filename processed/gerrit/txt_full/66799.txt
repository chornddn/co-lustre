LU-20418 build: introduce gen_compat and drop cfs_* timer

Introduce a faster build checking system that uses snippets of
python code in:
  config/compat.d/*.ksym
to generate a macros and/or inject code into config.h

The bulk of the cfs_timer* API is not needed after 4.15 the only
remaining part is conditionally defining timer_container_of which
can migrated to config.h.
Use a snippet to inject this into config.h and remove the
cfs_timer* API.
