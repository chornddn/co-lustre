LU-20869 tests: speed up sanity-quota test_49a

test_49a set and deleted quota for every ID with a serial
loop of lfs setquota, checked each ID range twice with the
same arguments, and ended with formatall and setupall.
The delete loop already removes every ID that was set, so
the reformat only cost time: no later test depends on it,
and test_87, the only other user of lfs quota -a, sets the
IDs it reads.

Run the setquota and delete loops 8 ways in parallel,
check each range once, and drop the reformat.

Also use NOSYNC during deletion and fail the test if deleting
either quota type fails.

On rocky9 with 1000 IDs the test took 150, 151 and
156 s before and 50, 40 and 40 s after. In CI the median
review run spends 210 s of 367 s in formatall and setupall,
and the mean is 457 s over 6630 runs per 30 days; at about
250 s saved per run this is about 460 hours per 30 days.
