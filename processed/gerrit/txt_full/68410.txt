LU-10026 llite: issue compressiblity change in workqueue

This patch uses kernel-global workqueue to handle the file's minor
layout change RPC equest. At vvp_io_fini() when it find that the
file's compressibility should be changed, it creates a work and
insert the request to the kernel workqueue.

This would prevent the layout minor change RPC issued from within an
IO, and it could avoid the possible double lock the LOV conf lock.

lov: replace switch compressibility

The switch compressibility flag results in weird behavior -
it tells us we are to flip what's there, but results in some
very hard to read code.

I *think* the existing code is probably correct in absence
of race conditions, but an instruction to "flip" rather than
set is very confusing and could easily do the wrong thing
if there's a race which changes the compressibility value.

Replace it with two explicit bit flags.
