LU-20076 tests: make target start cheaper

Setting the debug masks after each target start goes through
rpc.sh, which costs far more than the three set_param calls it
runs. Send those as a plain remote command, which is about 2700
fewer rpc.sh calls across 17 suites. A node reached this way
always has Lustre loaded, so rpc.sh's module load is not needed.

The first mount of a target also sleeps for a second between two
syncs to commit the label. sync does not return until the label
is on disk, so one sync is enough. conf-sanity does this about
450 times.

Measured on a single node with pdsh over ssh, the old call took
about 0.8 s and the plain remote command about 0.25 s, so roughly
0.5 s saved per target start. That is about 1350 s across the
2700 calls of a full pass of the 17 suites. The sync change
saves about 1 s each, or about 450 s per conf-sanity run. At
about 5900 conf-sanity runs in the last 30 days that is roughly
2.6 million seconds (about 730 hours) of test time.
