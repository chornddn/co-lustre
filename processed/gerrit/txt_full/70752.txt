LU-20711 tcu: add Trash Can audit feature

To support the Trash Can audit feature, this patch does the
following changes:
- Add a new MDT tunable "mdd.*.trash_can_audit" to control
  recording of the audit information on the server side, disabled
  by default.
- Add a new flag URM_FL_AUDIT and set it when audit feature is
  enabled, add unrm xattr extension struct unrm_audit to collect
  audit information, including the deleter's UID, GID, NID and
  JobID, also the original FID.
- Add a new flag URM_FL_FULLPATH and unrm xattr extension struct
  unrm_fullpath for future use.
- Read unrm xattr with lgetxattr() instead of opening the object,
  so that a symlink or a FIFO in the Trash Can can be purged too.
- Report the error and stop ltrash purging if an audit record cannot
  be written, instead of silently dropping the records.
- Correct the logic in mdd_trash_declare_unrm_xattr_set(): Always
  mark the object with LUSTRE_UNRM_FL; As long as audit is enabled,
  set unrm_xattr and export audit information; If audit is disabled
  and keep_ugpid is true, don't set unrm_xattr and audit information,
  otherwise, only set unrm_xattr.
