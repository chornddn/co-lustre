LU-19712 utils: Prevent migrate/mirror on exclusive pinned files

For migrate operations allow the command to proceed when the target
layout's pool matches the exclusive pin pool, even if the pool is not
defined in the command line. Migrations that would change the pool,
and all mirror operations, will be blocked while an exclusive pool pin
is present.
