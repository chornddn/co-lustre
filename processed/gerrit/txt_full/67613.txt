--- Commit Message ---
LU-19994 ec: block LCME_FL_PARITY flag changes

The LCME_FL_PARITY flag is reserved for EC parity mirrors that are
created implicitly by the --ec option.  It must not be settable on a
file layout component through "lfs setstripe --comp-set
--comp-flags=parity", nor clearable with "^parity", on either a
plain data component or the data component of an EC file.
