LU-18687 lnet: do not include lustre_compat.h from lnet

LU-20438 made lnet_rdma.c and o2iblnd.h include <lustre_compat.h>
from lustre/include to get lustre_is_p2prdma_page(). LNet must not
depend on lustre/include: in the in-kernel build lnet has no such
include path, so lnet_rdma.c fails to compile with

  fatal error: 'lustre_compat.h' file not found

Move the fallback into the lustre_compat mm.h shadow header as a
plain is_pci_p2pdma_page() stub for kernels that lack it, and have
the callers use the kernel API name directly.
