--- Commit Message ---
LU-20685 utils: mask hash flags when completing dir migration

Directory migration sends the fixed-hash flag in the final
layout update. Servers before 2.16 compare that value with
the hash type alone and reject multi-stripe migration.

Mask the flags only for the completion setxattr. Keep them
in the migration parameters for subsequent directories.
The server retains the fixed flag from the initial layout.

Fixes: 392f558f4052 ("LU-17810 dne: dir restripe without fixed hash flag")
