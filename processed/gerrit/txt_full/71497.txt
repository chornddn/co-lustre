LU-16960 build: loosen kmod-osd and osd-mount version Requires

kmod-lustre-osd-* required osd-*-mount of exactly the same version,
and lustre-osd-{zfs,wbcfs}-mount required lustre-osd-* of exactly
the same version.  Installing a newer Lustre for a newly installed
kernel next to the build for the running kernel, before rebooting,
would fail when upgrading the userspace packages:

  lustre-osd-ldiskfs-mount = 2.17.61 is needed by (installed)
  kmod-lustre-osd-ldiskfs

Require only the same major.minor version in both directions, as
lustre already does for kmod-lustre.  The new kmods can then be
installed beside the old ones with "rpm -i" and the userspace
packages upgraded with "rpm -U".
