LU-21289 lod: cancel update llogs only in recovery thread

"lctl --device <MDT> llog_cancel" on a running MDT reaches
lod_llog_cancel(), which replaces the update catalogs.  A cross-MDT
operation that declared its update records in the old catalog then
fails its record write with -EIO.  The master MDT keeps its local
updates, so the namespace becomes inconsistent.  No document
describes this path.  The recovery thread uses the same ioctl on
recovery abort, when no other thread runs distribute transactions.

lod_llog_cancel() now returns -EOPNOTSUPP to other callers.  Add
replay-single test_122c.
