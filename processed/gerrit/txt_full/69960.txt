--- Commit Message ---
LU-21023 lod: reload a remote dir's LMV before -ESTALE

lod_dir_layout_check() reloads the LMV of a directory for
MD_LAYOUT_VERSION only when its object is stale. For a remote
directory OSP's opo_stale tracks the attr cache: a remote lock
invalidates it, but the next osp_attr_get() clears it, so the LMV
parsed before the directory changed stayed in use. A mkdir in a
directory under migration then failed with -ESTALE ("Stale version
from a client") though the client had the current layout.

When the layout version of a remote directory doesn't match, reload
its LMV once and check again before returning -ESTALE.

Fixes: db55a3677021 ("LU-18847 mdt: version layout checking")
