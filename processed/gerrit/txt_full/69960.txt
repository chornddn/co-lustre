--- Commit Message ---
LU-21023 lod: reparse a remote stripe's LMV under the lock

lod_dir_layout_check() reparses the LMV of a directory for
MD_LAYOUT_VERSION only when a stripe is stale. A lock intent reply
can refresh the cache of a remote stripe without leaving it stale,
so the LMV parsed before the lock was taken stayed in use, and a
mkdir in a directory under migration failed with -ESTALE ("Stale
version from a client").

Reparse it when a stripe is remote too.
