--- Commit Message ---
LU-20869 tests: speed up sanity test_56wa

test_56wa creates 200 hard links to dir1/file1 and then pipes
lfs find into lfs migrate, which migrates the same file once per
link. The 200 links date from LU-6051, when the old lfs_migrate
script deduplicated hard links, and no longer check anything
specific. test_56xb still covers lfs_migrate with many links.

Create 2 links instead, which still exercises migrating a
hard-linked file. Drop the MDS 2.5.55 version check around the
links, since no server that old can interoperate, and fix the
stale comment there.

In three runs each on a VM, the test took 5 to 7s instead of
36 to 43s. At 17047 CI runs per 30 days that saves about 30s
per run, over 140 hours; CI runs take far longer than the VM
(mean 194s), so the saving there should be larger.
