--- Commit Message ---
LU-20518 tests: skip sanity-pcc quota tests without format

sanity-pcc 10a to 10f set up user or group quota on a loop
mounted ext4 device on the PCC agent. When the agent kernel lacks the
quota format module (quota_v2 is shipped separately by some distros,
such as Ubuntu 24.04), quotaon fails with "Quota format not supported
in kernel" and the test fails, though nothing under test is wrong.

Add quotaon_or_skip(), which skips with skip_env when quotaon reports
that error and keeps failing on any other quotaon error. Also skip in
setup_loopdev_project() (test_39) when the prjquota mount fails and
quota_v2 is not available.
