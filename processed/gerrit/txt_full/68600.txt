--- Commit Message ---
LU-20354 quota: aggregate LQA usage from per-ID cache

Serve lfs quota --lqa by scanning the global index for IDs in
the LQA ranges and summing each ID's existing usage-cache
entries, so GETQUOTALQA can return QIF_SPACE/QIF_INODES without
a slave-side range protocol.

LQA's shared lqe still skips per-slave caching. Add
qmt_lqa_get_usage() with batched glb-index walks, wire it from
qmt_quotactl, treat LQA inacc like GETQUOTA in lfs, and cover
with kunit plus sanity-quota/312. Document LQA behavior in the
usage_cache_* man pages.
