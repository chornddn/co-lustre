--- Commit Message ---
LU-21153 tests: wait for OST0 on all MDTs in sanity 27yb

sanity 27yb restarts ost1 from an EXIT trap and does not wait for
recovery. In a DNE setup the other MDTs may still see OST0000 in
REPLAY_WAIT when the next tests run, so the MDS statfs of OST0000
returns -EAGAIN, the OST is not counted as active, and sanity 27Ca
creates a "-c -1" file with one stripe fewer than OSTCOUNT.

Wait for recovery and for every MDT's import of the OST in the 27yb
exit trap. Do the same in 27ya, which only waited for MDT0000.
