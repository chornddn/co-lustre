LU-21103 lov: move EC raid set code out of lov_io.c

The policy that decides which stripes of an erasure coded read to
avoid is spread through lov_io_mirror_init() and
lov_ecio_add_data_sub(), and the raid set helpers it uses sit in
lov_io.c with the rest of the IO code.  Later patches give the raid
set decision a single implementation and let mirror selection use
the same OST availability checks, so move the code they build on to
where it can be shared first.

Move the OST availability predicates lov_sub_unreachable(),
lov_sub_slow(), lov_sub_unavailable() and lov_sub_loaded() to
lovsub_object.c, next to the sub-object they query.  Move the raid
set helpers and lov_ec_io_route() to a new file lov_ec.c, and
enum lov_ec_route to lov_cl_internal.h.  Functions still used from
lov_io.c are no longer static; the others stay static in their new
file.

No functional change.
