--- Commit Message ---
LU-21217 socklnd: send a zero-copy message in one call

On kernels where TCP takes MSG_SPLICE_PAGES, socklnd still sent
a zero-copy payload one page per sock_sendmsg() call, a shape
left over from ->sendpage. A 1 MB message took 256 calls, each
taking the socket lock and redoing TCP's per-call work, where
the copy path takes one.

Pass the whole bio_vec array in one call when splicing. Kernels
with ->sendpage still send one page per call.
