LU-18857 tests: open allow_register for old scripts and mounts

The MGS refuses new registrations unless allow_register is open, and
test-framework.sh opens short windows around format and writeconf.
Client test scripts before 2.18.0 (b2_15, b2_16) open no window, and
a window opened before a module reload is lost, so interop and some
native sessions would fail to mount targets with -13: sanity-sec
test_31, conf-sanity 24a, 32e and 103, and replay-vbr setup after
sanity-sec.

Have do_rpc_nodes() pass RPC_CALLER_FEATURES=allow_register, and have
rpc.sh on the servers call rpc_allow_register_compat(), which sets
allow_register=unlimited for callers that do not pass it, i.e. client
test scripts before 2.18.0, until the modules are unloaded.  Native
sessions keep the default.

In mount_facet(), call allow_register_mount() to open a window before
mounting a target that registers with the MGS at this mount, a new or
writeconf'd target by its label or the writeconf mount option, after
loading the modules on the MGS node if needed.  This also covers tests
that run tunefs --writeconf directly.  conf-sanity test_37 mounts
without mount_facet(), so it calls allow_register_mount() itself.
wbcfs targets register at every mount.  Tests that check how the MGS
handles allow_register (conf-sanity 157a-c and 157f) set
ALLOW_REGISTER_AT_MOUNT=false.
