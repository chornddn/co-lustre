--- Commit Message ---
LU-16518 osd-wbcfs: fix uninitialized result in osd_create_type_f

lbug_with_loc() is only marked __noreturn when objtool knows about
it (HAVE_LBUG_WITH_LOC_IN_OBJTOOL), so on other kernels the compiler
assumes LBUG() returns. clang then fails the build with -Werror:

  osd_object.c:533:2: error: variable 'result' is used
  uninitialized whenever switch default is taken
  [-Werror,-Wsometimes-uninitialized]

Set result to NULL in the default case of osd_create_type_f().
