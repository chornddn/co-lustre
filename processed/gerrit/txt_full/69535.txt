LU-19672 idl: reserve OBD_CONNECT2_BATCH_DESTROY flag

Reserve OBD_CONNECT2_BATCH_DESTROY at 0x80000000000000ULL for a
target that accepts OUT updates which tolerate -ENOENT, so the OSP
can batch object destroys.  Only the flag, obd_connect_names[] and
the wire checks are added here so the value can land before the
feature patch.
