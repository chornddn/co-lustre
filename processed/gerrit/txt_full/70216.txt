--- Commit Message ---
LU-21072 build: Use build when source is unusable

Since Linux 6.6 (d8131c2965d5) /lib/modules/<ver>/source is no
longer created, so the lustre-client DKMS build fails to find
the kernel source.

Use build when source is missing or has no include/linux, as
dkms.mkconf does. Also do this for the kdir default in
lustre.spec.in.
