--- Commit Message ---
LU-14144 utils: use MODULE.PARAM names for module parameters

"lctl {get,set,list,find}_param --module" matched module parameters
by bare name in every module and printed them without the module
name, so identically-named parameters like lnet.peer_buffer_credits
and ksocklnd.peer_buffer_credits could not be distinguished.

Name module parameters MODULE.PARAM, resolved to
/sys/module/MODULE/parameters/PARAM.  Wildcard module names only
match Lustre/LNet modules.  Also fix --recursive for module dirs.

Restore the llapi_param_get_paths() API changed by 7c7edbcaa8, and
add llapi_param_get_paths_flags() for callers that need the flags.
