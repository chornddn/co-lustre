LU-21061 lfs: add lfs migrate -m --with-data

"lfs migrate -m -p POOL" moves the directories and inodes of a tree
onto the MDTs of a pool, but the file data stays on the OSTs it was
on, and default file layouts in the tree may still name another pool,
so new files keep going there.

Add --with-data: after the metadata, walk the tree, give POOL to each
default file layout that names another pool, and migrate the data of
each file whose OST components do not all name POOL through the "lfs
migrate" path, keeping the rest of its layout apart from OST indices.
With -d, only the files in the directory move.  Mirrored, released
and busy files are reported and left in place, and rerunning the
command moves them and skips what has moved already.  Nothing moves
to a pool that lists no OSTs, and DoM data stays with its inode.

Test-Parameters: mdscount=2 mdtcount=4 testlist=ost-pools
