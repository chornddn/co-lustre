--- Commit Message ---
LU-20958 llite: drop strict SOM size with the UPDATE lock

A strict SOM size and blocks from the MDS are only valid under the
MDS UPDATE lock: a write or truncate of the file takes LAYOUT|UPDATE
in EX mode before the MDS marks the SOM stale.  The client kept
OBD_MD_FLSIZE|OBD_MD_FLBLOCKS in lli_attr_valid after that lock was
cancelled, so anything trusting them without a getattr would use a
size from before another client's write.  stat() was not affected,
since ll_getattr() revalidates first, but EC lseek and the fsync
blocks update are about to rely on these bits.

Clear them from lli_attr_valid when the UPDATE lock is cancelled, so
the next getattr fetches them again.

Add sanity-flr test_44i, which writes a mirrored file with a strict
SOM size and checks the blocks stored at close.
