--- Commit Message ---
LU-20755 tests: fix sanity-sec/5 and sanity-sec/64a for older servers

test_5 checks that l_getidentity returns EIDRM for a nonexistent user.
That only happens on servers with LU-19996, an older MDT logs a
different errno, so the test can never pass. Skip test_5 on older
servers.

test_64a always asks for the "projid_set" RBAC role, even on servers
that don't have it, so the nodemap_modify fails with EINVAL. Only ask
for the role when the server supports it, and skip the parts of the
test that need it otherwise.

Test-Parameters: trivial
Test-Parameters: testlist=sanity-sec serverversion=2.16 env=SANITY_SEC_EXCEPT="45 47 48b 49"
