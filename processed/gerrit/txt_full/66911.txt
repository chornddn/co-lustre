LU-20426 lnet: netlink interface for stats commands

The "lnetctl stats show" and "lnetctl stats reset" commands are the
last LNet statistics paths still carried over ioctl, while net, peer
and route already moved to the Netlink generic interface. Their fixed
ioctl structures cannot grow a field without breaking the ABI, which
leaves no room to add statistics controls.

Add an LNET_CMD_STATS Netlink command. A dump returns the global LNet
counters as a schema-tagged statistics mapping, rendered by name in
userspace, and a doit resets them. lnetctl issues the Netlink request
first and falls back to the existing ioctl when the running module
does not provide the command, so a newer lnetctl still drives an older
module.
