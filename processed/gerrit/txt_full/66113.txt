LU-20036 lfs: add --ec-map getstripe output for EC raidsets

Add lfs getstripe --ec-map and VERBOSE_EC_MAP to print
lcme_raidset_count and lcme_raidsets on parity components,
mapping data stripe indices to parity stripe indices via
the linked data component.

> $LFS getstripe -I$parity_comp_id --ec-map file

  lcme_raidset_count:  3
  lcme_raidsets:
    - 0: { k: 3, data_stripes: "0-2", parity_stripes: "0-1" }
    - 1: { k: 2, data_stripes: "3-4", parity_stripes: "2-3" }
    - 2: { k: 2, data_stripes: "5-6", parity_stripes: "4-5" }

Document the option in lfs-getstripe(1) and add
sanity-ec test_31.
