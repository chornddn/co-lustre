--- Commit Message ---
LU-20879 target: consolidate OUT_UPDATE handling

Fetch OUT_UPDATE buffers in out_handle() with tgt_update_bufs_get(),
the helper shared with mdt_batch(), instead of its own copy of the
inline/bulk buffer setup, and check each update buffer with the new
out_update_request_check() helper.

Check opcode in out_handler_find().  Check the object mode with
dt_mode_is_valid() before deriving object format.

Return -EINVAL from dt_record_write() when object is not writable.

Swabbing is now done in out_update_request_check(), so RMF_OUT_UPDATE,
lustre_swab_object_update(), and lustre_swab_object_update_request()
are now unused and are removed.
