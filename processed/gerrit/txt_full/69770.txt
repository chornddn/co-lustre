--- Commit Message ---
LU-11962 ofd: prepare layout version checks for fencing

To fence writes from clients that the MDT evicted, OSTs compare the
layout version clients send with that of the object, but:
- the first layout version of an object can come from a client RPC,
  so clients cannot send the version of a non-FLR layout: a client
  flushing pages cached before another client instantiated a
  component would then be refused;
- "lfs mirror split" that leaves a file not mirrored keeps a write
  era that an interrupted resync closed on its objects.

Only record the first layout version of an object from the MDT or a
resync write in ofd_object_ff_update() and ofd_object_fallocate().  Make
mdd_xattr_split() send the new layout version to the objects of a file
that is no longer mirrored.  This prepares for clients to send a layout
version with every modifying RPC, and for OSTs to refuse unversioned
ones there.
