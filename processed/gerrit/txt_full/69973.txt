LU-20913 utils: Add -r to lfs pool pin/unpin/pin_info

The `lfs pool pin`, `lfs pool unpin` and `lfs pool pin_info`
commands only act on the paths given on the command line, so
pinning a tree means scripting find.

Add -r/--recursive, which walks each path with llapi_find_with_cb()
and applies the operation to every regular file and directory, so
symlinks, FIFOs, sockets and device nodes are skipped. -r requires
--pool or --not-pool and cannot be combined with --fid. Under -r,
an entry with nothing to unpin does not affect the exit status,
since a walk meets hard links and entries that were never pinned.
The per-target open/act code is shared by the three commands.

Update the man pages and add sanity test 157g.
