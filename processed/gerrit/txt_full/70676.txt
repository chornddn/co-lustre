LU-21175 build: fix specfile with doca 3.2

rpmbuild failed to build lustre with doca 3.2:

```
$ rpmbuild -ba --with=mofed SPECS/lustre.spec
...
++ find -H /usr/src/ofa_kernel/ -type d -name ofed_scripts
++ xargs dirname
dirname: missing operand
Try 'dirname --help' for more information.
+ o2ib_path=
error: Bad exit status from /var/tmp/rpm-tmp.PbAd2W (%build)

RPM build errors:
    Bad exit status from /var/tmp/rpm-tmp.PbAd2W (%build)
```

Doca relies on dkms for building and uses symbolic links to point to
the build directories in ofa_kernel/default and
ofa_kernel/x86/<kernel>. As a result, find -H returns nothing under
/usr/src/ofa_kernel.

Look for the OFED devel directory (one containing Module.symvers)
under %{mofed_default_path}, in this order:
 1. the path itself, when --with-o2ib=<path> was passed:
    e.g: ~/mofed_build/ofa_kernel
 2. the exact kernel being built:
    e.g: /usr/src/ofa_kernel/x86_64/6.12.0-211.66.1.el10_2.x86_64
 3. the default directory (alternatives(8) symlink):
    e.g: /usr/src/ofa_kernel/default
 4. the remaining per-kernel directories, newest version first:
    e.g: /usr/src/ofa_kernel/x86_64/6.12.0-211.66.1.el10_2.x86_64
         /usr/src/ofa_kernel/x86_64/6.12.0-211.52.1.el10_2.x86_64
