LU-21284 osd-ldiskfs: validate agents before cleanup

Deferred agent cleanup trusted the inode number from a directory
entry and cleared its link count if its current FID was remote. A
stale entry could therefore delete an unrelated remote agent after
inode reuse.

Save the entry FID and require a matching LMA with LMAI_AGENT before
cleanup.  Preserve the existing behavior for entries without
dirdata.

Add sanity/803c to inject a mismatched cleanup candidate for
rm_entry, rm, and rmdir.  Check the agent's link count and
allocation, and verify that a later unlink of its own name still
frees it.  Detect the injection hook at runtime so backports do not
need a version guard.

Local syntax and checkpatch checks passed.  Kernel build and fixed
and unfixed runtime validation are pending.
