LU-20779 revert: "llite: Remove the 2.17.58 timebomb"

This reverts commit 461c24974158f7042bf96ca7db6cc38709e5b672.

This is causing sanity test_160a to failed with old servers:
mkdir parent '/mnt/lustre/d160a.sanity/pics/2008' failed

Before commit 668dfb53de8c3ccb9f17ba93a449eb454cf17899 ("LU-13577 wbc:
reimplement mkdir() by using intent lock"), default LMV was not
embedded inside the REINT_CREATE RPC reply. As a result, if a client
attempted to directly create a directory, it could inadvertently
select the wrong MDT (DNEv3).

Reproducer:

[root@client lustre]# lfs mkdir -i0 -c1 test; mkdir -p test/pics/2008
mkdir: cannot create directory "test/pics/2008": Object is remote
