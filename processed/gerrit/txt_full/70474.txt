LU-21060 obdclass: limit client job stats memory

- Client job records are freed only by expiry or removal.  With many
  job IDs they can use much memory on a client node.
- Add client_jobstats_max_memory, a node-wide limit for retained
  client records: bytes, units or percent of RAM, 64 MiB by default.
  client_jobstats_memory shows the reserved bytes.
- Reserve a conservative size before each allocation.  Client records
  use preallocated counters, so a later update cannot fail.
- Count rejected updates in osc.*.job_stats_dropped and
  mdc.*.job_stats_dropped.  A rejected update never fails the I/O.
- Free the records of removed jobs from a work item, so the limit
  recovers without more I/O on the device.
- Built on LU-21123 for percent parsing.
- Add man pages and sanity tests 205y, 205A, 205B and 205C.
