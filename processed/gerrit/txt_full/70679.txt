DRAFT LU-21180 kunit: add shared mock_ost local dt_object/thandle helpers

Add mock_ost.ko, a KUnit helper module providing a mock local
dt_object (as returned by dt_object_child()) with canned
do_xattr_get() replies and a do_declare_xattr_set() call counter,
plus a trivial thandle (th_top == NULL) that short-circuits
lod_sub_get_thandle(). This lets kunit tests for lod functions that
read/declare an xattr on the next object layer run against a loaded
lod.ko without a real OSD underneath, without each test reimplementing
its own fake object/transaction.

No test consumes it yet; later test commits depend on mock_ost.ko.
