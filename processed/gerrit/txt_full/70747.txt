LU-11628 lfsck: give OST objects a missing parent FID

Layout LFSCK checks the parent FID (trusted.fid) of each OST object
a layout references, but takes an object that has none as consistent.
Objects that were never written have none, unless the MDT that
created them sent it, so lfs fid2path cannot map them and a scan of
the OST cannot tell which file they belong to.

Repair such an object as an unmatched pair: set its parent FID, with
the stripe index and component, and its owner, from the MDT-object
that references it.  It is counted in repaired_unmatched_pair.

Add sanity-lfsck test 15e.
