LU-20869 tests: shorten sanity-quota test_3a and test_3b

test_3a and test_3b each run test_block_soft() for the user,
group and project quota types. Every cycle waits out the block
grace time (20s on ldiskfs, 60s on ZFS, plus 5s) and runs
several wait_delete_completed and syncs, so each test spends
about 50s per quota type on ldiskfs and about 125s on ZFS.

Run the group type only with SLOW=yes. User and project quotas
still run by default, and the group quota code shares the same
soft limit and grace handling.

On a rocky9 ldiskfs test VM, ONLY="3a 3b" took 146s and 147s
for test_3a, 153s and 154s for test_3b before, and 99s and 102s
for test_3a, 106s and 107s for test_3b after; with SLOW=yes the
times are unchanged (149s and 154s). Expected CI saving, using
CI means of 322s (3a) and 336s (3b) over about 7100 runs each
per 30 days and about 47s per run on ldiskfs (measured) and
about 123s per run on ZFS (estimated, about 3700 runs): roughly
340 hours per 30 days across both tests.

Test-Parameters: trivial testlist=sanity-quota env=ONLY="3a 3b"
