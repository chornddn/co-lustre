--- Commit Message ---
LU-20758 tests: relax sanity/63c OST_SYNC upper bound

sanity/63c writes a fully striped file and verifies that sync_on_close
issues at least one OST_SYNC per stripe. The current test also caps
the count below 2 * stripes, but background or reclaim writeback can
issue additional OST_SYNC RPCs while dd is still writing, so
2 * stripes is not a hard upper bound.

Change the assertion to check only the lower bound, and make the error
message print that bound instead of an equality. The test remains a
lower-bound smoke check for the sync_on_close path; it no longer fails
on valid additional background writeback.
