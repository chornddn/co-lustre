--- Commit Message ---
LU-20534 swap: Add single-stripe swap infrastructure

Extend the swap_layouts infrastructure to support swapping a single
stripe between two file layouts, enabling per-stripe migration without
requiring full layout swaps. This will be the foundation for the lfs
replace_stripe command.

The implementation preserves all existing swap_layouts functionality
while adding support for surgical single-stripe replacement. Backward
compatibility is maintained with old clients that send smaller RPC
messages without the new fields.
