--- Commit Message ---
LU-20923 ptlrpc: return the error when a reply cannot be sent

ptl_send_buf() treated any LNetMDBind() failure as a transient
out-of-memory and assumed that the error was -ENOMEM.  LNetMDBind()
could return other errors as well.  Return the actual error code.
