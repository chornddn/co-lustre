DRAFT LU-21180 utils: add kunit test for ec_split_stripes

Add lustre/kunit/ec_split_test.c for ec_split_stripes(), a pure
static inline helper in lustre_user.h that splits a stripe count into
one or two equally-sized bucket sets for EC data/parity grouping.
Covers totals below EC_MIN_SPLIT_SIZE, evenly divisible totals (with
and without an extra bucket needed), the general two-bucket-size case
(including the 15/7 example from the function's doc comment), and a
suggested size of 1, each checking the invariant esc_k0 * esc_n0 +
esc_k1 * esc_n1 == total.

Run from sanity test_51m, loading kunit on the MDS with enable=1.
