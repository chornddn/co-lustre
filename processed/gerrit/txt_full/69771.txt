LU-11962 lod: prepare for a SOM mirror in FLR files

Strict Size-on-MDT of files that are not mirrored will use a mirror
made of a single data-less foreign HSM component flagged HS_SOM, so
that clients send a layout write intent before they modify the file.
Prepare servers and utilities to handle files with such a mirror:

- move the code that appends an HSM mirror to a layout out of
  lod_declare_pccro_set() into lod_layout_add_hsm_mirror();
- define HS_SOM, shown as "som" by "lfs getstripe";
- clear the stale flag of a SOM component at RESYNC_DONE, as it has
  no data to resync, and accept its ID in the list of resynced ones;
- copy no data into a SOM mirror in llapi_mirror_resync_many(), and
  read from no foreign mirror in llapi_mirror_find(), so "lfs mirror
  resync" makes such a file RDONLY again;
- do not reuse a SOM mirror as the HSM mirror of PCC-RO.
