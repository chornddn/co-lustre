--- Commit Message ---
LU-19804 quota: enforce projquota on PROJINHERIT rename

When renaming a file into a directory with the project inherit flag,
it will inherit the new project ID, then the project quota should be
enforced on this project ID.

This patch reserves the quota space before the rename and release it
after the rename completes.

The object size is difficult to get on MDT, then the client sends
the size/blocks into the rename request so the MDT has the accurate
value for reserving quota.

The test_99 is added in sanity-quota.
