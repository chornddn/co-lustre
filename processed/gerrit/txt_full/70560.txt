LU-19431 tests: except sanity-pcc/40 for older clients

sanity-pcc test_40 would fail on 2.16 clients with "Total time for
async open attach should be smaller".  On these clients the open
attach of the 50MB file with O_DIRECT fails with -EFAULT, because
the hybrid I/O switch makes the data copy into the PCC file use
direct I/O on a kernel buffer, so the 1G threshold read is served
from the OSTs and is faster than the background attach.  This was
fixed in the client for 2.17.0 by commit 0bff4700a977 ("LU-19092
pcc: avoid hybrid I/O switch for PCC data copy"), and newer
clients pass the test against any server.

Add sanity-pcc.lu19431.ex to skip test_40 on clients before 2.17.0.

Also add the llite.pcc_async_threshold(4) man page.
