LU-20896 utils: no unaligned DIO for encrypted file copies

With the key loaded, "lfs migrate" and "lfs mirror verify" of an
encrypted file would fail with -EINVAL on a client with pages larger
than the 4KiB encryption unit, if the OSTs did not support unaligned
direct IO, e.g. 2.15 servers.  The ciphertext of the file ends at the
end of an encryption unit, so migrate's last direct write was not a
whole page, and verify read up to the end of that unit.

Round the last direct write of an encrypted file in migrate up to a
page, as llapi_mirror_copy() does, since the size of the volatile file
is set from the file afterward.  Round the reads of verify up to a
page, since the read stops at the end of the last encryption unit.

Run migrate and verify in sanity-sec test_66c with unaligned DIO
turned off, for any page size.
