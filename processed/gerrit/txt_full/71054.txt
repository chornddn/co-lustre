--- Commit Message ---
LU-18317 libcfs: parse IPv6 o2ib NIDs in userspace

The kernel gained support for IPv6 addresses on o2ib NIDs in commit
22667e91b1 ("LU-18317 lnet: fix configure o2ib NID with IPv6
address") by adding the size-aware nf_addr2str_size and
nf_str2addr_size parsers to the O2IBLND netstrfns entry.  The
userspace copy of the same table was not updated, so mount.lustre
still rejects an IPv6 o2ib NID that the kernel accepts:

  mount.lustre: Unsupported NID '6699:7654::1234:1234:d84@o2ib'
  mount.lustre: Can't parse NID '6699:7654::1234:1234:d84@o2ib'

libcfs_strnid() falls back to the 32-bit nf_str2addr (IPv4 only) when
nf_str2addr_size is absent, which is why tcp parses IPv6 NIDs but o2ib
does not.  Add the same two fields to the userspace O2IBLND entry so
mount.lustre parses IPv6@o2ib NIDs like the kernel does.
