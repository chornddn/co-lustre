--- Commit Message ---
LU-21060 mdc: add MDC job statistics

- Add mdc.*.enable_job_stats, mdc.*.job_stats and
  mdc.*.job_cleanup_interval, with the same rules as on the OSC.
- Count metadata operations with the counter names of mdt.*.job_stats,
  plus the client-only layout, swap_layouts and rmfid.  A lookup
  intent counts as getattr only when the name was found, and an open
  that creates a file also counts as mknod.
- Count Data-on-MDT bytes and latency with the OSC BRW counters.
- Count each decoded, successful positive lookup of a batched getattr,
  also when a later subrequest fails.  All of them share one batch
  latency sample.
- Add man pages and sanity tests 205o, 205s, 205u and 205w.  Extend
  205r and the test helpers to the MDC.
