LU-20869 tests: speed up conf-sanity test_73e

test_73e adds 41 LNet networks on each remote server node, one
do_rpc_nodes call per network. Every call re-sources the test
framework on the remote node, so each add took about 2 to 3
seconds and the nodes were handled one after another.

Run the 41 adds from a single do_node loop per node, and run the
nodes in parallel. All 41 networks are still added on every node.

On a VM with one MDS and one OSS the test takes 99s, 91s, 92s
and 90s (one run took 259s from slow cleanup unrelated to the
loop), against 183s, 174s and 171s before. CI has more remote
nodes and runs the test about 4117 times per 30 days at a mean
of 715s, so the saving there is larger.
