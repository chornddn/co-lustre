--- Commit Message ---
LU-19921 nodemap: migrate inactive exports to default nodemap

During nodemap export reclassification, if an export does not have
an active connection, we previously simply skipped it because we
rely on reconnect to reclassify it later. However, this left the
export attached to the old nodemap configuration's member list,
which prevented the old configuration and its associated nodemaps
from ever being released.

Fix this by moving exports without active connections to the
default nodemap of the active configuration. This safely frees
the old configuration while still allowing subsequent reconnects
to properly reclassify the export.

Additionally, improve reference counting safety in
__nodemap_member_switch() by having it acquire a reference on
the new nodemap and release the reference on the old nodemap.
This avoids caller-side reference handover bugs.

Fixes: fb7915fa7fb0 ("LU-19079 sec: update nodemap membership on flavor change")
