--- Commit Message ---
LU-20690 tests: skip EC create llapi tests in 27D interop

llapi_layout_test test55 and test60 create EC files, which are now
stored as LOV_PATTERN_PARITY. A pre-v2_17_52-42-gf1b7ae0cc6 MDS
does not support that pattern, so file creation fails with EINVAL
and sanity test_27D fails against b2_15 and b2_16 servers.

Skip test55 and test60 with such a server, as is already done for
the other llapi tests that create EC files.

Test-Parameters: trivial testlist=sanity env=ONLY=27D serverversion=2.16
