--- Commit Message ---
LU-19672 osp: batch object destroy over OUT protocol

Replace the OSP llog sync path's per-record OST_DESTROY RPCs with
batched OUT_UPDATE RPCs, so MDT->OST unlink processing no longer
costs one round-trip per object. Only destroy records are
batched (idempotent, safe to reorder/replay); a destroy is packed
as OUT_REF_DEL + OUT_DESTROY, as ofd_destroy_by_fid() does.

Add UPDATE_FL_TOLERATE_ENOENT so the target records -ENOENT for a
sub-update instead of aborting the batch. OBD_CONNECT2_BATCH_DESTROY
advertises target support; osp_sync_process_record() accumulates
destroys into one osp_update_request, flushed at
sync_max_records_per_rpc records or sync_batch_max_age_ms.

New tunables: sync_max_records_per_rpc (0 disables batching),
sync_batch_max_age_ms.
