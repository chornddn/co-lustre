--- Commit Message ---
LU-21061 lmv: count only pool MDTs in pool quota usage

"lfs quota --pool" sums the block usage of the OSTs of a pool, but
the inode and DoM usage of every MDT, so a pool with inode limits
reports usage that it does not limit.

Pass the pool to lmv_quotactl(), which then sums only the MDTs of
the pool if it lists any.  A pool without MDTs still reports the
usage of all MDTs.  Also list the MDTs of the pool in
"lfs quota -v --pool".
