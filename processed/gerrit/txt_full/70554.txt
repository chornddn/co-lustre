--- Commit Message ---
LU-21079 mdd: clear orphan changelog record at user endrec

Changelog records up to and including a user's endrec are purgeable,
but the mount time orphan check only treats a first record strictly
below the smallest user endrec as an orphan. If a GC thread purge is
interrupted by umount after it removed all but the record at endrec,
that record is never cleaned up at the next mount.

Treat a first record equal to the smallest user endrec as an orphan
as well. An empty changelog must still be skipped explicitly.
