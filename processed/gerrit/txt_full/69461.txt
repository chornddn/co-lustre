--- Commit Message ---
LU-20882 scripts: avoid commit-msg temp file leak

The commit-msg hook created its temporary message file before
opening the input, so a missing or unreadable message file, or
no argument, left a stray "<name>.XXXXXX" file behind.

Open the input first and create the temporary file only once
it is known to be readable.
