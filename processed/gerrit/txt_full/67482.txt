--- Commit Message ---
LU-20354 qmt: add per-slave quota usage cache for GETQUOTA

Let QMT serve aggregated quota usage from an in-memory per-slave
cache instead of always returning zero and forcing clients to fan
out to every OST/MDT. Warm the cache from QSD DQACQ/REL piggybacked
qb_usage, and refresh stale/missing entries via OSP quotactl proxied
through MDT. If a per-slave usage fetch fails, fall back to granted
from that slave's local index file so other slaves' usage remains
usable. When the aggregated usage cannot be obtained, keep legacy
client behavior by omitting QIF_SPACE/QIF_INODES.
