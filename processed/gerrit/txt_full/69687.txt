LU-18502 utils: indent a multi-line value for get_param -y

With --yaml, "lctl get_param" prints the first line of a multi-line
value on the line of the parameter name. When the value is a block
mapping, a YAML parser rejects the output. A block mapping cannot
start on the line of its key. For example, nodemap.*.enable_cap_mask
with a cap type other than "off" prints "type: ..." and "caps: ..."
on two lines.

In print_param_internal(), start a multi-line value on the next line.
Indent each line of the value by two spaces. A parser then reads the
lines as the value of the parameter name.
