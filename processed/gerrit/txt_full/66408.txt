LU-19125 lfs: add multithreading to lfs project command

Add parallel directory traversal support to the 'lfs project'
command and refactor the implementation to create a reusable
library API.

- Replace custom linked-list directory traversal with
  llapi_find_with_cb().
- Auto-calculate thread count based on MDT count and CPU count.
- Add -j/--threads option to command.

Threading behavior:
  lfs project /dir          -> 1 thread (non-recursive)
  lfs project -r /dir       -> auto-calculated
  lfs project -j 8 -r /dir  -> 8 threads (user override)
