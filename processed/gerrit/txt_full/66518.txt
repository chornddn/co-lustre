--- Commit Message ---
LU-20337 tests: fix obdfilter-survey to parse IPv6

obdfilter-survey uses a `:` delimiter to parse `host:device`. When
the host is an IPv6 address, which contains multiple embedded `:`,
the parsing fails. The fix is to split the string on the last `:`.
