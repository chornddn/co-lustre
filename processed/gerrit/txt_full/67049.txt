LU-20290 lnet: refactor discovery visibility framework

Refactor the discovery visibility policy framework to separate policy
evaluation from visibility set composition.

Each visibility policy contributes one or more visibility sets, while
the core is responsible only for composing the sets produced by the
active policies. This establishes a generic framework for supporting
multiple independent visibility policies without changing the current
discovery behavior.

Add a D_NET message where the composition permits or refuses the full
view for a Push. The message gives the name of the policy that
refuses. It helps you to find the cause of a Push that the core
stops.

No functional changes.
