--- Commit Message ---
LU-20076 tests: find LUSTRE from test-framework.sh path

If test-framework.sh was sourced from an interactive shell or a
script outside lustre/tests without LUSTRE set, LUSTRE would be
derived from "$0" and point at the wrong directory, so sourcing
functions.sh failed and the shell exited.

Derive the default LUSTRE from ${BASH_SOURCE[0]}, the location of
test-framework.sh itself, which is the same as "$0" for the test
scripts in lustre/tests.
