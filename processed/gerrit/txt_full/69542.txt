LU-14301 obdclass: return -ENOTTY for missing o_iocontrol

When an obd device type has no o_iocontrol method, obd_iocontrol()
returns -ENOTSUPP. This is a kernel-internal errno (524), which is
not defined in userspace errno.h. But it is passed unchanged by
class_handle_ioctl() to userspace, for an ioctl on /dev/obd that
targets such a device, e.g. an OSD or an MGC. Userspace tools then
get "Unknown error 524".

Return -ENOTTY instead, which is the errno for an ioctl that does
not apply to the target object, as returned by the o_iocontrol
methods for an unrecognized command.
