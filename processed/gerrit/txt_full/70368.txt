--- Commit Message ---
LU-21107 build: remove kernel objects in make clean

make clean should remove kernel object files. Previously, it did via
the MOSTLYCLEANFILES variable. However, when that variable was
removed, nothing was left that cleaned up the kernel modules. This
cleans them up by delegating to the Kbuild clean target.

The new target runs for make clean, distclean, and maintainer-clean.
