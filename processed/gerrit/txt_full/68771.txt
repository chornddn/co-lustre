LU-20714 llite: read foreign symlink prefix under lock

ll_show_options() prints sbi->ll_foreign_symlink_prefix without
holding ll_foreign_symlink_sem, while foreign_symlink_prefix_store()
swaps in a new prefix under the write lock and frees the old buffer.
Nothing keeps the pointer this reader sampled alive, so any
unprivileged read of /proc/mounts or /proc/self/mountinfo racing a
root write of the foreign_symlink_prefix parameter can print freed
memory.

Take the semaphore for read around the access, as
foreign_symlink_prefix_show() already does. ll_options() swaps the
same field unlocked, but runs before the super block is in a mount
namespace or the sysfs files exist, so it has no concurrent reader.
