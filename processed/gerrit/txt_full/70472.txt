LU-21060 obdclass: separate jobstats engine from obd_device

- The jobstats engine works only for MDT and OST devices.  Its API
  takes an obd_device and uses obt_jobstats, and lprocfs_jobstats.c
  is built only with server support.  A client device cannot use it.
- Move the engine API to struct obd_job_stats:
  lprocfs_jobstats_init(), lprocfs_jobstats_log(),
  lprocfs_jobstats_fini() and the job_cleanup_interval helpers.  The
  stats keep the owner name for messages.
- Keep lprocfs_job_stats_init(), _log() and _fini() as server
  wrappers.  MDT and OST callers and the job_stats output do not
  change.
- Build lprocfs_jobstats.c without server support as well.
- Split job lookup out of the logging path, reject a negative counter
  index, copy the job ID with strscpy() and remove the unused
  ojs_readers.
- Carry the engine fixes of the open reviews 68602 (LU-17000) and
  69763 (LU-20984) by Oleg Drokin until they land: clear js_posnode in
  job_alloc(), handle every job_insert() error and wake the
  OJS_CLEANING waiters.
