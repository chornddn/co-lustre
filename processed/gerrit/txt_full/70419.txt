LU-21122 lod: allow PFID updates when an OST is full

After a successful layout merge, split or swap,
lod_trans_space_check() can reject PFID updates on a full OST,
leaving the parent FID or component ID inconsistent with the
MDT layout.  The same check also rejects MDT migration of files
with objects on full OSTs.

Set th_skip_space_check on OST sub-transactions in LOD, which
only replace PFID xattrs.  Keep the space checks for remote MDTs
and retain backend allocation errors.

Expose mdd.*.pfid_update_attempts, mdd.*.pfid_update_failures and
mdd.*.pfid_update_enospc for updates after layout changes, and log
failures, including errors returned by mdd_trans_stop().

Add sanity-flr/71b and 71c to check mirror extension and MDT
migration on a full OST, verifying the on-disk PFID and checking
counters for mirror extension.  Also fix hexadecimal FID parsing
in ost_fid2_objpath().
