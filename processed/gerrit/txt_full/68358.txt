--- Commit Message ---
LU-9680 utils: handle very large netlink message in liblnetconfig

A few scaling patches have exposed a problem in the liblnetconfig
library when recieving message from kernel space. We would double
the current internal library buffer to recieve the message but
the next messsage can be way bigger than that. Examine the new
message size to determine how much to increase the buffer by.
