LU-20388 pcc: fix test_2b failure due to write from the same node

In sanity-pcc/test_2b, "SINGLEAGT" and "remote_client" may be the
same client node.
This may result in the test failure as the write from the same
Lustre mount on the same node will not invalidate the PCC-RW
cache.
However, the test thought that the PCC-RW cached file will be
invalidated by the write from this fake "remote_client".

There is no need to use remote client to write the file, just use
another mount point on the same node is enough.
This patch fixes the above error accordingly.
