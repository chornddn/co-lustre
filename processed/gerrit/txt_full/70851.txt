--- Commit Message ---
DRAFT LU-21180 lod: add kunit test for OST/OSS avoidance helpers

Add KUnit coverage for the OST/OSS avoidance helpers in lod_qos.c
used while allocating a mirror (FLR) or EC component's stripes to
spread them away from servers/targets already used by a conflicting
component in another mirror: lod_comp_is_ost_used(),
lod_avoid_update(), lod_oss_avoid_some(), lod_oss_avoided(),
lod_fdom_tgt_skip() and lod_should_avoid_ost().

These helpers were static; export them for the new test module and
add an entry-side canary assertion in lod_avoid_test_init() so that
if the exit-side avoidance-array reset is ever broken, the next test
case fails loudly instead of silently inheriting a dangling pointer.
