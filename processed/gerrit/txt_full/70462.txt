LU-19566 lfsck: clear the header of a rebuilt LOV EA

When LFSCK rebuilds a composite LOV EA for an orphan OST object
in lfsck_layout_new_comp_lovea(), the buffer holds the crashed
LOV EA being replaced or, when creating the LOV EA, whatever
lti_big_buf last held (linkEA, LMV).  Only some of the
lov_comp_md_v1 header fields were set, so lcm_ec_count and the
padding fields kept those bytes, and without a layout version
from the OST, lcm_layout_gen was incremented from them as well.

Clear the whole header and the first entry before filling them.
Keep lcm_layout_gen only when replacing an existing LOV EA.
