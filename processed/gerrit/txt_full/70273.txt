--- Commit Message ---
LU-20565 tests: use EC_* layouts in sanity-ec extend tests

sanity-ec subtests 8a-8c and 8e-8l (lfs mirror extend --ec) hard-coded
an EC 4+2 layout on 4-stripe data mirrors with a gate of 6 OSTs,
although each tests a mirror extend rule, not the geometry.  They
would be skipped on the 4 OST test sessions.

Use the EC_ARG, EC_DSTRIPE and EC_CSTRIPE defaults that enable_ec()
scales to OSTCOUNT, and EC_DSTRIPE data stripes, so they run with 3
OSTs.  Put each PFL boundary in front of an EC component on a
multiple of the row width.

Test-Parameters: trivial testlist=sanity-ec
Test-Parameters: testlist=sanity-ec ostcount=4
