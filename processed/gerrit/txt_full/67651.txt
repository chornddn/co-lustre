LU-20541 lfs: Implement migrate_stripe command and add test

Add lfs migrate_stripe to move one OST object of a file onto another
OST using a single-stripe volatile partner and llapi_swap_stripe().

Copy follows absolute LOV stripe numbering and object offsets, keeps
holes sparse, and ftruncates the volatile so trailing holes still
carry file size without SOM. Match source uid/gid on the volatile for
mdd_swap_layouts(). Default path is optimistic (DV check at swap);
--lock-copy holds a group lock across copy and swap.

Document in lfs-migrate_stripe.1. sanity-ec 35b-35g cover content,
holes, PFL offsets, size, absolute striping, and root on user files.
