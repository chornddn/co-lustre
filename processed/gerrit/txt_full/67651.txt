LU-20541 lfs: Implement migrate_stripe command and add test

Implement lfs migrate_stripe to move a single stripe of a file to a
different OST without migrating the whole file.

There are several potential use-cases for this:
- repairing EC or FLR data stripes when they become unavailable.
- opportunistically evacuating from an OST before a planned maintenance
  (this also works for redundacny-unprotected non-EC and non-FLR files)
- rebalancing OST used capacity.
...

We do not yet support recompute and replace of EC parity stripes.
That is for later.

- Create a volatile file with one stripe on the target OST
- Copy stripe data (skip full and partial holes; O_DIRECT aligned)
- Atomic swap via llapi_swap_stripe() using OST object FIDs
- Optimistic (default) or locked (--lock-copy) strategies with DV check

Add sanity-ec tests 35b/35c for content and hole preservation.
