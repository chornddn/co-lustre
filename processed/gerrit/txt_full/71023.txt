--- Commit Message ---
LU-21236 obdclass: use OBD macros for DIO page arrays

Allocate and free the DIO page number array, and the folio
array of the unaligned DIO bounce buffer, with the OBD
macros, so they are counted in Lustre memory use. Record
the page number array size, since the aligned path
allocates it before it knows the page count.

The user page array stays on kvfree(), since the kernel
allocates it.
