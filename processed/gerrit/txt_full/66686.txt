--- Commit Message ---
LU-20385 osd-zfs: use object id directly instead of zc_zapobj

Replace references to it->ozi_zc->zc_zapobj with the directory object
id in osd_dir_it_rec() (via it->ozi_obj->oo_dn->dn_object) and in
osd_scan_dir() (via the id parameter).

Sourcing the id from the object rather than the cursor is a no-op
change. A ZAP is a single DMU object and the cursor's zc_zapobj
is always set to the same directory object the cursor was opened
on (dn_object / the id parameter).

ZFS commit efda1093ffa8 ("zap: add zap_cursor_init_by_dnode() & rework cursor resource lifetime")
deprecates this field. Lustre is the only remaining caller.
