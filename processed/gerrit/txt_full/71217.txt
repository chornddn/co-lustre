LU-21262 kernel: update RHEL 9.8 [5.14.0-687.66.1.el9_8]

Update RHEL 9.8 kernel to 5.14.0-687.66.1.el9_8.

The RHEL 9.8 kernel source and debuginfo RPMs are not on
mirror.stream.centos.org, so lbuild fails to download them.
Fetch them from the Rocky Linux 9.8 vault in lbuild-rhel9.

The Rocky kernel spec reads the DUP, kpatch, NVIDIA and IMA
certificates from the rocky-sb-certs package on the build host,
which lbuild does not install, so %prep fails with:
  Could not open file or uri for loading certificate from
  /usr/share/pki/sb-certs/kernel-dup1-x86_64.der
Add unpack_rocky_sb_certs() to download rocky-sb-certs, copy the
certificates into SOURCES, add a Source line for each so they are
also packaged in the kernel SRPM, and point the spec at that copy.
