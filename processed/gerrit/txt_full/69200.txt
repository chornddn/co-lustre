--- Commit Message ---
LU-6689 nodemap: refuse migrate early without layout_ops

Without the 'layout_ops' rbac role, 'lfs migrate' to another layout
and 'lfs mirror extend' are only refused on the final layout swap or
merge, once the file data has been copied into the volatile file they
work with, which means this whole copy is done for nothing.

To avoid this, make the client send the FID in the open intent and let
the MDT refuse right away a layout that is not the layout of the
original file. This is gated by the OBD_CONNECT2_MIGRATE_SRC connect
flag, so an older client or server simply keeps the late refusal.

Add sanity-sec test_64n.
