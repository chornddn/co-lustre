LU-19540 lnet: hash all bits of the NID in nidhash()

nidhash() only XORs the network and the address words of a NID, and
on little-endian hosts the last octet of an IPv4 address lands in the
top byte.  With a power-of-two number of MDTs, every client on a
subnet then gets the same lmv_qos_rr_index and lmv_statfs_start, so
they all start round-robin mkdir and statfs on the same MDT.

Hash the NID with jhash() in nidhash(), so that every bit of the
result depends on the whole NID, and use it in lnet_nid2peerhash() and
lnet_nid_cpt_hash() instead of their own hash_32() chains.  Return
u32, since the hash never had more than 32 bits, and use u32 for the
hash table keys of the socklnd and o2iblnd peer lookups, so that they
hash the key as hash_add() does.  Use the low bits of nidhash() for
the peer table hash, since lnet_nid_cpt_hash() picks the table of a
large NID with the high bits.  Move nidhash() from the uapi header to
lib-lnet.h, since only kernel code uses it.

Keep the XOR order for the o2iblnd connection race tie-break in
kiblnd_nid_race_key(), since both peers must agree on it.
