LU-21247 lnet: log NI address removal on console

When the IP address of an NI is removed while LNet runs, ksocklnd
and ko2iblnd mark the NI down and only log it under D_NET. If the
address was moved to another host, the peers then get o2ib rejects
logged as "consumer defined fatal error", which looks like a
hardware fault.

Change the NI state only on events for the NI address, as before
LU-17460 and LU-17743 dropped that check. Print on the console when
the address is removed and when it is restored.

In kiblnd_rejected(), report an all-zero reject payload as coming
from the remote RDMA CM, with its likely causes.

Add sanity-lnet test_307 (socklnd) and test_308 (o2iblnd).

Fixes: e5903f8b5319 ("LU-17460 lnet: support IPv6 for link state")
Fixes: 9b18afabaf22 ("LU-17743 ko2iblnd: move to struct lnet_nid")
