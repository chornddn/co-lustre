LU-21228 lfs: find --report

Add --report to lfs find, so that a search can describe a filesystem
as well as list it: a YAML document in the style of job_stats, with
histograms of size, space and age, and the largest directories.

--report[=FILE] is an action, as -fprint is in find(1): the report
goes to FILE, to a file under /var/log/lustre, or with --report=- to
stdout.  A target scan reports what it read and what the options
matched.

A file without strict size-on-MDT takes its size and space from the
lazy size-on-MDT.  The report prints totals, so a slightly stale LSOM
is good enough, and no OST needs to be read.

A walk stats each size the MDT did not give, or takes the lazy size
with --lazy.  --report-memory limits the report's tables, --no-report
cancels --report, and --report-format names the format (yaml).  With
--fid2path a report-only search names directories through the mount.
A report covers one filesystem, since its tables are keyed by FID.

Programs get the same report from llapi_find_report(), and note a
target they skipped with llapi_find_report_note().
