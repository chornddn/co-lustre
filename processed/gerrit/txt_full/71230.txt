--- Commit Message ---
LU-21271 tests: replay-single/70f to enable writeback cache

this is needed to workaround data mismatch problem: replay_barrier()
turns OST read-only (which means dropping all writes), but then the
client reads data back.

this is a problem on ldiskfs only as ZFS doesn't drop writes, instead
it rollbacks to per-RO state.

the workaround is to enable writeback cache on OST when ldiskfs is
used, so reads can be served from the cache.
