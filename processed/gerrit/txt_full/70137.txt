--- Commit Message ---
LU-21059 tests: do not chain the script EXIT trap in a test

A stack_trap EXIT in a test also runs the EXIT trap of the test
script when the test ends.  Thus large-lun test_2 and test_5 run
cleanupall.  In sanity-lnet, a test trap runs cleanup_testsuite.  If
the suite starts with Lustre mounted, cleanup_testsuite calls
setupall, and the later tests fail.

run_one runs each test in a subshell.  The subshell does not run the
EXIT trap of the script.  But "trap -p" in the subshell still prints
that trap.  Then stack_trap reads the output and adds the script trap
to the test trap.

Clear the EXIT trap at the start of run_one.  Add sanity-lnet test_30
to check that a test EXIT trap holds only the test commands.
