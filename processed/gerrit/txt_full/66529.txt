--- Commit Message ---
LU-19917 mgc: dynamic MGS nids discovery

. enable fault tolerant MGS, client can connect to any server as MGS
. MGS nid list can be specified in client mount command, and they
  will be shuffled to balance load, the benefit of MGS nid list is
  that the system startup time is reduced for large clusters, and the
  MGS load is balanced among all servers.
. imperative recovery log process adds all server nids to client
  MGC import dynamically, so that user can start using fault tolerant
  MGS without any configuration.
. client MGC name should be different from server MGC, because server
  MGC only connects to primary MGS, rename it to "MGCCL+nid".
. shorten MGC ping interval to
  max(PING_INTERVAL_SHORT, obd_timeout/20) so that client switches
  MGS in time to avoid missing IR update.
. add sanity.sh test_399c
