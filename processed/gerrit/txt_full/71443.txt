LU-21327 rustreapi: add a safe data version API

rustreapi cannot read a file's data version, which an S3 gateway needs
on every request to tell whether a file changed under it, so the call
must cost no more than the ioctl itself.

Add data_version(), which takes a BorrowedFd and DataVersionFlags
(ReadFlush, WriteFlush) and makes a single LL_IOC_DATA_VERSION ioctl
with no open, stat or allocation.  DataVersionError separates a
descriptor that is not a regular file on Lustre (ENOTTY) and one
opened O_PATH (EBADF) from other errnos.

LL_DV_SZ_UPDATE is left out: the client masks it off this ioctl, so it
has never had an effect from user space.
