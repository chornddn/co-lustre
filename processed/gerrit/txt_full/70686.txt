DRAFT LU-21180 kunit: add optional gcov coverage to ku

Add support to measure test coverage.

-g requires CONFIG_GCOV_KERNEL, debugfs mounted, root, and the gcov
and gcov-tool binaries from the matching gcc; it is off by default
since not every test setup has that kernel config.

ku resets the kernel's gcov counters before each module is inserted,
and after the test run (before rmmod, since counters vanish then)
copies the .gcda files out of debugfs next to the matching .gcno/.c,
merging them (summing counts) into $KU_GCOV_DIR/_merged across every
module the run selects. It then prints one aggregated summary filtered
to the .c files that triggered a module (headers are skipped, but
still available in the full annotated output under $KU_GCOV_DIR), and
under each file also the per-function coverage for just the functions
that the diff touched (matched via git diff hunk headers), so the
summary line stays short even on files the diff barely touches.

By default only the directories of the changed/triggering files are
collected, which is quick; -f additionally pulls in every dependency
.ko's directory for a complete report, but is much slower. The
gcov-tool merge step itself is skipped whenever there is nothing to
sum yet, the common case of running on a single uncommitted change.

Example, after changing lod_qos_calc_rr() in lustre/lod/lod_qos.c:

  $ lustre/kunit/ku -g
  ...
  --- ku: aggregated gcov summary (changed files only) ---
      lustre/lod/lod_qos.c                     0.00% of 1912
          lod_qos_calc_rr()                    0.00% of 74
  ku: -g: full report (all files) saved under /tmp/ku-gcov/_merged
  ku: all selected kunit modules passed

$KU_GCOV_DIR/_merged keeps the merged .gcda counters and matching
.gcno files for every file gcov touched, not just the ones in the
printed summary, so it's still there after ku exits for a closer
look than the one-line-per-file/function summary gives, e.g. a full
annotated per-line listing:

  $ cd /tmp/ku-gcov/_merged/lustre/lod
  $ gcov -b -c lod_qos.c
  $ less lod_qos.c.gcov
