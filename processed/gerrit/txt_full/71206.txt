--- Commit Message ---
LU-21254 target: undo the first update of a failed replay

distribute_txn_replay_handle() undoes the executed updates when one
update of a replay fails.  The undo loop stops before index 0, so
the first update stays applied.  If that update is the last ref_del
of an inode, the inode keeps nlink 0 with no destroy.  The MDT frees
the inode when it releases the object, and the name entry stays.

Include index 0 in the undo loop, as out_tx_end() does.

Fixes: 2fe22edfe3c3 ("LU-3534 osp: send updates by separate thread")
