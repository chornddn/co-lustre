LU-19520 lod: remove duplicate foreign mirror drop

lod_qos_parse_config() skipped the foreign HSM and PCC mirrors of the
layout that a client set for a new file, and lod_verify_striping()
let a plain component with the foreign pattern through for it.
lod_verify_striping() also drops these mirrors, removing them from
the layout buffer with lod_erase_comp_entry(), so every user of the
layout sees it without them.

Remove lod_lum_is_foreign() and the code that used it.

This needs https://review.whamcloud.com/71423 ("LU-19520 mdt: hide EC
parity from clients that cannot parse it") to land as well, so it can
only be tested once both have landed.
