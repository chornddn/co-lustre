DRAFT LU-21180 lod: add kunit test for lod_dom_stripesize_choose

Add a lod_dom_test kunit module covering
lod_dom_stripesize_choose(): checks a DOM component's stripe size
against the per-MDT DOM size limit and, if it is too large, either
shrinks the DOM extent to the limit or, if the limit has dropped to
zero, erases the DOM component via lod_erase_dom_stripe() when a
same-mirror component follows it, or fails with -EFBIG when it does
not.

The limit itself comes from lod_dom_stripesize_limit(), which caches
the OSD statfs result and only calls dt_statfs() once the cache is
older than LOD_DOM_SFS_MAX_AGE. Tests keep lod_lsfs_age fresh so the
cached lod_dom_stripesize_cur_kb is used directly, exercising the
real geometry logic without needing a statfs mock.

Make lod_dom_stripesize_limit() and lod_dom_stripesize_choose()
non-static and export them, since they previously had no caller
outside lod_verify_striping().
