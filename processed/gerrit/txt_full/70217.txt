--- Commit Message ---
LU-20879 osd-ldiskfs: match osd-zfs on a repeated destroy

osd-ldiskfs osd_destroy() did not account for an object that has
already been destroyed.  Return -ENOENT when obj->oo_destroyed is
set, as osd-zfs osd_destroy() already does, so that a repeated
destroy of the same object is handled consistently across backends.
