--- Commit Message ---
LU-20983 quota: save LQA ranges for both MD and DT pools

Since the loop in qmt_lqa_add()/qmt_lqa_remove() ends with
LQUOTA_RES_DT, only lqa-dt-<name>/ranges was ever written, so after
an MDS restart the lqa-md pool had no ranges and LQA inode usage and
limits were lost. Save/remove the range for each pool inside the loop
while the reference is held.

Test changes:
* add sanity-quota test_97i to check that the ranges file is created
  in both lqa-dt and lqa-md pools
* skip sanity-quota test_91 on non-ldiskfs MDT since it uses debugfs
* remove duplicate cleanup_quota_test stack_trap from sanity-quota
  test_97d
* remove debugging garbage from sanity-quota test_1b
