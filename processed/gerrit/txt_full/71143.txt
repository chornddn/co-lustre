LU-21248 tests: o2ib link state and alias tests

sanity-lnet test_109 and test_214 need tcp NETTYPE, so the o2iblnd
alias and link state code is not tested.

Add their o2ib counterparts. test_109b uses an alias of the o2ib
interface when NETTYPE is o2ib, otherwise Soft-RoCE. test_214b always
uses Soft-RoCE, since taking a real o2ib link down would cut the node
off, and waits for the NI to come back up after link up.

Split setup_o2ib_test_ni() into setup_fake_rxe(), load_o2iblnd() and
setup_o2ib_test_if(). test_308 now calls add_net() itself.

Test-Parameters: trivial testlist=sanity-lnet env=ONLY="109b 214b"
