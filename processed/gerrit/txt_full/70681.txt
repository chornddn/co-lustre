--- Commit Message ---
DRAFT LU-21180 lod: add kunit test for lod mirror staleness/fill logic

Export lod_last_non_stale_mirror(), lod_fill_mirrors(), lod_lu_ops,
lod_prepare_resync() and lod_prepare_resync_mirror() for direct
testing, without a mounted filesystem or OSD/OSP.

Add lustre/kunit/lod_mirror_test.c covering lod_last_non_stale_mirror()
(refusing to stale a mirror if that would stale every mirror, across
one/two/three mirrors - complements sanity-ec.sh 100a/100b),
lod_fill_mirrors() (parsing ldo_comp_entries[] into ldo_mirrors[]:
stale propagation, LCME_FL_PREF_WR vs. non-rotational fallback,
mixed parity/non-parity and HSM components, mismatched mirror id
counts - more exhaustive than the sanity-ec 2b/2c and sanity 90a/90b
it complements, since it reaches branches that would otherwise need
crafted layouts and failure injection), and lod_prepare_resync()/
lod_prepare_resync_mirror() (deciding which not-yet-inited components
of a stale or named mirror need instantiating for a resync).

mirror_test_setup() and friends: memset() zeroed the already
initialized mtc_env, corrupting lc_remember and LBUG-ing in
lu_context_fini() on module exit. Use
offsetof(struct mirror_test_ctx, mtc_env) as the memset length.

resync_test_setup(): allocate lti_comp_idx with
OBD_ALLOC_PTR_ARRAY() instead of pointing it at a struct-embedded
array, since lod_key_fini() unconditionally frees it with
OBD_FREE_PTR_ARRAY(), which otherwise corrupts the slab allocator.

Run from sanity test_51l, loading kunit on the MDS with enable=1.
