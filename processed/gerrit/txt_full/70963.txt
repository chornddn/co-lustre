LU-19536 tests: race mprotect with an unaligned DIO write

Add sanity test_119y and its helper dio_mprotect_race, which
makes the tail of the user buffer of an unaligned DIO write
PROT_NONE from another thread while the write is in flight.
The write may fail, but it must never report as written
data it did not copy from the user buffer.

The window between the up front fault-in and the end of the
copy depends on the node, so unless given a delay the helper
times an uncontended write first and sweeps the delays over
that time. Without the fix for short copies, 18 of 400 such
writes on a VM reported success without copying all of
their data.

The helper is based on a reproducer by Andrew Perepechko.
