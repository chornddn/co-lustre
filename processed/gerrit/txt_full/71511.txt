--- Commit Message ---
LU-21345 utils: report LSOM sync result in llsom_sync

In one-shot mode llsom_sync does not say whether any LSOM data were
refreshed. If the MDT changelog GC force-deregisters the changelog
user, the changelog is turned off and emptied, so there is no record
to read, sync nothing and exit 0. The LSOM data stay stale.

Print a warn when nothing was synced. In sanity 807a, check with
changelog_user_rec() that the changelog user is still registered
before and after llsom_sync, so that the failure reports the real
reason instead of "expected blocks: 2048, got: 0".
