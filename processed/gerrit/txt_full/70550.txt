LU-21147 doc: add adaptive OST read cache design

The OSD read cache gates page retention on two static, device-wide
thresholds: readcache_max_io_mb and readcache_max_filesize.  A shared
file larger than readcache_max_filesize is never cached no matter how
many clients read it, whereas a small file read by a single client is
cached even though that client already caches the data locally under a
DLM PR lock.

Add Documentation/adaptive-read-cache.txt describing the design of an
adaptive heat-based OST read cache that tracks per-object distinct
client read fan-in in OFD using rotating Bloom filter bins and hands
the read-caching verdict to osd-ldiskfs and osd-zfs via dt_bufs_type
flags.
