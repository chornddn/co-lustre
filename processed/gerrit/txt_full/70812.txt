DRAFT LU-21180 lod: add kunit test for lod_set_pool

Add lod_pool_test.ko, exercising lod_set_pool(): setting a pool name
from NULL, replacing an existing one, the @*pool == @new_pool
short-circuit used by lod_obj_set_pool() when nothing changed, and
clearing a pool back to NULL. It is a small, self-contained string
helper with no dt_object/OST/thandle involved, used here as a worked
example of mapping a kunit module to a single function via
KUNIT.list's new "<glob>:<function>" syntax, rather than the
whole-directory "*.[ch]" glob the other lod kunit modules use.

Also cover the OST pool registry itself, via a real (but device/OSD
free) lod_device: lod_pool_exists(), lod_pool_find(), lod_find_pool()
(the latter also rejecting an empty pool) and lod_check_index_in_pool()
against a pool created with lod_pool_new(), and lod_qos_set_pool(),
which resolves a component's requested pool name and clamps its
stripe count to the pool's target count. Export the lod_pool.c
helpers and lod_qos_set_pool() for direct testing.
