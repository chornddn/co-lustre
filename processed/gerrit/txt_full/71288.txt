LU-15834 idl: reserve MDS_RESYNC_SIZE op bias

Reserve MDS_RESYNC_SIZE at 1 << 28 in mds_op_bias, and name rs_size
the rr_size field of mdt_rec_resync that it marks valid, so an
in-place mirror extend can tell the MDT the file size.  Only the
bias, the field name and the wire checks are added here so the value
can land before the feature patch.
