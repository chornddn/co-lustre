LU-21061 lmv: migrate directories onto pool MDTs

"lfs migrate -m -1 -p POOL" sends the pool to the MDTs, which take the
other stripes of a directory from it, but the client picks the MDT of
the top directory among all MDTs, and nothing checks that the pool
exists or that a given MDT index is in it.  Rerunning the migration
also moves every file and directory again.

In lmv_migrate(), choose the MDT of a top directory among the MDTs of
a pool that lists MDTs: keep a directory that is on one of them, else
follow its parent if that is on one, else choose by space usage.
Name the chosen MDT in the request, so that the MDT skips a file or
plain directory that is already there, and a rerun finishes an
interrupted migration without moving the rest again.  Check the pool
and the MDT indices in llapi_migrate_mdt() as for mkdir, sharing the
check with verify_dir_param(), and strip a "fsname." prefix from the
pool name in lfs before it is copied into the request.
