LU-21224 lnet: lst new_session oopses on Linux 7.1

lst new_session oopses with a NULL dereference in lst_sessions_cmd()
on Linux 7.1 and later. Since upstream commit b93ec16310b4
("genetlink: use maxattr of 0 for the reject policy"), genetlink
fills info->attrs only for ops with a policy, and the lnet_selftest
family has none, so info->attrs is NULL.

Find the attribute list in the message itself, which works on every
kernel. No other Lustre netlink handler reads info->attrs.

Fixes: 15c82ae3d319 ("LU-8915 lnet: migrate LNet selftest session handling to Netlink")
