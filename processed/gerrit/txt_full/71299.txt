--- Commit Message ---
LU-19455 tests: avoid list statahead in sanity 123h

test_123h can fail with "hit total is too low" at about 1 run in
2000. When the lowest numbered file name also happens to be the
first entry in readdir (hash) order, which differs on every
filesystem, statahead detects the directory listing pattern on
the first stat() instead of the file name pattern. It then
prefetches in hash order while the test walks the names in
numeric order, so almost every lookup misses.

Remove such an entry before the scan so the file name pattern
is the only one that can match.
