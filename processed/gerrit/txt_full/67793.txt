--- Commit Message ---
LU-20557 llog: don't call llog_size() if rc is set

The llog_cat_size_cb() calls llog_cat_process_common() which
sets valid llog_handler only along with rc == 0, but
there is missing rc == 0 check before llog_size() call,
so it uses NULL llog_handler.

Patch adds explicit check for rc == 0
