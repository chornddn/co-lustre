--- Commit Message ---
LU-20821 tests: skip OSS nodes without ost_io in cleanup_123aj

cleanup_123aj() restores nrs_policies=fifo on every OSS node
returned by osts_nodes().  If an earlier test leaves only ost1
mounted, an OSS node with no active OST has no ost.OSS.ost_io
device.  The set_param then returns non-zero and marks an
otherwise successful test_123aj as FAIL.

Check the parameter exists on each OSS node before restoring it,
and treat the per-node restore as best effort, matching the
existing best-effort MGS cleanup commands.
