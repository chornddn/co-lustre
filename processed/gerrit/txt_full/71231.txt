--- Commit Message ---
LU-21269 target: track requests between commits

Add counters to track how many ptlrpc requests accumulate between
updates to obd_last_committed. This helps diagnose commit latency
issues where requests pile up before the last_committed transno
advances.

Two new sysfs attributes are exposed on MDT and OST:
  - commit_gap: current number of requests pending commit
  - commit_gap_peak: cumulative peak since mount

The gap is incremented on each transno allocation and snapshot/reset
in tgt_cb_last_committed when obd_last_committed advances.
