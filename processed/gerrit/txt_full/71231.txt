--- Commit Message ---
LU-21269 target: track requests between commits

Add counters to track how many transactions accumulate between
updates to obd_last_committed. This helps diagnose commit latency
issues where transactions pile up before the last_committed
transno advances.

Two new sysfs attributes are exposed on MDT and OST:
  - commit_gap: current number of transactions pending commit
  - commit_gap_peak: largest gap sampled since mount

The gap is incremented on each transno assignment and snapshot/reset
in tgt_cb_last_committed when obd_last_committed advances. When a
target fails over, both counters are reported on the console from
tgt_fini().
