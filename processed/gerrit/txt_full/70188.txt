LU-20869 obdclass: hash OBD device names

Attaching an OBD device looked up its name by walking the whole
device list several times, so attaching N devices cost O(N^2)
string compares. sanity test_55b, which attaches 24000 devices,
spent most of its 130s to 250s run in those scans.

Keep the device names in an rhashtable beside the device xarray,
and use it for name lookups and the duplicate check at
registration. UUIDs are not hashed because several devices can
share one (a client's OSCs and MDCs do).

The hash insert now rejects a duplicate name even while the
other device is not yet fully attached, and a failed xarray
insert no longer leaks the device list reference.

Set up the hash before /dev/obd is registered, and tear it down
after, so an ioctl racing module load never sees an uninitialized
table.

sanity test_55b with 24000 devices on a rocky9 VM, 3 runs each:
before 130s, 254s and 146s, after 6s, 5s and 5s.
