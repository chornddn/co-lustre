LU-20507 tests: don't require IPv6 on the fake interface

setup_fakeif() adds an IPv6 address to the fake interface and
treats a missing address as a fatal error. A node that sets
net.ipv6.conf.default.disable_ipv6 gives every new device
disable_ipv6=1, so the add fails and every test that calls
setup_fakeif() fails with "Failed setup test1pg".

A device takes disable_ipv6 from the default when it is
registered, so the interfaces that came up before the setting
was applied still carry an IPv6 address. Read the setting the
veth itself was given and only require the IPv6 address where
the interface accepts one. A namespace veth starts from the
kernel defaults and keeps its address.

Record intf_has_ipv6 ${INTERFACES[0]} in HAVE_IPV6 rather than
repeat it in each caller.
