LU-21169 hsm: allow restore without the hsm_ops role

When a client's nodemap lacks hsm_ops, reads that require HSM recall
fail with "No data available", even when file permissions allow
access. This prevents clients from accessing archived data without
HSM management privileges.

Exempt HUA_RESTORE from the hsm_ops role check in mdt_hsm_request().
Allow explicit restore and automatic recall on default and named
nodemaps while retaining role checks for HSM management and copytool
operations. Coordinator request masks, file-state checks, and normal
file access permissions continue to apply. Requesting restoration
does not grant access to file contents.

Document the restore exception and extend sanity-hsm test 411 to
check explicit restore and automatic recall without hsm_ops while
HSM management operations remain denied.
