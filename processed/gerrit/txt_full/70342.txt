LU-20869 tests: shorten sanity 123ac and 123ad

Pass 2 of sanity 123ac ran "statx --cached=always -D", which
only lists names and never calls statx(). It always timed as
0 seconds, so its loop never stopped early, and every run
created and unlinked 100000 files without checking anything:
about 540 seconds of 620. Add -l so that the pass really does
stat each file, which gives AT_STATX_DONT_SYNC its first test,
and cap it at 1000 files.

Most of 123ad went on running the base test twice, for a speed
check that only logs in a VM. Drop those runs and use one set
of files for both statahead settings. The hit count and RPC
checks are unchanged.

Quote the format in pass 1 of 123ac, so that its fields are no
longer passed as file names, and print the batched RPC count,
which was always empty.

With the CI debug mask on one ldiskfs node, 123ac goes from
640 to 44 seconds and 123ad from 309 to 58 seconds.

Fixes: 3f7853b31ef6 ("LU-10934 llite: integrate statx() API with Lustre")
