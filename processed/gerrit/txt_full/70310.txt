--- Commit Message ---
LU-20637 llapi: name objects below clear-name encrypted dirs

A device scan gave no pathname to any object below an encrypted
directory, taking its names for ciphertext. With the embedded
llcrypt, filename encryption is off by default, so the names on
the MDT are usually clear.

The directory map now reads the llcrypt context of each encrypted
directory (encryption.c, or security.c from before 2.15) and keeps
its names when the filenames mode is LLCRYPT_MODE_NULL. A directory
with no valid context is still taken as encrypted.
