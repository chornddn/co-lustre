--- Commit Message ---
LU-21045 obdclass: allow disabling server jobstats

Cloud operators administer Lustre servers independently of clients.
Clients can keep sending distinct JobIDs and consume server memory
and accounting time even when the operator does not need jobstats.

Add a per-target job_stats_enable control for MDTs and OSTs.  Skip
jobstats lookups, allocations and counter updates while disabled,
using the existing atomic flags.  Leave existing statistics and
expiry intact, and allow collection to resume without client changes.
Document the control and cover new and existing JobIDs in sanity/205p.
