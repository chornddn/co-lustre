DRAFT LU-21180 lod: add kunit lod_buf_test

Add lod_buf_test, covering per-thread LOD buffer lifecycle helpers,
the DoM-stripe-entry removal helper, and the lod_object component/
mirror array lifecycle: buffer growth, no-op on a smaller request,
release, removing a DoM component entry and its data blob from an
in-memory composite layout, and allocating/freeing a lod_object's
component array (and mirror array, for a mirrored layout).

Functions tested:
- lod_ea_store_resize()
- lod_def_striping_comp_resize()
- lod_free_def_comp_entries()
- lod_erase_dom_stripe()
- lod_alloc_comp_entries()
- lod_free_comp_entries()

Export lod_free_comp_entries() so the test module can call it
directly, matching lod_alloc_comp_entries(), which was already
exported.
