LU-21021 llite: refresh layout in getxattr of lustre.lov

ll_getxattr_lov() packs the cached layout without taking the layout
lock. After another client changed the layout, fgetxattr() on an open
file, and so llapi_layout_get_by_fd(), returns the old layout until
some other operation refreshes it.

Call ll_layout_refresh() in getxattr of a regular file before packing
its layout. listxattr, which only needs to know that there is a
layout, does not refresh, nor does getxattr while a group lock is held
on the file: a new layout would wait for the group lock's I/O, which
the caller may hold itself. If the refresh fails, the cached layout is
returned.

Add multiop command Xg, which prints the layout generation,
sanityn test_123, and test60 to swap_lock_test (sanity test_405),
which reads the layout of a group-locked file after a layout swap.

Test-Parameters: testlist=sanityn env=ONLY=123,ONLY_REPEAT=10
Test-Parameters: testlist=sanity env=ONLY=405
