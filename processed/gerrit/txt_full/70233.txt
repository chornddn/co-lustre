--- Commit Message ---
LU-20923 target: reply -EPROTO when a handler packs no reply

tgt_handle_request0() requires each request handler to either pack a
reply or return an error, and treated a handler that returned success
with no reply as a coding bug.  A request can also drive a handler
(for example MDS_GETATTR or MDS_GETXATTR) onto an early success path
that packs no reply.  Send the client -EPROTO and log the handler at
D_ERROR in that case, so the request is failed and reported rather
than treated as a bug.  This is the common backstop reached by both
the MDC and OUT request paths.
