LU-19520 mdt: hide EC parity from clients that cannot parse it

A 2.15 client failed the whole layout of a file with an EC parity
component with -EINVAL, so it could not even stat the file.  2.16 and
2.17 clients oopsed in lov_lsme_pack_v1v3() on getxattr("lustre.lov")
of such a file once its parity was instantiated, since they kept the
stripe count of a component with an unknown pattern but none of its
objects.  Released clients cannot be fixed.

Remove the components whose pattern a client did not send in
ocd_layout_pattern_types at connect, or that are not in
LOV_LAYOUT_PATTERN_TYPES_217 for a client that predates it, from the
layouts the MDT sends it: in mdt_fix_reply() for getattr, open and
setattr replies, in mdt_lvbo_fill() for layout locks, and in
mdt_getxattr() for trusted.lov.  The copy keeps the component and
mirror IDs and the layout generation, and drops the EC fields of the
data components.  The MDT saves the mask the client sent, so that
disabling parity in mdt.*.layout_pattern_types does not hide it from
clients that can parse it.

Older clients refuse an FLR layout with a single mirror, and without
an FLR state they would write without the layout intent that stales
the hidden parity.  When one mirror is left, add a data-less HSM
mirror flagged with the new HS_SOM.  It has mirror ID 0, which
LL_IOC_FLR_SET_MIRROR takes as no mirror, so no designated I/O
reaches it, and it is stale unless the file is RDONLY with its hidden
components in sync, so that no write needs an intent for it.

A resync, mirror copy or mirror write from such a client would write
to that stale mirror as to the file itself, and truncate a sparse
file at its first hole.  The MDT refuses MDS_REINT_RESYNC with
-EOPNOTSUPP for a file with components hidden from the client, which
these tools send before any I/O.

LOD drops the HS_SOM mirror, and a plain component with the foreign
pattern, which is how llapi copies a foreign one, from a layout that a
client sets, so a copy of the layout made by an older client has
neither the parity nor this mirror.  It also drops any other foreign
HSM or PCC mirror from the layout of a new file, as only the MDT adds
those, so restoring a layout saved from a file with such a mirror no
longer fails with -EINVAL.  Generalize lod_erase_dom_stripe() into
lod_erase_comp_entry() for this, checking the offsets it moves.

Add sanity-ec test_14, and OBD_FAIL_LLITE_NO_FLR_EC to mount a
client that does not negotiate layout patterns.
