LU-21019 osd-ldiskfs: keep times across deferred truncate

ldiskfs_truncate() sets mtime and ctime to the current time. Since
the truncate of a punch is deferred to osd_trans_stop(), it replaces
the times the caller set in the punch transaction, and it changes the
times of a punch that should keep them: splitting off a DoM mirror or
migrating a file off DoM (mdd_dom_fixup()) sets the file's mtime to
the current time. osd-zfs does not change the times on a punch.

Restore mtime and ctime after ldiskfs_truncate(), so that a punch
changes no times, as on osd-zfs. A counter that osd_attr_set() and
xattr changes bump under oo_guard keeps times set while the truncate
ran. Whether an operation updates ctime is left to its caller, which
sets it in the punch transaction (ofd and mdd for a truncate).

Add sanity-flr test_61d.
