LU-20578 tests: count configured NIs in check_parameter

check_parameter() compared the number of NIs reporting a tunable
against ${#INTERFACES[@]}. test_241 configures only INTERFACES[0],
so on a node with two or more LNet interfaces the counts never
matched and the test failed although the tunable was set.

Take the expected count from the NIs configured on ${NETTYPE} at
the time of the check, and restrict the reporting NIs to that same
net. A node that runs a second net on the same LND would otherwise
count NIs the expected value does not cover.

test_310 configures every interface, and its check that each one
reports the module parameter is deliberate. It keeps that check by
passing ${#INTERFACES[@]} as the expected count.
