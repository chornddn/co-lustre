LU-20104 lnet: fix selftest session teardown and BRW bugs

Fix lnet-selftest crashes and stale sessions, on top of the
LU-20342 module-unload deadlock fixes.

Split the server srpc_ev into srpc_bulkev and srpc_replyev.
The shared event was reused for the bulk MD and then the reply
MD, so a late bulk UNLINK landed on the rewritten reply event
and double-completed a recycled RPC, causing the list_add
corruption in srpc_lnet_ev_handler reported by James Simmons.
Also gate the bulk/reply events on ev->unlinked, and require
both events fired before completing an RPC re-entering
srpc_handle_rpc in SWI_STATE_DONE.

Order session teardown so client-side batches drain before the
session is deactivated and server-side RPCs are drained, and
add lst_wait_until_timeout() to bound console RPC waits held
under ses_mutex.

Fix BRW offset handling: mask offset with ~PAGE_MASK, allocate
bulk with off+len, and reject off+len > LNET_MTU.

Add lnet-selftest.sh tests for teardown stress, BRW offset
edge cases, and the workqueue list-corruption race.

Test-Parameters: trivial testlist=lnet-selftest,sanity-lnet
