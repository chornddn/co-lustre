--- Commit Message ---
LU-20682 llite: validate xattr value in ll_xattr_set()

ll_xattr_set() swabs and rewrites the LOV and LMV EA from
setxattr(2) without checking the value.  removexattr(2) hands it
value == NULL, and a short value carrying a big-endian LOV magic
or the "lmv" name is rewritten past the end of the kernel buffer.

A composite value survives that length check and still leaves the
buffer: lustre_swab_lov_comp_md_v1() walks the lcm_entry_count
entries and the lcme_offset blobs the value carries itself, none
of which lcm_size bounds.

Touch a value only when it exists and holds the whole header its
magic describes.  Keep the composite walk within lcm_size, which
the caller has checked the value is long enough to hold, and
within each entry's own lcme_size.
