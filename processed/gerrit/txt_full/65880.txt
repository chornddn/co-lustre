LU-12668 ec: resync crash on overstriped parity mirror

If a file's parity mirror is set overstriped
("-C, --overstripe-count"), the lov_pattern_supported/available()
check fails, so that mirror is not creatd, and write to it fails.

This patch fixes the check properly, and also add some error message
to be more clear.
