LU-20708 osc: let read faults switch mirrors on a bad OSC

osc_io_iter_init() returns -EAGAIN for a non-delayed CIT_READ on an
OSC whose import is not healthy, so the read moves to another mirror,
or for EC, once every mirror was tried, is rebuilt from parity.  A
read fault is non-delayed too, and since "llite: rebuild faulting EC
pages from parity" restarts the same way, but it still got -EIO from
an inactive OSC, which ll_fault() returns as SIGBUS.  So mmap reads
of an FLR or EC file fail while one of its OSTs is deactivated or
unreachable, though read(2) of the same file works.

Return -EAGAIN for CIT_FAULT as for CIT_READ.

Add sanity-flr test_33d and sanity-ec test_49h: mmap reads of an FLR
file with each mirror's OST deactivated, and of an EC file with a
data OST deactivated.
