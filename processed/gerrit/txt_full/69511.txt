LU-20802 lov: add OBJECT I/O scope read and lseek

EC rebuild, single-stripe migration, and verify need to read or
seek one OST object by object offset; that address space is not
reachable through the file-offset path.

Open LL_IO_SCOPE_OBJECT for O_DIRECT pread and lseek (SEEK_DATA,
SEEK_HOLE, SEEK_END). The caller names one OST object by
(ios_comp_id, ios_stripe_idx); pos is an offset on that object.
ios_comp_id is the lcme_id, or 0 for a plain (V1/V3) layout, and
stripe index 0 is valid. ios_obj_fid and ios_layout_version must
be 0. The ioctl only checks the arguments; the target is resolved
on each I/O. Only OST RAID0 and parity components; DoM and foreign
components or an out-of-range stripe index return -EINVAL,
compressed returns -EOPNOTSUPP, and an inactive OST returns -EIO.

Add ci_obj_io with ci_designated_comp_id / ci_designated_stripe
and a separate lov_obj_io_ops table so OBJECT I/O is one identity
sub-IO. File-offset helpers (lov_io_rw_iter_init, lov_io_iter_init,
lov_io_lseek_end, lov_offset.c) are unchanged. EOF is the target
object's LVB size in ci_eof (shared with parity I/O). Add
cl_io_glimpse_end() so the LOV slice refreshes ci_eof from the
glimpsed stripe LVB; call it after every successful non-AGL
CIT_GLIMPSE. Do not copy the FLR layout generation into
ci_layout_version; OBJECT I/O does no layout generation check.

Reject write, truncate, and fallocate on an OBJECT-scope fd while
holding the I/O scope, and do not let ll_direct_IO() fall back to
buffered I/O for it. Return -EOPNOTSUPP for encrypted files at
ioctl time and for compressed components, -EINVAL for DoM or
foreign components and from splice_read, and -ENOENT for released,
empty, or uninstantiated layouts. Dead objects return -EIO without
CIT_EC_RD. sanity-flr test_214a-c cover object read/lseek and
reject pwrite, ftruncate, mmap, and non-O_DIRECT.
