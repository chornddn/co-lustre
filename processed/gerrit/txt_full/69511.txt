LU-20802 lov: add OBJECT I/O scope read and lseek

Open LL_IO_SCOPE_OBJECT for O_DIRECT pread and lseek (SEEK_DATA,
SEEK_HOLE, SEEK_END). The caller names one OST object by
(ios_comp_id, ios_stripe_idx); pos is an offset on that object.
ios_comp_id must be non-zero and stripe index 0 is valid.
ios_obj_fid and ios_layout_version must be 0. The ioctl only
checks the arguments; the target is resolved on each I/O.

Add ci_obj_io with ci_designated_comp_id / ci_designated_stripe
and a separate lov_obj_io_ops table so OBJECT I/O is one identity
sub-IO. File-offset helpers (lov_io_rw_iter_init, lov_io_iter_init,
lov_io_lseek_end, lov_offset.c) are unchanged. EOF is the target
object's LVB size in ci_eof (shared with parity I/O). Add
cl_io_glimpse_end() so the LOV slice refreshes ci_eof from the
glimpsed stripe LVB. Do not copy the FLR layout generation into
ci_layout_version; ios_layout_version is checked when the caller
sets it.

Reject write, truncate, and fallocate on an OBJECT-scope fd while
holding the I/O scope, and do not let ll_direct_IO() fall back to
buffered I/O for it. Dead objects return -EIO without CIT_EC_RD.
OBJECT is checked before the scope switch, so STRIPE can update
that switch on its own. sanity-flr test_214a-c cover object
read/lseek and the rejected operations.
