LU-20923 mdd: reject a PCC create without a layout

A PCC create (MDS_OPEN_PCC in cr_flags) must carry a layout
(MDS_OPEN_HAS_EA).  In mdd_create(), return -EINVAL for MDS_OPEN_PCC
without MDS_OPEN_HAS_EA rather than proceeding.  The reject path jumps
to the out_stop/out_free cleanup, which frees hsm_buf when
MDS_OPEN_PCC is set, so also initialize hsm_buf at its declaration
(like pin_buf); otherwise that path, which runs before hsm_buf is
memset, would free an uninitialized buffer.
