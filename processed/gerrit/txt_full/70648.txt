--- Commit Message ---
LU-21165 utils: use int for getopt result in lctl del_ost

jt_del_ost() stored the getopt_long() return value in a char.
Where char is unsigned, such as aarch64, the value never matched
-1, so the loop fell through to the default case and
"lctl del_ost" always printed its usage message, and
conf-sanity test_123ah would fail with "del_ost --dryrun failed".

Store the getopt_long() result in an int.
