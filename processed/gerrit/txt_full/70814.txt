--- Commit Message ---
DRAFT LU-21180 lod: add kunit test for EC raid-set geometry

Export lod_ec_data_range_for_parity(), lod_ec_comp_raidset_range(),
lod_ec_check_data_usable() and lod_ec_shrink_data_geometry() for
direct testing.

Add lustre/kunit/lod_ec_geom_test.c covering the pure raid-set
geometry helpers behind EC (erasure coded) layouts, operating on
plain structs (struct ec_split_comp, struct lod_layout_component)
with no dt_object/OST/thandle involved: mapping a parity-component
stripe index to the raid set of the linked data component it covers
(lod_ec_data_range_for_parity()), mapping a stripe index of a
component (data or parity) to the raid-set range within that same
component (lod_ec_comp_raidset_range()), checking whether a candidate
OST index is already used by the relevant raid-set window of the
linked data component (lod_ec_check_data_usable()), and converting
esc_k0 raidsets into esc_k1 raidsets to shrink an EC data layout down
to the number of OSTs actually found (lod_ec_shrink_data_geometry()).
