DRAFT LU-21180 lod: add kunit tests for lod_dev.c helpers

lod_dev.c, which handles LOD device/stack setup and configuration
parsing, had no kunit coverage.  Most of its code needs a live device
stack to exercise, but two small helpers are pure (or nearly pure)
functions that can be tested in isolation: lodname2mdt_index(), which
parses the MDT index out of an LOD device name, and lod_statfs_sum(),
which accumulates one target's obd_statfs into a running total,
rescaling for differing block sizes.

Add lustre/kunit/lod_dev_test.c with 6 test cases covering both
functions: lodname2mdt_index() for the pre-1.9 no-"-MDT" case, a
well-formed name, and malformed suffixes; lod_statfs_sum() for the
same-block-size case and both directions of block-size rescaling.

Un-staticize lod_statfs_sum() and export it (lodname2mdt_index() was
already exported) so the test module can call it directly.
