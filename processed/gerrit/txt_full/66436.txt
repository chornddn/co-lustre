LU-12668 ec: ensure hole ranges for raidset parity

Complete the block-granularity EC parity resync/verify path so
partial writes and verification stay consistent with sparse
parity mirrors.

When a raidset has no data coverage, punch or verify that parity
mirror is holed for the entire raidset through
llapi_ec_ensure_hole_range(), shared with the stripeset-level hole
path and with clearer mismatch diagnostics.

For raidsets that contain data, in resync path,  punch the full
parity stripe once and then write the @cov ranges, instead of
punching each @cov interval separately. This cuts RPC count and
keeps the resync path simpler. In verify path, it's irrelavent with
@cov since we need to compare the whole stripe, both range contains
data and that is filled with zero, otherwise it would cause
inconsistency.

Right after @cov is created, expand and merge coverage intervals to
page boundaries via ec_cov_page_align_and_merge(), since files in
resync operation is opened with O_DIRECT.

Enable sanity-ec/12b, add sanity-ec/12d,12e
