LU-21140 llite: list each name once in a splitting directory

While a striped directory is being split or migrated, readdir can
return the same name twice: LMV reads each stripe in its own RPC and
merges the pages by hash without comparing names, so an entry read
from the old stripe before it moves and from the new stripe after it
is listed twice. A parallel "lfs find | xargs rm" of a directory
that is auto-splitting then fails with ENOENT on the second removal.

Keep the names returned by an open directory in an xarray while its
layout is changing, and drop a name already returned. A name is
recorded only after dir_emit() accepts it, so an entry that did not
fit in the user buffer is read again, and the set is cleared on
seek or end of directory and freed on close. A listing that
starts before the split begins is not covered, as its names were not
recorded.

Add sanity test_230D, which lists a directory while it auto-splits.
