--- Commit Message ---
LU-21104 ptlrpc: make an idle import valid when activated

Deactivating an import marks it invalid.  Activating it again calls
ptlrpc_recover_import(), which reconnects only a FULL import, so an
import that had disconnected while idle stays invalid.  I/O through
it fails in osc_io_iter_init() before it makes a request that would
reconnect the import, so every I/O to that OST keeps failing:

  client# lctl set_param osc.lustre-OST0000-osc-*.active=0
  client# lctl set_param osc.lustre-OST0000-osc-*.active=1
  client# touch /mnt/lustre/f
  touch: setting times of '/mnt/lustre/f': Input/output error

In ptlrpc_set_import_active(), only mark an idle import valid with
ptlrpc_activate_import(), as it connects on its next request.
