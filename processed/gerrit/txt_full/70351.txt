--- Commit Message ---
LU-21104 ptlrpc: make an idle import valid when activated

Deactivating an import marks it invalid.  For a connected import, the
reconnect started when it is activated again makes it valid, but an
import that was IDLE is not reconnected: ptlrpc_recover_import()->
ptlrpc_set_import_discon() only acts a FULL import, so the idle import
will not be able to be recovered, so all I/O to the OST fails:

  client# lctl set_param osc.lustre-OST0000-osc-*.active=0
  client# lctl set_param osc.lustre-OST0000-osc-*.active=1
  client# touch /mnt/lustre/f
  touch: setting times of '/mnt/lustre/f': Input/output error

In ptlrpc_set_import_active(), mark an idle import valid with
ptlrpc_activate_import() without reconnecting it, so that it connects
on its next request like any other idle import.

Fixes: 5a6ceb664f07 ("LU-7236 ptlrpc: idle connections can disconnect")
