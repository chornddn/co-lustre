--- Commit Message ---
LU-21275 tests: re-read initial_grant in sanity 64f

test_64f remounts the client a second time to reset the OST grant,
but keeps using the init_grants value read after the first mount.
The initial grant an OST gives out on a new connection is not
always the same, so the remaining check_grants calls compare
against a stale expected value and the test intermittently fails
with "grants mismatch".

Re-read initial_grant from the OSC import after the second
remount_client.
