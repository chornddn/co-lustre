LU-11962 flr: add strict SOM for non-mirrored files

The MDT can only return the size and blocks of a file without a
glimpse of every OST object when the file has strict Size-on-MDT,
which so far only "lfs mirror resync" sets, on mirrored files, so
stat() of files that are no longer modified still needs OST RPCs.

Add "lfs somsync --strict" and llapi_file_som_sync() to make a file
RDONLY with strict SOM, using the FLR resync protocol: with a write
lease, MDS_REINT_RESYNC on a non-FLR file, including one with a plain
layout, now appends a mirror made of a single data-less foreign HSM
component (HS_SOM), moves the file to SYNC_PENDING and closes its
write era on the OSTs.  The client then gets the final size and
blocks, and RESYNC_DONE makes the file RDONLY with SOM_FL_STRICT.  A
later write needs a layout write intent, which moves the file to
WRITE_PENDING and SOM to STALE as for any mirrored file.  Clients
since 2.15 handle such a layout unchanged.

Conversion needs write permission, is refused while the file is open
elsewhere, and is refused if mdt.*.enable_strict_som=0.  "lfs migrate"
makes SOM strict again after migrating an RDONLY file.

As for any mirrored file, a client that the MDT evicted but that
still holds the layout from before the conversion can write without
the MDT knowing until it notices the eviction.  Fencing such writes
needs clients to send a layout version for every file, which is left
for a later patch.
