LU-20739 kernel: RHEL 10.3 server support

Add the ldiskfs series and server kernel patch series for RHEL 10.3
(kernel 6.12.0-264.16.1.el10_3).

ext4-dirdata-core and ext4-dirdata-lustre-compat do not apply to the
RHEL 10.3 ext4: it dropped the ext4_has_feature_metadata_csum()
conversion that 10.2 has, so its namei.c uses
ext4_has_metadata_csum(), and its ext4_mkdir() returns NULL on
success.  Add rhel10.3 copies of
linux-6.18/ext4-dirdata-core.patch and
rhel10.2/ext4-dirdata-lustre-compat.patch, switched back to
ext4_has_metadata_csum() as in 10.0/10.1.

Add the x86_64 server kernel config for RHEL 10.3, and register the
6.12-rhel10.3.series patch series in the target, which_patch and
ChangeLog.
