LU-21048 AGENTS: note zero-init struct depending on CONST==0

Add a review checklist item for code that compares foo->field == CONST
while a different, zero-initialized instance of the same struct is
relied upon to mean the same CONST, with no explicit assignment or
BUILD_BUG_ON() tying the two together.

Example:
        if (scope->ios_scope == LL_IO_SCOPE_FILE) {
                memset(&lfd->fd_io_scope, 0, sizeof(lfd->fd_io_scope));
                return 0;
        }
