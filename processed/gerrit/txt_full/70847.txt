DRAFT LU-21180 lod: add kunit test for lod_prepare_create

lod_prepare_create() is mdd's entry point for object creation: it
runs lod_qos_parse_config() on the caller's optional striping buffer,
then walks ldo_comp_entries[] allocating every component the object's
size covers via lod_comp_prep_create(). It was untested.

Add lod_prepare_create_test.c, covering no OSTs available (-EIO
before touching any striping), a two-component PFL layout where only
the component covering a 0-byte file's size gets instantiated, and a
caller-supplied V1 striping buffer that replaces the pre-set
component before allocation. Reuses the same fake lod_device/mock_tgt
OST setup and lod_qos_declare_object_on() stub as lod_comp_test.c.

Export lod_prepare_create(), needed by the new test module, and
register it in lustre/kunit/Makefile, KUNIT.modules_list and
lod/KUNIT.list.
