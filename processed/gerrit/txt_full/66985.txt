LU-20438 lnd: Support PCI P2P DMA mapping

Modify o2iblnd to support mapping PCI P2P DMA pages.
Check HCA capabilities for P2P DMA support and use
appropriate DMA mapping APIs when P2P pages are detected.

Fix LBUG crash during 0-length bulk transfers when P2P DMA is active.
LNetGet initiates GET requests with 0 payload length. When P2P DMA
is enabled, the code bypassed IMMEDIATE message checks and attempted
RDMA mapping even for 0-length transfers, triggering a LASSERT(nob > 0)
panic in kiblnd_setup_rd_kiov. Fix this by forcing IMMEDIATE mode if
the transfer size is 0.

Additionally, correct GET request page mapping in kiblnd_send to use
msg_md->md_kiov (sink pages) and msg_md->md_length instead of payload_kiov
and payload_nob (which are empty/0 for GET), aligning with upstream master.
