--- Commit Message ---
LU-20076 tests: build node lists with fewer forks

Every subtest builds the node list at least twice, and each
list ran about 40 processes and subshells, mostly to look up
each facet's active host and to change case and sort. Each
do_nodes() also counts its nodes and lists the facets again.
On a test VM this was 34 ms for a node list and 15 ms for the
remote environment string.

Do the lookups and joins with shell builtins and keep only one
sort per list, which takes those to 15 ms and 5 ms. The output
is unchanged. Do not start lsmod and awk on every log() call
when libcfs is loaded.
