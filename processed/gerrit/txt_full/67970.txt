--- Commit Message ---
LU-18298 tests: re-enable sanity-pcc test_1c/1d on SLES15

These two subtests were excluded on SLES15 SP3-SP5 for LU-18298, whose
root cause is now fixed: a write open racing a layout blocking AST left
the file handle unable to use PCC for the rest of its life, so the write
bypassed PCC and restored the HSM released file.

The reported SLES15 failure carries the same signature as the one that
was reproduced and fixed, so the exclusion should no longer be needed.
No SLES client was available to confirm that directly, hence the split
from the fix: if this run still fails, drop this patch and leave the
exclusion in place, without disturbing the fix itself.
