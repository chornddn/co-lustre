LU-20099 nrs: add zero reserved rate and unlimited rate for mClock

This patch adds zero reserved rate and umlimited limit rate for
mClock NRS scheduler.

When the reserved rate for a rule is set with 0, the class bucket
matching the rule will be skipped to add into the mClock reserved
red-black tree when insert the bucket into the trees.
It means that there is no any reserved rate for the class bucket.

When the limit rate of a rule is set with "unlimit" or "max", the
limit deadline of the class bucket matching the rule will be
always set with the current time when the class bucket is
inserted into the mClock limit red-black tree.
It means the waiting time to service the next request in the
class bucket is always 0.

Add a test case sanityn/test_77vk to verify the setting of zero
reserved rate and unlimited limit rate.

Add a test case sanityn/test_77vl to evaluate the case when
setting R=0 or L="max".
