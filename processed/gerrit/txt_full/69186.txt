--- Commit Message ---
LU-19651 lnet: quiet socket not found error at shutdown

Every LNet shutdown with socklnd logs a spurious error:

  LNetError: (acceptor.c:252:lnet_acceptor_remove_socket())
    Interface eth0 not found

LNetNIFini() stops the acceptor thread before the LNDs, and the
acceptor releases every listening socket in socket_list as it exits.
ksocknal_shutdown() then cannot find the socket that it added in
ksocknal_startup().

Only report a missing listening socket while the acceptor is running,
as it is for "lnetctl net del".

Add a check to sanity-lnet test_290 that LNet cleanup closes the
listening port and does not print this error.

Fixes: 2e49bc7dd1 ("LU-18812 lnet: restrict IP addresses that socklnd listens on")
