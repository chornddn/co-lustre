LU-21224 osd-ldiskfs: build without CONFIG_CRC_T10DIF

obdclass defines obd_dif_crc_fn() and obd_dif_ip_fn() only when
CONFIG_CRC_T10DIF is enabled, but osd-ldiskfs calls them
unconditionally. CRC_T10DIF has no prompt in recent kernels and is
only selected by its users, among them BLK_DEV_INTEGRITY, so a
kernel without block integrity (mainline 7.0 from defconfig) has
neither and osd_ldiskfs.ko fails at modpost with both symbols
undefined.

Define both as NULL in obd_cksum.h when CRC_T10DIF is off, in place
of the copy osc kept for itself, so osc and osd share it. They are
unreachable then: the T10 type of an OSD is only set when the device
has an integrity profile, which needs BLK_DEV_INTEGRITY.
