--- Commit Message ---
LU-20354 quota: add DOM MDT list to qmt_sarray

Extend qmt_sarray with a separate dom_mdts list so DT pools can
track DOM MDTs without overloading the primary tgts array used by
lgd and recalc. Primary helpers keep ignoring DOM.

enum qmt_stype has no negative values, so GCC treats it as unsigned.
Since b64bc2c6f35f returned it from qmt_uuid2idx(), -EINVAL wrapped
to a large unsigned value and every "if (stype < 0)" check was dead.

Return an int error code again (stype via out-param) so those checks
are live and a bad UUID cannot drive a garbage stype into callers.
