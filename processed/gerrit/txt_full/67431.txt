LU-17620 tests: Disable migration in racer for now

both the file and directory kinds.
Let's disable that for now, stabilize the other parts of it and then
fix the migration problems and then reenable it in racer.

This is esp. true as we know there are several lock deadlocks we
know about in migration code.
