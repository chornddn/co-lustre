LU-21147 ofd: add adaptive heat-based OST read cache

The OSD read cache decides whether to cache read pages using static
size thresholds (readcache_max_io_mb and readcache_max_filesize) with
no memory of past client access.  Large shared files are excluded from
the OST cache once they exceed readcache_max_filesize, while small
unshared files read by a single client pollute the OST cache despite
already being cached on the client under a DLM PR lock.  In addition,
osd-zfs lacks the read_cache_enable and readcache_max_io_mb tunables
and does not forward dt_bufs_type flags into osd_bufs_get_read().

Add per-object distinct-client read heat tracking in ofd_heat.c keyed
on exp_client_uuid using four rotating Bloom filter decay bins.  When
obdfilter.*.readcache_adaptive_enable is enabled, ofd_preprw_read()
evaluates ofd_heat_touch() and passes DT_BUFS_TYPE_ADAPT and
DT_BUFS_TYPE_HOT to the OSD so distinct-client fan-in replaces static
size gating on the read path while still honoring read_cache_enable.
Add read_cache_enable and readcache_max_io_mb to osd-zfs, add heat
counters and cache_hot_* statistics, and add man pages and sanity
subtests 921a-921g.
