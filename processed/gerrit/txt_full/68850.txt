LU-17296 tests: fair share with no rule for mClock

LU-17296 asks for a server setting that shares the service between the
jobs and needs no configuration. The mClock policy with the weight
dimension and no rule gives that setting. Each class bucket takes the
default weight of the default rule. The active buckets then get an
equal share.

Add four tests. Test 77xa runs an unequal fio pair, and it compares
FIFO against the weight share. Test 77xb shows that one weight rule
tilts the share against a bucket that matches no rule. Test 77xc
shows the same for a wildcard job ID rule. Test 77xd starts the
policy on the MDT.

Give nrs_fio_flow_one() two more tuple fields: the number of fio jobs
and a command prefix. Move the file setup of test_mclock_two_flows()
into mclock_two_files_prep(), because the new tests need it.

Document the mode in Documentation/man4/nrs_policies.4.

Test-Parameters: trivial testlist=sanityn env=ONLY="77xa 77xb 77xc 77xd",ONLY_REPEAT=3
