LU-14144 utils: find Lustre module params without --module

"set_param -P" is applied on each node by running "lctl set_param"
from an upcall or udev rule, which can't pass --module, so module
parameters could not be set persistently.

If no Lustre parameter matches, fall back to Lustre/LNet module
parameters, with the new LLAPI_PARAM_MODULES_FALLBACK flag for
llapi_param_get_paths_flags().  Existing patterns like "osc.*" are
unaffected since they match first.

Have "set_param -P" refuse parameters that are read-only at runtime,
since they would fail on every node at every mount.

Fixes: 7c7edbcaa8 ("LU-14144 utils: allow /sys/module/OBD/parameters/*")
