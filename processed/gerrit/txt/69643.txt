--- Commit Message ---
LU-20837 libcfs: move lustre_debug_vlen() out of line

Older kernels built without CONFIG_OPTIMIZE_INLINING define
"inline" as always_inline. lustre_debug_vlen() uses a va_list,
which gcc cannot inline, so the build fails there, e.g. with
gcc 8.5.0 on a 4.18 (el8) kernel:

  lustre_debug.h:43:19: error: function 'lustre_debug_vlen'
  can never be inlined because it uses variable argument lists

Move the function to tracefile.c and leave a declaration in
the header.
