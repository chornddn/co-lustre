LU-20650 lfs: find --since-cookie, check each MDT when read

The stale check runs on every MDT before any of them is read, so that
a refusal comes before the first match is printed. But a purge can
reach a later MDT while an earlier one is being read. Then that MDT's
scan starts at the oldest record left, the records between the anchor
and it are gone, and the run ends with rc 0 and a short answer.

So llapi_find_since() reads the oldest record again just before each
MDT is scanned, the first one too, through find_cookie_purged(), the
purge test find_cookie_check() now shares: one find_cl_first() record
each. If it is past anchor + 1, the run stops with -ESTALE and names
both numbers. The matches already printed stay printed. The cookie is
not rewritten, so every later run is refused the same way until it is
removed, rather than skip the purged records.

An MDT recorded at 0 had nothing consumed, so the pre-pass keeps the
oldest record it saw there. If that has changed when the MDT is read,
an emptied log included, the run warns, names the MDT and goes on, as
the pre-pass does for such a log. The cookie advances as usual: the
purged records are gone from the log, so holding it back would get
none of them back and only make the next run repeat this one.

An error reading that record is handled as a failed scan: the MDT is
not read, the run goes on to the next one and fails at the end, so
the cookie is not rewritten.

The check reads the log, not the scan's own stream. Under coalescing
the stream gives one record per object, with its latest index, so the
first index it delivers says nothing about what was purged.

Still not covered, and the man pages say so: a purge that empties the
log of an MDT recorded past 0 (seen once new records arrive), records
made and purged during the run on an MDT recorded at 0 whose log was
empty when it began, a purge during the run of an MDT the cookie has
no line for (a first run), a purge on the MDT being read, which is the
only window on a single-MDT filesystem, and a record written late at
the tail of a busy log.
