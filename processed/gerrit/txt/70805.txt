LU-21203 osd-zfs: detect pools on non-rotational devices

osd-zfs reports a target as non-rotational only when its
nonrotational parameter is set by hand, while osd-ldiskfs takes the
flag from its block device at mount.  OS_STATFS_NONROT is used to
choose FLR mirrors to read from, so a ZFS OST on SSD or NVMe devices
is treated like one on disks unless the administrator sets it.

ZFS keeps this in vdev_nonrot: a disk vdev takes it from its block
device, a file vdev is always non-rotational, and a mirror, RAID-Z
or dRAID vdev is non-rotational when all of its children are.  At
mount, set od_nonrotational in osd_pool_nonrotational() when every
top-level vdev of the normal class is non-rotational.  Log, special,
dedup, hole and removed (indirect) vdevs are skipped, since bulk file
data is not allocated from them.  The nonrotational parameter still
overrides the detected value.

Add sanity test_56cb, which sets the rotational flag of the devices
of a ZFS OST to 0 and then 1 and checks the parameter each time the
OST is started again.

Test-Parameters: fstype=zfs testlist=sanity env=ONLY=56cb,ONLY_MINUTES=30
