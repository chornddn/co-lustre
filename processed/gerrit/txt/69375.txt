--- Commit Message ---
LU-20866 o2iblnd: return tunables setup error

kiblnd_tun_defaults() returns 0 when kiblnd_tunables_setup() fails.
Thus, lnet_genl_parse_local_ni() never rejects a NI whose default o2ib
tunables are invalid (e.g. a bad ib_mtu module parameter). The failure
is only caught later in kiblnd_startup(), with "Error -22 starting up
LNI" instead of "default tunables are invalid".

Test-Parameters: trivial
