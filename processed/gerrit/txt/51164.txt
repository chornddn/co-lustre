--- Commit Message ---
LU-16858 build: Remove pinger config option

Lustre is never built or tested without the pinger, so the
--enable-pinger/--disable-pinger configure option and
CONFIG_LUSTRE_FS_PINGER are removed and the code they
guarded becomes unconditional.

A site which does not want pings (historically Cray) can
still suppress them at runtime with the servers'
suppress_pings module parameter.
