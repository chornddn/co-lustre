--- Commit Message ---
LU-20597 utils: handle sparse OST indices in quota

llapi_get_obd_count() returns different values for MDTs and OSTs.
For MDTs, it returns the target array size, which covers sparse
indices but also includes holes. For OSTs, it returns the number of
configured targets.

print_obd_quota() and lfs_reset_quota() treat this value as a dense
upper bound. A filesystem with eight OSTs at indices 256 through 263
is therefore queried at indices 0 through 7. print_obd_quota() omits
the existing OSTs, while lfs_reset_quota() can return without checking
whether grants on those OSTs have been reset.

lfs_reset_quota() also retains wait_index when switching from MDTs to
OSTs, which can skip the first OST entries after waiting for an MDT.
Its shared wait counter can leave the OST phase without enough time to
poll its targets.

Obtain the index-ordered target list with llapi_get_target_uuids() and
use the actual indices for quota queries. Use the same list for MDTs
to avoid probing holes. Reset both the array position and retry
counter before checking OST grants, giving each phase its own bounded
retry period.

Clear ignored -ENODEV and -ENODATA results before continuing to the
next target. Otherwise, an unavailable final OST can make a completed
quota reset return an error.

When the quota reset retry budget is exhausted, return -ETIMEDOUT.
Previously, lfs_reset_quota() printed an error but left rc as zero, so
a successful restoration of the quota settings made lfs setquota -r
return success.

Extend sanity-quota test 16b to verify quota output with sparse MDT
and OST indices. Create grants on MDT0064 and OST0064, block the
OST0064 grant reset, and wait until the MDT0064 grant has drained
before verifying that the reset is still waiting for OST0064. Use
60-second timeouts for the MDT grant-drain and reset-completion waits
so a failed reset cannot hang the test.

Since fail_loc is node-global, run the reset verification only when
OST0064 does not share its host with an earlier OST or any MDT.
Request separate MDS and OSS hosts so the automated test exercises
the fail-injection path.
