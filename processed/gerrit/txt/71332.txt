LU-18687 build: add 'make <dir>' for single module directories

Building one kernel module directory on its own is useful when the
kernel already carries the rest of Lustre in-tree, e.g. osd-zfs
against an out-of-tree ZFS, or to rebuild a single module quickly.

Add a 'make <dir>' target for every kbuild directory under lnet/ and
lustre/ (lnet/libcfs, lustre/osd-zfs, ...). It runs kbuild on the
whole tree with LUSTRE_MODULE_SUBDIR set, and the top-level Kbuild
then limits obj-m to that directory, so it is compiled with the same
include paths and flags as the full build and no directory needs
changes of its own. The directory list is derived from the kbuild
Makefiles; o2iblnd keeps its dedicated targets.
