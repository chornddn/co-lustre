LU-21061 llite: keep default LMV pool when inheriting

With implicit inheritance the client makes the default LMV of a
subdirectory that has none on disk, such as one that existed before
its parent got a default.  The client drops it once max_inherit runs
out, so mkdir deep in such a tree is no longer limited to the MDTs
of the pool.

Add lmv_inherit_default() to make the default a subdirectory
inherits the same way the MDT does: a parent default that stops
inheriting still passes on its pool, with a single stripe on any
MDT and unlimited inheritance.  Use it in
ll_dir_default_lmv_inherit() and lmv_object_inherited(), which now
also compares pools.

Also give an "lfs mkdir" layout that names no pool the pool of the
parent default in ll_dir_setdirstripe(), so that the MDT allocates
its stripes from the same pool.
