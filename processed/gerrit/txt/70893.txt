DRAFT LU-21180 lod: add kunit lod_mdt_alloc_specific test

Add two kunit test cases for lod_mdt_alloc_specific(), the allocator
lod_prep_md_striped_create() uses for a striped directory with an
explicit MDT index or index range: one for is_specific=false
(round-robin from the starting index), one for is_specific=true
(exact MDT list), both exercising the local/master-MDT branch
(idx == ss_node_id) as well as the remote-MDT branch.

The local branch needs lod->lod_child and
lu_site2seq(ld_site)->ss_node_id, neither of which the existing
lod_mdt_alloc_rr/qos tests require. Add mock_tgt_set_node_id() to
fake ss_node_id, and register a mock_tgt at the master index
unattached to lod_mdt_descs, reachable only via lod_child, the same
way the real local MDT is reached.

Un-static lod_mdt_alloc_specific() and export it for the test module.
