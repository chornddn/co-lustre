--- Commit Message ---
LU-18687 llite: check mmap_lock with mmap_assert_locked()

our_vma() asserts that the caller holds mmap_lock by expecting
mmap_write_trylock() to fail.  The kernel removed that function in
v6.5-rc4-110-gcf95e337cb63, so it is only available through a
lustre_compat replacement.

Use mmap_assert_locked() instead, which checks the lock on kernels
built with lockdep or CONFIG_DEBUG_VM, and backfill it for kernels
that still have mmap_sem.  Remove the mmap_write_trylock() replacement
and its configure check.

Test-Parameters: trivial
