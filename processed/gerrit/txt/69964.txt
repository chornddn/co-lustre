--- Commit Message ---
LU-21023 mdt: return -ESTALE for a file migrated in getattr

A getattr that waited for the lock of a file behind its migration
then found it destroyed, and returned -ENOENT for a name that still
existed: a stat or test -e of the file failed.

- mdt: in mdt_getattr_name_lock(), return -ESTALE for a non-directory
  that is dying once its lock is granted, i.e. destroyed while this
  waited, e.g. unlinked or migrated. Do it both when it is revalidated
  by FID and when it is looked up for another MDT (mti_cross_ref), so
  a path-based call looks the name up again and finds the new FID.
  mdt_object_is_stale() holds the check for both.
- llite: in ll_inode_revalidate_fini(), clear nlink of a non-directory
  on -ESTALE as on -ENOENT, and log it at D_INFO, not D_ERROR.
