--- Commit Message ---
LU-21023 mdt: return -ESTALE for a file migrated in getattr

A getattr that waited for the lock of a file behind its migration
then found it destroyed, and returned -ENOENT for a name that still
existed: a stat or test -e of the file failed.

- mdt: for a non-directory that is dying once its lock is granted,
  return -ESTALE, both when it is revalidated by FID and when it is
  looked up for another MDT (mti_cross_ref), so the VFS looks the
  name up again and finds the new FID.
- llite: log -ESTALE from a revalidate at D_INFO, not D_ERROR.
