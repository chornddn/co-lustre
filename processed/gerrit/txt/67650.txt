LU-18681 mdd: no obd_obt_init() for mdd_object_alloc()

There is no need to call obd_obt_init() (target-device private
OBD device state) for every MDD object allocation.  Not only is
this expensive and useless, if that device were ever used then
the spinlock would be reset continually, making it also dangerous.

Found during code review of another patch.
