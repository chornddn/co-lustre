--- Commit Message ---
LU-20684 lod: timestamp component initialization

Set lcme_timestamp when a composite layout component first gets
storage objects.  Keep replay, NOSYNC, and EC timestamps, and leave
released placeholders unstamped.  Clear copied timestamps on SEL
repeat so the new component receives its own timestamp.

Older servers left unused timestamp fields dirty.  Accept plausible
initialization timestamps in liblustreapi and detailed getstripe
output, following the EC scrub rules.  Keep timestamps out of
the flag-only output.

Add PFL, SEL repeat, replay, and HSM restore coverage.  Use MDT0 for
the SEL timestamp bounds and document the output.
