--- Commit Message ---
LU-20344 lnet: scope LNetAddPeer primary to reachable NIDs

LNetAddPeer() takes the first non-loopback NID as the peer primary
and, when lock_prim_nid is set, locks it. A locked primary can
neither be deleted nor relabelled by discovery, so locking it on a
NID whose network has no local NI and no route wedges the peer
permanently.

In LNET_DISCOVERY_MODE_REACHABLE, scope the manual add path the way
lnet_peer_merge_data() already scopes the discovery merge: skip a
NID on an unreachable network via lnet_peer_discovery_skip_nid() so
the primary lands on a reachable NID. When none of the configured
NIDs is reachable, leave the primary unlocked rather than wedge it,
so discovery can settle a usable primary once a network comes up.

Modes ENABLED and DISABLED are unchanged.

test_242 drives LNetAddPeer() via "lctl add_uuid" and checks that in
LNET_DISCOVERY_MODE_REACHABLE the peer primary is kept off an
unreachable NID, and that an all-unreachable peer is left unlocked
rather than wedged.
