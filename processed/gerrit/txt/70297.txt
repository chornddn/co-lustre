LU-21088 osd-ldiskfs: wait for thaw before dropping prealloc

When an object on the orphan list leaves the cache, e.g. through the
lu cache shrinker in kswapd, osd_drop_preallocated_space() runs
ldiskfs_truncate(), which starts a journal handle. ext4 does not
block new handles on a frozen filesystem, so this can change a
target while a block-level snapshot (LVM, md, fsfreeze) is taken
and print a WARNING from ldiskfs_journal_check_start().

Take sb_start_intwrite() around the truncate, as ext4_evict_inode()
does, so the drop waits for the thaw.

conf-sanity: add test_174, freeze the MGS device with dmsetup suspend
and run the shrinker. It fails without this patch.
