--- Commit Message ---
LU-18847 mdt: return -ESTALE for stale layout on open

mdt_reint_open() returns the variable "result", and the out_child
cleanup path acts on "result" too. When the layout version check
fails, the GOTO assigns -ESTALE to "rc" instead of "result". Since
this branch is only reached with result == -ENOENT, the intended
-ESTALE is dropped and the client gets -ENOENT, so it does not
refresh its stale layout and retry the create as designed.

Assign -ESTALE to "result" so the correct error is returned.
