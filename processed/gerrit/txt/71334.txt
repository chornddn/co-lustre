--- Commit Message ---
LU-18687 build: include module.h by its kernel path

The in-kernel build of Lustre fails with:

  fs/lustre/include/obd_class.h:20:10: fatal error:
  'lustre_compat/linux/module.h' file not found

copy-builtin leaves include/lustre_compat behind.  The headers there
shadow the kernel ones through the include path, so the callers
must name the kernel header and not the compat directory.

Include <linux/module.h> in obd_class.h.
