LU-20076 tests: time remote commands on CI nodes

Not for landing.  Console markers from Maloo runs show a remote
command costs about 0.55 s on CI nodes, and about 0.35 s with ssh
connection sharing (69318), while the same do_node takes about
0.04 s with sharing on a VM test cluster.  A command the driver
runs locally also takes about 0.2 s in CI.  conf-sanity runs
over 40000 remote commands, so this cost is most of its run time.

Add sanity test_999p, which times the parts of a remote command
on the nodes it runs on: local fork and bash startup, lctl mark,
do_node with and without VERBOSE, new and shared ssh connections,
pdsh, and fork and bash startup on each server.  It also prints
the ssh, sshd and load settings that bear on the result.  Every
line it prints starts with TIMING_PROBE.

Test-Parameters: fortestonly testlist=sanity env=ONLY=999p mdscount=2 mdtcount=4
Test-Parameters: fortestonly testlist=sanity env=ONLY=999p fstype=zfs mdscount=2 mdtcount=4
Test-Parameters: fortestonly testlist=sanity env=ONLY=999p
