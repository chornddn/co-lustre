LU-20104 lnet: fix selftest session teardown and BRW bugs

Fix multiple issues in lnet-selftest that caused kernel
deadlocks, crashes, and stale sessions.

Split the server-side srpc_ev field on srpc_server_rpc into
separate srpc_bulkev and srpc_replyev, mirroring the client
side (crpc_bulkev/crpc_reqstev/crpc_replyev).  The single
shared event struct was reused for the bulk MD post and then
for the reply MD post, so a stale bulk UNLINK arriving after
the state machine had moved to REPLY_SUBMITTED was dispatched
against the now-rewritten ev_type=SRPC_REPLY_SENT and flagged
the reply as fired.  The wi then completed the RPC while the
reply MD was still in flight, and the eventual reply event
double-completed against a recycled RPC slot, leading to
INIT_WORK on a queued swi_work and a list_add corruption in
srpc_lnet_ev_handler (reported by James Simmons).  Also gate
SRPC_BULK_PUT_SENT and SRPC_REPLY_SENT on ev->unlinked so
that intermediate SEND/ACK events stop scheduling redundant
wi runs.

INIT_WORK the server RPC swi_work once at allocation in
srpc_service_init(); srpc_init_server_rpc() now resets state
via swi_reset_workitem() instead of re-running INIT_WORK,
which would reset the list_head of a work_struct a late
UNLINK event had already queue_work()'d.  Add an
srpc_completed flag so a stale queue_work after completion is
discarded rather than double-completing the RPC.

In srpc_handle_rpc(), call srpc_server_rpc_done() when a
server RPC workitem re-enters in SWI_STATE_DONE after an
async LNetMDUnlink event, preventing orphaned RPCs on
scd_rpc_active.  Completion now waits for both bulkev and
replyev to fire (ev_fired is initialised to 1 in
srpc_init_server_rpc, so unposted MDs do not block).

In sfw_remove_session(), stop and drain client-side batches
before deactivating the session, then drain server-side
RPCs with re-abort on each iteration.

In lstcon_session_end(), stop all active batches before
sending end_session RPCs.

Add lst_wait_until_timeout() and use it in
lstcon_rpc_cleanup_wait() to bound waits for console RPCs,
preventing infinite spins while holding ses_mutex.

Defer zombie session destruction from lst_test_wq to
lst_serial_wq via sfw_destroy_session_deferred(), avoiding
cancel_work_sync() deadlock on the same workqueue.

Fix BRW offset handling: mask offset with ~PAGE_MASK in
brw_client_prep_rpc(), allocate bulk with off+len in
brw_client_init(), and validate off+len <= LNET_MTU.

Add lnet-selftest.sh tests for session teardown stress,
BRW offset edge cases, and a workqueue list-corruption
race (teardown_race).

Test-Parameters: trivial testlist=lnet-selftest
