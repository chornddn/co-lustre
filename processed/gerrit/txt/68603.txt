--- Commit Message ---
LU-17000 obdclass: fix error pointer put in index backup

When lu_object_find_slice() fails, lustre_index_backup() leaves the
error pointer in "parent", turns backup off and falls through to the
exit path, which puts the object under a plain "if (parent)".  An error
pointer is not NULL, so dt_object_put_nocache() is handed it and
dereferences it.  Clear the variable on the error path.
