LU-20211 mdt: replace inactive OST objects past truncate size

A truncate to a non-zero size on a file with a stripe on an
unavailable OST still has to reach that OST, even when the truncate
discards all of the stripe's data.  Only truncate(0) replaced the
layout, since a full layout replace loses the data before the size.

If every stripe on an unavailable OST holds no data before the new
size, replace each of those OST objects with a new object of the same
stripe size on an available OST, using a single-stripe layout swap
with a volatile victim, and keep the rest of the layout and its data.
lod_layout_has_unavailable_stripe() lists the stripes and checks the
first file offset each one holds, also in the probe before
mdt_attr_set() takes the layout lock.  If any unavailable stripe holds
data before the size, or the layout has EC parity, keep the layout
and do a normal truncate.  lod_pick_replacement_ost() moves all
objects of one unavailable OST to the same new OST, so an overstriped
component keeps its stripes per OST, and picks that OST in the
component's pool with the most free space that the component does not
use yet.  If the component already uses every usable OST, e.g. it is
striped over all OSTs or its whole pool, reuse its OST with the most
free space that no other replacement took, and have
mdd_swap_single_stripe() mark a component that gets two objects on
one OST as overstriped, and clear it again if the swap is rolled
back.  A compressed component cannot be overstriped, so the swap
refuses it and its layout is kept.  If the new object lands on
another OST, it is not swapped in.  The single-stripe swap passes
the OST object FIDs in the FID order that mdd_swap_layouts() sorts
the two files into.

Return the requested size with MS_LAYOUT_REPLACED, not the MDT inode
size, which a DoM file does not update.  The client discards its
dirty pages from the page after that size before the layout change,
since the replaced objects hold no data before it.  A resent truncate
is reconstructed with the current layout for any size.

Add sanity/test_27xu for plain, DoM, pool, all-OST and overstriped
layouts, and a layout that must be kept.
