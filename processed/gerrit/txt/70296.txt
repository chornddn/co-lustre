--- Commit Message ---
LU-20076 tests: stop rpc.sh calling back to the MGS

Each rpc.sh call sources the config, which works out MGSNID from
the MGS node with three remote commands, each a second ssh for
its mark under VERBOSE. A timing trace on Maloo put this at most
of the 2.2 seconds a call costs before its command runs. Pass the
NID the caller already has.

The trace also found about 0.4 seconds in the tool lookups of
init_test_env, since EL's which() wrapper pipes every shell
function through /usr/bin/which. Drop the wrapper.

On a 3-node cluster with the MGS on its own node, a call fell
from about 2.3 to 0.65 seconds.
