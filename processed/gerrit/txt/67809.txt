LU-20561 tests: fix lock count retrieval in sanity-flr

get_osc_lock_count() matched client OSC namespaces using
ldlm.namespaces.-OST%04x-osc-[-0-9a-f]*.lock_count.

When a second client is mounted, another -OST%04x-osc- namespace
is created, so get_param returns one lock_count value per line.

Assigning this multi-line output to count causes
lock_count=$((lock_count + count)) to fail with an arithmetic
syntax error. As a result, in $(get_osc_lock_count ...), the
subshell exits before reaching echo, leaving the command
substitution empty. This causes test_22/test_31 to fail with
"unary operator expected" and "glimpse requests were sent".

Use total_used_locks() to sum the lock counts from all matching
namespaces. Pass ...-osc-[-0-9a-f] so the helper's *...* pattern
still matches client hex instance IDs while excluding OSP
namespaces such as ...-osc-MDT*.

Test-Parameters: trivial \
  testlist=sanity-flr env=MOUNT_2=yes,ONLY=22+31

Test-Parameters: trivial clientdistro=ubuntu2604 \
  testlist=sanity-flr env=MOUNT_2=yes,ONLY=22+31
