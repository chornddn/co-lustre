LU-18687 build: remove C plugin support

The plugin for detecting static functions has been superseded
by newer version of gcc/clang, along with checkers like
smatch/sparse. To simplify our transition away from autotools,
remove C plugin support. Developers could still manually pass
C flags to use C plugins, if desired.
