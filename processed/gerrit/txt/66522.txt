LU-20338 tcu: non-root user should see and unrm own file

This patch fixes the failure when non-root user access and unrm
files owned by itself.

When get the attributes (UID/GID/Projid) of a "pFID" stub
object, we locate the corresponding directory by parsing the
FID-format name from the LinkEA. And then return the attributes
of the directory instead of the "pFID" stub object itself, so
that when unrm the file, it can obtain the original attributes
from the "unrm" XATTR for the permission check.

Add a new test case sanityn/test_118z to verify the fix.

Test-Parameters: testlist=sanityn env=ONLY=118z,ONLY_REPEAT=10
