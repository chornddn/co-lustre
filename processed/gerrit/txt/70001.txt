--- Commit Message ---
LU-21027 utils: accept relative path for lctl dk raw

"lctl dk <file> 1" passes the file name straight to the kernel
dump_kernel control file, which rejects relative paths with EINVAL
("write(<file>) failed: Invalid argument").

Resolve the path with cfs_abs_path() before passing it to the kernel,
as jt_dbg_debug_daemon() already does for "lctl debug_daemon start"
(LU-8993). cfs_abs_path() also works when the output file does not
exist yet, as long as its parent directory does.

The filename is now allocated rather than kept in a PATH_MAX stack
buffer, so every exit path in jt_dbg_debug_kernel() goes through a
single "out" label that frees it. Existing return values are
unchanged.

Test-Parameter: trival
