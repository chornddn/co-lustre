LU-21027 utils: accept relative path for lctl dk raw

"lctl dk <file> 1" passes the file name straight to the kernel
dump_kernel control file, which rejects relative paths with EINVAL
("write(<file>) failed: Invalid argument").

Convert a relative file name to an absolute one using getcwd()
before writing it to the control file.

Test-Parameter: trival
