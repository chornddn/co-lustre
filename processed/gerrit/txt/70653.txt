LU-21172 lod: annotate on-stack timer in lod_ost_alloc_qos

lod_ost_alloc_qos() keeps its semaphore timer on the stack but
sets it up with timer_setup(). With CONFIG_DEBUG_OBJECTS_TIMERS
this prints "ODEBUG: object ... is on stack ..., but NOT
annotated", e.g. in recovery-small test_152.

Use timer_setup_on_stack() and timer_destroy_on_stack(). Linux 6.16
renamed destroy_timer_on_stack() to timer_destroy_on_stack(), and
el10.2 has the new name, so add a configure check that maps the new
name to the old one on older kernels.
