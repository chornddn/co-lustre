**Fix Applied:** Changed the expected size of `struct lnet_hdr` from 92 to 96 bytes in `lnet/lnet/wiretest.c`.

**Rationale:** 

The patch moved `lnet_assert_wire_constants()` from `api-ni.c` to a new `wiretest.c` file and added new wire constant checks. However, the check for `struct lnet_hdr` had an incorrect expected size.

The actual size calculation for `struct lnet_hdr` is:
- `dest_nid` (struct lnet_nid): 20 bytes at offset 0
- `src_nid` (struct lnet_nid): 20 bytes at offset 20  
- `dest_pid` (lnet_pid_t): 4 bytes at offset 40
- `src_pid` (lnet_pid_t): 4 bytes at offset 44
- `type` (__u32): 4 bytes at offset 48
- `payload_length` (__u32): 4 bytes at offset 52
- `msg` (union lnet_cmd_hdr): 40 bytes at offset 56

**Total: 56 + 40 = 96 bytes**

The original value of 92 bytes was incorrect and caused the compile-time assertion to fail. The fix updates this to the correct value of 96 bytes, which matches the actual structure layout as verified by the offset checks in the same file.
