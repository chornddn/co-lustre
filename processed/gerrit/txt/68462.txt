--- Commit Message ---
LU-20438 lnet: Implement distance-based PCIe P2PDMA routing

This patch completes the P2P hardware distance topology abstraction,
vastly optimizing network interface (NI) selection for GPUDirect RDMA.

By introducing the lnd_get_device callback on the LND, LNet statically
queries and evaluates the physical PCIe distance between the GPU
(page provider) and all active host configuration adapters (HCAs).
This ensures LNet bounds multi-rail transfers to perfectly matched NICs
collocated beneath the identical PCIe switch, sidestepping NUMA traffic.

Also includes robust m4 autotools validation to failover gracefully
to NUMA routing on legacy infrastructures lacking PCIe p2pdma heuristics.
