LU-20423 nrs: check LRU hit using the wrong TBF class bucket

In the nrs_tbf_cli_findadd(), when found a matched class bucket
from the hash table but with zero refcount, it should continue to
check LRU whether it is in LRU list or not.
But the current code uses the wrong class bucket to check LRU,
it should use the right class bucket which is found from the hash
table.
