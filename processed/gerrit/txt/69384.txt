--- Commit Message ---
LU-20869 tests: speed up sanity test_133h

test_133h ran one do_facet round trip per proc parameter to
check that each ends with a newline. Each facet has 700 or
more such parameters, so the test is dominated by process
and ssh startup rather than by reading the parameters. It
averages 14.5 minutes in CI.

Run the loop over the parameters once per facet on the
remote node and report only the names that fail, then dump
and fail on those as before. The same parameters are
checked with the same awk test, and a parameter without a
trailing newline is still reported.

On a local VM cluster (client, MDS, OSS with 4 OSTs; 709,
749 and 672 parameters on the client, mds1 and ost1) the
test went from 1462 seconds to 25 and 28 seconds.

Test-Parameters: trivial testlist=sanity env=ONLY=133h
