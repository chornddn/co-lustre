LU-21322 lfsck: keep a partial namespace LFSCK idle

When a namespace LFSCK finished with an MDT that failed or did not
join it, its status was LS_PARTIAL, which lfsck_namespace_setup() did
not know. On the next mount it printed "unknown lfsck_namespace status
8" and set the status to LS_CRASHED, so the MDT restarted the LFSCK
when recovery completed. lfsck_namespace_prep() reset only a completed
LFSCK, so that run and any later start without "-r" kept LF_INCOMPLETE
and were partial again, on every mount.

Keep a partial namespace LFSCK idle and start it from the beginning,
as layout LFSCK does. Resume a namespace LFSCK that its controller
failed, stopped or paused, as layout LFSCK does, without the message.

sanity-lfsck test_28b remounts an MDT whose namespace LFSCK is
partial, checks that it does not start again, then starts it without
"-r" and checks that it completes. test_28 becomes test_28a.
