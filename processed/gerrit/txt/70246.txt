--- Commit Message ---
LU-20896 osc: fix unused variable in non-llcrypt build

Without embedded llcrypt (CONFIG_LL_ENCRYPTION unset), the fallback
osc_encrypt_pagecache_blocks() macro drops its inode, index and
directio arguments, so a clang -Werror build of osc_brw_prep_request()
fails with:

  osc_request.c:1607:12: error: variable 'index' set but not used
  [-Werror,-Wunused-but-set-variable]

Make the fallback a static inline function with the same arguments
as the llcrypt version, so the caller does not depend on which
arguments the implementation uses.

Test-Parameters: trivial
