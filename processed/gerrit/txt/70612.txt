LU-21155 osd: fix cmp_key_txn function

the function is used to search in rbtree holding ldiskfs transactions:

int cmp_key_txn(const void *transaction, const struct rb_node *node)
{
	struct osd_thandle *oh = container_of(node, typeof(*oh), ot_node);
	transaction - (void *)oh->ot_transaction

this way the function is supposed to return -1, 0 or 1 to direct the
search to right direction and return 0 if pointers match. the problem
occurs when pointers have large diff - the function does sutraction,
but then casts the results to low 32bits (int):

(gdb) p (0xff181498a9a50180 - 0xff181499a9a50180) & 0xffffffff
$3 = 0
