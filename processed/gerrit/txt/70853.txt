DRAFT LU-21180 lod: add kunit coverage for pool spill logic

Add kunit coverage for lod_spill_target_refresh() and
lod_check_and_spill_pool(), the QoS-driven pool spill logic that
redirects allocation away from an over-full pool to its configured
spill target. Export both from lod_pool.c so lod_pool_test.ko can
link against them.

Tests cover: spill check skipped while pool_spill_expire is still in
the future, skipped when spill is disabled (threshold_pct == 0),
is_active left false below the threshold and set true at/above it,
and lod_check_and_spill_pool() redirecting a pool name to its spill
target and incrementing pool_spill_hit, including the no-name case.
lod_qos_statfs_update() is made a no-op via obd_osfs_age so the tests
exercise lod_spill_target_refresh()'s own math over the mock targets'
cached ltd_statfs data.

Also add the new functions to lod/KUNIT.list so lustre/kunit/ku's
file-selection picks up lod_pool_test on changes to them, and add the
lod_pool_add()/lod_pool_remove() entries missed by an earlier commit.
