LU-21061 lod: keep default LMV pool for subdirectories

A default LMV that names a pool keeps a subtree on the MDTs of the
pool only for as many levels as it is inherited: the default given
to a new subdirectory is rebuilt without the pool, it is dropped
once max_inherit runs out, and with implicit inheritance it is not
stored on the subdirectory at all.

Copy the pool into the default LMV of a new subdirectory.  When the
parent default stops inheriting, give the subdirectory a default
with only the pool, a single stripe on any MDT of the pool and
unlimited inheritance.  Store the default of a new subdirectory if
it has a pool, also with implicit inheritance, so that the MDT can
find the pool of the directory.  A pool that lists only OSTs is kept
the same way, so that new files deep in the tree stay on its OSTs;
subdirectories there are then placed by space usage rather than
always on the parent MDT.
