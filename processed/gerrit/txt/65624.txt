LU-20210 utils: add nodemap RBAC roles to rustreapi

Bind enum nodemap_rbac_roles from lustre_idl.h as a rustified enum
in lustreapi-sys.  It only carries the constants: an nmf_rbac mask is
not a variant, so it must never be built from a raw mask.

Add rustreapi::nodemap with RbacRole, a bitflags mask of the roles.
From<nodemap_rbac_roles> matches every variant, so a role added to
the C enum fails to compile until RbacRole has it.  from_mask()
converts a raw mask: it maps NODEMAP_RBAC_ALL and any NONE sentinel,
whose value depends on the headers it came from, and drops unknown
bits.  Serde uses the kernel's comma-separated lowercase role names,
accepts "all" and "none", ignores case and skips unknown names.

Roles were added in 2.15.5x-2.17.5x development releases, so the
LUSTRE_2_* features cannot tell which ones the headers have.
lustreapi-sys probes the bindings and passes the role names to
rustreapi's build.rs, which sets the rbac_role cfgs.
