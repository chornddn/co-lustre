LU-20611 llapi: skip a scanned inode reused mid-read

lfs find --target, --local and --fsname read targets in service.  A
scan reads an inode's external xattr block after the inode, so the
inode can be freed and reused by another file in between, and the
record gets that file's xattrs.

After reading an external block, scan_inode_unchanged() reads the
inode again and skips the object if its generation or xattr block
changed.  It uses pread() because ext2fs_read_inode() would answer
from its inode cache.  Only objects with an external xattr block pay
for it.  Also set "cache=off" on the worker's io channel, so a cached
xattr block that has since been given to another file is not read.
