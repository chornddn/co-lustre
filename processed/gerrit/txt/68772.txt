--- Commit Message ---
LU-20714 lov: do not read uninitialized lum in getstripe

lov_getstripe() skips the copy_from_user() into lum for a foreign
layout but still tests lum.lmm_magic. Nothing writes lum on that
path, so the test reads uninitialized stack, which measures as a
different arbitrary value on every call. When one matches
LOV_USER_MAGIC_V1 or V3, lum_size is computed from an equally
arbitrary lmm_stripe_count and truncates the foreign layout copied
back to the caller.

Compute lum_size only where lum has been filled in.

Test-Parameters: trivial
