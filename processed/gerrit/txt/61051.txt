LU-7426 osp: enable indexed llogs

Create the update log catalogs (lod) and the MDT-OST sync log catalogs
(osp) as indexed llogs. The changelog catalogs are not switched here.

An existing catalog keeps the format it was created with, so an
upgrade needs no conversion, and only a catalog created by this code
is indexed. Code from before indexed llogs cannot use an indexed
catalog, so a filesystem on which this code made a catalog can not be
downgraded to that code.

Some concerns, see inline comments. This switches the on-disk format of the update-log and OSP sync catalogs to the indexed layout by default, with no compatibility gate. There is also a pre-existing issue in the parent change that this patch makes reachable on every MDT: in llog_osd_idx_init(), each error path calls up_write(&lgh->lgh_last_sem) and then does GOTO(out, ...), and `out:` calls up_write() a second time. If dt_record_write() fails while the index blocks are being set up (for example -ENOSPC/-EIO locally, or an OSP packing error for a remote update log), the rwsem is released twice. That is probably best fixed in the parent change rather than here.
