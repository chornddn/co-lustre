--- Commit Message ---
LU-20808 mdd: no attribute read for the ancestor walk

mdd_is_subdir() reads the attributes of the directory it starts from,
but the walk only passes them to the ".." lookup that mdd_parent_fid()
falls back to, and that lookup checks no permission. They are never
used.

For a remote directory the read is a synchronous RPC, and a rename
pays it before it takes its locks: the walk that orders the parent
locks starts from the source parent, whose cached attributes were
dropped when the previous operation released its lock on it. Drop the
read and pass no attributes.
