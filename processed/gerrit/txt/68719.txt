LU-20714 llite: bound-check foreign symlink upcall buffer

foreign_symlink_upcall_info_store() parses a root-supplied sysfs
buffer without checking that an item fits in the bytes left. A
truncated POSLEN_TYPE item is read past the end and underflows
the size_t "remaining", so the loop then walks memory. The
STRING_TYPE guard subtracts the item header and the EOB size from
"remaining", which underflows the same way, so it passes and an
attacker-chosen item->size is memcpy()ed from past the buffer. A
format ending on a complete item is accepted with no EOB_TYPE
terminator, so a later readlink() overruns the path buffer.

Reject any item that does not fit and formats without a
terminator, let a string that exactly fits through, and add
sanity test 27Pa.
