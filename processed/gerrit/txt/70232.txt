--- Commit Message ---
LU-20923 lod: reject a remote striped create with no layout

lod_declare_striped_create() cannot select OST objects for a remote
object, so the caller must supply the stripe layout (lovea), which
normally happens only during migrate (mdd_migrate_create).  Return
-EINVAL when the layout is absent, so a remote striped create with no
layout fails cleanly instead of proceeding without one.
