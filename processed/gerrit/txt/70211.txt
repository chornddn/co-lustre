--- Commit Message ---
LU-20879 obdclass: add a helper to classify the object mode

Add dt_mode_is_valid() and return a distinct DFT_INVALID from
dt_mode_to_dft() for a mode whose type is not a known file type, so
the object mode can be classified in one place.  dt_declare_create()
and dt_create() return an error for an object format of an
unrecognized type.
