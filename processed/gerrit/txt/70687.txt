LU-21182 osd-ldiskfs: round max object size down to PAGE_SIZE

On a server with 64KiB pages, a write to the last page of an ldiskfs
object fails with -EFBIG, so sanity 44b, 44c and 44e fail.  The
maximum object size is s_maxbytes, 2^44 - 4096, which is not a
multiple of the page size.  The last 64KiB page is only partly
addressable, and osd_ldiskfs_map_inode_pages() rejects any page that
reaches past s_maxbytes >> PAGE_SHIFT.  With 4KiB pages the limit
is page aligned and this never happens.

Report and enforce the limit rounded down to PAGE_SIZE through
osd_maxbytes(), in osd_statfs() and osd_conf_get().  This changes
nothing for 4KiB pages and costs less than 64KiB of the limit
otherwise.

Make sanity/44b use a write offset below the reported limit, as that
limit can now be lower than 2^44 - 8192.
