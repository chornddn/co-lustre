DRAFT LU-21180 lod: add kunit coverage for lod_pool_add/remove

The lod_pool kunit module covered lod_set_pool(), the pool registry
lookups and lod_qos_set_pool(), but not lod_pool_add()/lod_pool_remove(),
the functions that actually back "lctl pool_add"/"pool_remove": adding
or removing an OST from a named pool by UUID, matched against the
device's lod_ost_descs table.

Extend lod_pool_test with a small lod_ost_descs table built via the
shared mock_tgt helpers (see mock_tgt.h), and add cases covering:
adding a known target to a pool, rejecting an unknown target name,
rejecting an unknown pool name, and removing a known target (checked
via lod_check_index_in_pool()) while rejecting a target name the
device doesn't know about.

lod_pool_add()/lod_pool_remove() were not previously exported, so
export them for use from the kunit module, matching the other
lod_pool.c entry points.
