LU-20212 lov: skip invalid OST mirrors for aggregate I/O

I/O that aggregates stripe-local results into one logical answer
(glimpse, lseek, data_version) cannot succeed on a mirror while
any relevant OST import is deactivated or invalid.

In lov_io_mirror_init(), skip mirrors with unreachable OSTs in the
I/O extent during FLR selection for aggregate I/O.  When every
mirror is skipped, glimpse (ndelay) returns -EAGAIN after backoff
so the caller retries, and -EIO once it has tried all mirrors
several rounds; lseek and data_version fail with -EIO at once.

For designated-mirror I/O, apply the same extent-scoped check after
resolving ci_designated_mirror; there is no alternate mirror to try,
so return -EIO immediately.

Detect unreachable stripes with lov_mirror_extent_unreachable(),
limited to stripes intersecting the current I/O extent, via
lov_sub_unreachable().

Skip parity mirrors for glimpse and data_version as well, so they
never return parity object size or version.  Size FLR ndelay rounds
by the data mirrors that can serve the I/O, not lo_mirror_count, for
I/O types that skip parity; this also excludes stale mirrors from
the round of a plain FLR read.  CIT_EC_RD skips that rotation.
Add sanity-flr 31b.
