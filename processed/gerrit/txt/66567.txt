--- Commit Message ---
LU-20212 lov: Fail fast on glimpse with deactivated import

During a glimpse RPC, if any stripe belongs to a deactivated
import, a partial glimpse cannot determine the End-of-File (EOF).
As a result, a subsequent getattr may either hang or incorrectly
infer the file size using only the reachable stripes.

To prevent these hangs and inconsistent size calculations, fail
fast and return -EAGAIN when a deactivated import is encountered.

Add test sanity-ec 42a,42b.
