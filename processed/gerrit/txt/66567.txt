--- Commit Message ---
LU-20212 lov: avoid partial glimpse with deactivated import

During an FLR glimpse, if any stripe on the selected mirror has an
inactive import, glimpse RPCs to the remaining active stripes cannot
yield an authoritative EOF.

In this patch, we skip mirrors containing inactive stripes during
glimpse mirror selection. This significantly reduces redundant RPC
overhead by avoiding send RPCs to active stripes on a degraded
mirror, where a partial glimpse would otherwise yield unusable
results. If no mirror is available, return -EAGAIN so the glimpse
caller can retry after ndelay backoff, in case of transient error.

Skip parity mirrors for glimpse as well.

Add test sanity-ec 42a,42b.
