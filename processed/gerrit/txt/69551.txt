--- Commit Message ---
LU-20918 build: install modules under /usr/lib on SLES 16

SLES 16 is usr-merged, and weak-modules2 only searches
/usr/lib/modules for kernel modules. Modules installed under
/lib/modules are not seen by it, so they are not handled when the
kernel package is updated.

For suse_version >= 1600, make lustre.spec.in use /usr/lib/modules:

- set modules_fs_path to /usr/lib/modules/%{_kver}/%{kmoddir}
- after "make install", move $RPM_BUILD_ROOT/lib/modules to
  $RPM_BUILD_ROOT/usr/lib/modules and remove the empty lib directory
- run the find-debuginfo.sh chmod step on /usr/lib/modules

Other distributions continue to use /lib/modules.
