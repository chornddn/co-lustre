LU-19836 tests: fix recovery-small 17b and 26b interop

With master servers, recovery-small 17b and 26b fail when run
from this branch's scripts, as in the interop CI sessions.

17b searches all of /sys for ldlm_enqueue_min, which on newer
servers also matches the ldlm and per-target tunables. The
saved value is then written to read-only files and the test
fails with 126. Search /sys/module only, as master does.

26b only waits for a multiple of TIMEOUT for the eviction,
which is too short for the later eviction of newer servers.
Use master's wait, which allows for ldlm_enqueue_min, set
at_max before the export gets its deadline, and wait for
the imports to be connected before counting exports.

Test-Parameters: trivial testlist=recovery-small env=ONLY=17b
