LU-17047 tests: sanity/77c ensure ost debug_path is valid

test_77c has been failing intermittently for a while due
to either debug_param not being set properly before this test is
invoked or due to silent failure of getting the param from the
remote node.

Try to avoid these spurious test flakiness by forcing the
debug_path parameter to the expected setting during test startup.
A test shouldn't depend on no residuals being present from
unrelated prior tests anyway.

The rolling-downgrade sessions run the b2_15 sanity.sh against
master servers, so the fix that landed on master never reaches
them and 77c fails there on nearly every run.
