LU-13745 tests: test splice() reads with PCC-RO

There is no test that splice() of a PCC-RO cached file reads from
the PCC copy through pcc_file_splice_read().  splice-test writes the
file before splicing it, which would invalidate a PCC-RO copy.

Add a -n option to splice-test to splice an existing file without
writing it, and copy the spliced data to stdout, so that it can be
compared with the expected data.  Also count the bytes actually read
from the pipe, not the requested size.

Add sanity-pcc test_21k to splice a PCC-RO cached file, with and
without O_DIRECT and a concurrent pipe reader, and check that no
read RPCs are sent to the OSTs and the data matches the PCC copy.

Test-Parameters: trivial testlist=sanity-pcc
