--- Commit Message ---
LU-21061 mgs: allow adding MDTs to pools

lctl pool_add and the MGS accept only OST names, so a pool cannot
limit which MDTs a directory tree uses.

Accept MDT names in check_and_complete_ostname() and
mgs_pool_check_ostname(), checking them against the MDT index map.
Refuse MDT0000 in the MGS with -EPERM: it holds the root and the
filesystem-wide services, so it is never part of a pool.  Print "MDT"
instead of "OST" in the lctl messages for MDT members.

On an MDS, llapi reads pool members from a local LOD, which now lists
MDTs too, but it assumes a pool has no more members than there are
OSTs: llapi_get_poolmembers() prints the "Pool:" header again when its
caller retries with a larger buffer, and print_obd_quota() prints
nothing for such a pool.  Print the header only once the members are
read, and size the pool quota list for OSTs and MDTs, skipping the
MDTs.

Clients keep ignoring MDT members until they learn about them.
