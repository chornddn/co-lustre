--- Commit Message ---
LU-21061 mgs: allow adding MDTs to pools

lctl pool_add and the MGS accept only OST names, so a pool cannot
limit which MDTs a directory tree uses.

Accept MDT names in check_and_complete_ostname() and
mgs_pool_check_ostname(), checking them against the MDT index map.
Refuse MDT0000 with -EPERM: it holds the root and the filesystem-wide
services, so it is never part of a pool.  Print "MDT" instead of "OST"
in the lctl messages for MDT members.

Clients keep ignoring MDT members until they learn about them.

Test-Parameters: trivial mdscount=2 mdtcount=4 testlist=ost-pools
