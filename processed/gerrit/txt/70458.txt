LU-21061 lmv: keep deactivated MDTs inactive at mount

A client that mounts while an MDT is deactivated in the configuration
(lctl conf_param FSNAME-MDTxxxx.mdc.active=0) still uses it:
lmv_connect_mdc() marks the target active although its MDC import
stays deactivated.  New directories placed on it fail with -ESHUTDOWN,
and lmv_statfs() and lfs df ask it for statistics.

Take ltd_active from the deactivated flag of the MDC import in
lmv_connect_mdc(), as LOV leaves an administratively disabled OSC
inactive, and set OBDF_INACTIVE to match; reactivation still goes
through lmv_notify().  Count only active targets when
lmv_check_connect() fails, and give inactive MDTs the EA sizes too, so
they have them once activated.  Skip inactive MDTs in lmv_statfs(),
which now starts the sum from the first MDT that answers rather than
the first one tried, and returns -ENODATA when none does.  This also
fixes a sum whose first MDT failed, which was added to a result that
was never set.  Also stop OST0001 at the end of conf-sanity
test_50i, which stopped OST0000 twice and left OST0001 mounted for
the next test.
