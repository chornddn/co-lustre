LU-21208 lod: bounds-check OST index in lod_alloc_ost_list

lod_alloc_ost_list() validates each OST index from a user-defined
specific-OST striping with test_bit(ost_idx, m->lod_ost_bitmap),
but never checks ost_idx against m->lod_ost_descs.ltd_tgts_size
first. lod_ost_bitmap is grown lazily by ltd_add_tgt() only up to
the highest index actually registered, so an out-of-range ost_idx
(e.g. a stale or mistyped OST index never added to the target
table) makes test_bit() read past the end of the allocated bitmap.
The resulting garbage bit can appear set, letting the bad index
through to LTD_TGT(), which returns NULL, and that NULL reaches
lod_statfs_and_check()'s LASSERT(tgt), crashing the MDS with an
LBUG instead of returning -EINVAL.

Add the same ltd_tgts_size bounds check already used by
validate_lod_and_idx() in lod_lov.c before calling test_bit() in
lod_alloc_ost_list().
