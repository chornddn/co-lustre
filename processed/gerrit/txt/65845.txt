LU-20099 nrs: add minimum bandwidth guarantee for mClock

Implement the mClock NRS scheduling algorithm on the abstract
classful rule-based NRS framework. The scheduler gives a minimum
bandwidth guarantee (a reservation) to a Lustre service. The NRS TBF
policy gives the same guarantee. A red-black tree sorts the class
buckets by their reserved deadline, which comes from the reserved
rate.

The reservation (R) tier lands here. The limit (L) tier and the
weight (W) tier come in later patches of this series.

The function nrs_req_time_nsecs_calc() now gives the IOPS cost to a
bulk request that names zero pages. A rule that holds no IOPS mode
gave such a request a cost of zero.

A high priority move can remove a request that no thread served.
The function nrs_mclock_req_del() therefore leaves the class bucket
in its red-black trees, and it keeps the deadline. The insert
already charged the bucket for that request. A second charge gives
the bucket less than its reserved rate.

The tests sanityn/test_77j, test_77k, test_77kc and test_77ub now
take a policy name, so the mClock tests run the same checks.

Add sanityn/test_77v{a,b,c,d}.
