--- Commit Message ---
LU-19943 mdt: prepare for QMT0000/FLOCK sharding

Several MDT paths used IBITS DLM locks, but quota and flock locks
use PLAIN DLM locks.  Handle the differences properly in namespaces
so that when the QMT lock handling is split across MDS nodes in the
future the different lock types can be distinguished properly.

 - mdt_intent_policy() mostly process metadata intent locks as an
   IBITS lock, except the quota intents (DQACQ and CONN), which use
   PLAIN locks handled by the quota master that shares the namespace,
   and should also be allowed.
 - mdt_object_unlock() should ignore a NULL lock handle
 - fix a cleanup error in mdt_reint_migrate() that returned with the
   source and target parent locks held when mdt_migrate_links_lock()
   failed with an error other than -EBUSY; use the right error label
