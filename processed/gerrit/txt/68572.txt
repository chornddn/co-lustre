--- Commit Message ---
LU-20682 llite: guard NULL value in ll_xattr_set()

removexattr(2) reaches ll_xattr_set() with value == NULL, but the LOV
EA byte-swap branch loads value->lmm_magic and the LMV branch loads
lmu->lum_magic before anything else, so removexattr of a suffixed
lustre.lov.<x> name or of lustre.lmv oopses the client.  Any user who
can write the file can trigger it.  Skip both branches when value is
NULL.
