--- Commit Message ---
LU-20682 llite: guard NULL value in ll_xattr_set()

removexattr(2) reaches ll_xattr_set() with value == NULL, but the LOV
EA byte-swap branch loads value->lmm_magic first, so removexattr of a
suffixed lustre.lov.<x> name oopses the client.  Any user who can
write the file can trigger it.  Skip the swab branches when value is
NULL.
