LU-20787 tests: wait_osp_import() to initiate recovery

waiting for FULL state can find import when it hasn't detected
eviction yet. so we have to send an RPC to check it's current
state and initiate recovery if it's evicted.
this fixes spirious errors in tests like sanity-lfsck/44 when
a preceeding subtest doesn't check import's state properly.
