LU-20564 utils: probe md geometry under dm-linear OSTs

mkfs.lustre gave up on a device-mapper device with more than one
slave, so a hybrid OST (LU-20924), a dm-linear device with a mirror
for the ldiskfs IOPS groups followed by a parity array for the data,
got no stride/stripe_width.  mke2fs then took them from the stacked
io_min/io_opt, which gives the mirror's chunk as the stride, and no
stripe_width at all on flash.  Unaligned 1MiB writes on the parity
array are partial-stripe writes.

For a dm device whose targets are all linear, read the table with
the DM_TABLE_STATUS ioctl and take the geometry from the parity
segments (raid4/5/6 or raidkm), skipping mirror, raid0 and plain
segments.  All parity segments must have the same geometry.  Since
mballoc aligns to fs block 0, warn at mkfs about each parity segment
that does not start a whole number of rows from a row boundary of its
array, following its offset through partitions and dm-linear layers
down to the array.  Also warn about each boundary between a parity
and another segment that is not on a block group boundary, since
mke2fs -E iops= marks only whole groups.  The mount-time stripe check
uses the same probe, so it now also checks such devices.

Patch Set 1:

Tested on an el9.7 server (kernel 5.14.0-611.42.1) with loop-backed arrays. The mirror is md raid10 n3 with a 512K chunk. The parity array was md raid6 8+2 with a 128K chunk, and then a live raidkm 8+2 with a 128K chunk, once plain and once with --lost-list=stash-meta. 17 of 17 cases pass with each parity array:

- dm-linear mirror + parity: stride=32 stripe_width=256 are set, and there is no warning when the layout is aligned.
- A parity segment off a row warns: off in the dm table, off in its array, on an md partition, in an LVM linear LV, and in the same LV with dm-cache attached. Only the bad segment is named (3-segment case).
- A mirror/parity boundary off a block group warns, with the parity segment first or last.
- Mirror + plain disk, and dm-striped, are not seeded, as before.
- A plain parity array is seeded as before.
- mount.lustre warns when the stripe_width does not match the row of the parity segment.
