LU-21132 build: drop redundant kswapd checks

Linux commit v7.3-rc5-546-g27517f701ff3 ("mm: replace PF_KSWAPD flag
with kthread_func() check") removed PF_KSWAPD, breaking builds in
osd_object_delete() and qsd_start_reint_thread().

Drop the PF_KSWAPD checks instead of replacing them with
current_is_kswapd().  kswapd and direct reclaim both run with
PF_MEMALLOC set, so PF_KSWAPD was only ever set when PF_MEMALLOC was
too.  The one exception is a softirq running on kswapd's stack, where
PF_MEMALLOC is masked.  However, these functions can sleep and so are
never called from softirq context.
