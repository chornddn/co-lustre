LU-12669 ec: EC feature test build (DO NOT LAND)

A test vehicle, not for landing. It squashes the open changes below,
at the patchsets listed, onto master 6325870717 (v2_17_60) so that
they can be built and tested together: every open change with both the
218_review_priority and pt_ecro hashtags as of 2026-10-26, plus the
changes marked * or +. It is refreshed as they get new patchsets.

68361 (LU-20690) stores EC parity as LOV_PATTERN_PARITY and no longer
accepts the RAID0|PARITY encoding of master, so EC files must be
created with this build.

64441 (LU-12187 layout pattern negotiation) is applied after 62868,
which drops the module parameters 64441 negotiates with.  The local
fix after 64441 keeps the negotiation with FLR EC on by default
(enable_flr_ec=1, mdt_enable_flr_ec=1).

64919 ps52 and 69392 both make an EC read that parity cannot rebuild
wait for its stripes' OSTs instead of failing: 64919 changes sanity-ec
test_29a to expect it, and 69392 implements it (cl_io::ci_ec_wait),
with the same test_29a and a new test_29b.
