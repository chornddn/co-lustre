--- Commit Message ---
LU-21336 tests: ask LNet for a node's NIDs

h2name_or_ip() built a NID for each address from "hostname -I", so a
node with a second ethernet interface got NIDs that LNet does not
listen on, and a client given one as a target's failover peer retried
it forever.

Use host_nids_address(), which already asks LNet, and fall back to the
old guess when the module is not loaded.  A literal IP still maps to a
single NID for callers that want one rail.  Set LCTL before the config
file is sourced, since cfg/*.sh calls h2nettype.
