LU-21061 lod: put new file objects on directory pool

A default LMV that names a pool keeps the subdirectories of a tree
on the MDTs of the pool, but the objects of new files in the tree
still go on any OST.

In lod_ah_init(), give each component of a new regular file that
names no pool the pool of the parent's default LMV, if the pool has
OSTs.  DoM and foreign components are left alone, and a default file
layout that names a pool still wins.  The parent's default LMV is
read only when the MDT has pools.  Files in a subdirectory whose
default LMV is only on the client, such as one that existed before
its parent got a default, are not limited.

Open-creates from one process into a directory on MDT0 do not slow
down (single VM, 4 MDTs, 3 OSTs, 10000 files, median of 3 runs):

  no pool in the filesystem                6243 creates/s
  a pool exists, directory names no pool   6254 creates/s
  directory default LMV names the pool     6330 creates/s

Test-Parameters: mdscount=2 mdtcount=4 testlist=ost-pools
