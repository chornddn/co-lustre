--- Commit Message ---
LU-21060 osc: add OSC job statistics

- Managed Lustre users cannot read server jobstats.  Add per-job OSC
  counters on the client, with no server or wire change.  Collection
  is off by default.
- Add osc.*.enable_job_stats, osc.*.job_stats and
  osc.*.job_cleanup_interval.  job_stats is a root-only debugfs file
  with the server YAML format; job IDs, removal and expiry work as on
  the servers.
- Keep the stats in client_obd.  after_reply() calls a per-device
  callback for successful replies, and ptlrpc_jobstats_log() counts
  them under the job ID of the request.
- Count OST operations by their obdfilter names, and the BRW payload
  bytes really transferred with round-trip and ptlrpcd queue time.
- Client output has its own header record, so seq_file can retry a
  large record.  A complete read expires idle jobs.  A named removal
  claims expiry first, so concurrent clears drop one reference only.
- Limit client insertion retries, so concurrent expiry cannot keep an
  I/O in the accounting path.
- Add man pages and sanity tests 205q, 205r, 205v, 205x and 205z.
