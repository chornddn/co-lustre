LU-930 doc: add detail to llapi_fid2path_at(3)

The llapi_fid2path_at() man page didn't adequately explain how to use
the linkno and recno parameters. This made it difficult for users to
understand how to print out every path for files with multiple
hardlinks. I had to read the source code for lfs_fid2path() to figure
out how to correctly use the API.

This adds an explanation of the parameters and an example so that it
will be more obvious how to use the API.
