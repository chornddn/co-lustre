LU-20758 tests: fix sanity/63c OST_SYNC upper bound

fix sanity/63c OST_SYNC RPC range from [stripes, 2*stripes)
to [stripes, 2*stripes].

sanity.sh test_63c writes a fully striped file and expects the
OST_SYNC RPC count to be in the range [stripes, 2 * stripes),
but a valid run can reach exactly 2 * stripes
when both close-triggered CL_FSYNC_ALL
and background/reclaim CL_FSYNC_RECLAIM sync each stripe.

That legitimate upper bound is currently excluded by the strict
`<` comparison, causing an off-by-one failure such as:

  sanity test_63c: @@@@@@ FAIL: expect OST striped 3208 == 3192 + 8

Change the upper bound from [stripes, 2*stripes) to
[stripes, 2*stripes] will fix this error.
