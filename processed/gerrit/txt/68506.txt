--- Commit Message ---
LU-17000 mdt: drop a dead object check in mdt_lvbo_fill()

out_put: is reached only after mdt_object_find() has returned a valid
object, so obj is neither NULL nor an error pointer there and the
guard on mdt_object_put() is dead.  Every exit that can run with obj
unset goes to out: instead, which does not put the object.

Reported by smatch as "variable dereferenced before check 'obj'".
