LU-11728 tests: skip connectathon for old clients in nfsv3

Interop sessions run the test scripts of the older client branch,
which still run connectathon under NFSv3. Its locking tests fail
with ENOLCK (LU-18649), so every such session fails
parallel-scale-nfsv3 test_connectathon. Master already skips the
test.

Skip it for clients older than the LU-18649 skip, through the
server-side except file rather than changing the old branches.
