LU-21033 lfs: dk use debug_path as temporary file

This patch allow user to specify the directory where to store the
temporary raw file used in lctl dk.
lctl manpage has been updated accordingly to explain how temporary
file is used.

Previous behaviour (debug_path is ignored):
 # lctl set_param debug_path=/var/tmp/lustre-dbg
 # strace -e file -f -o /tmp/dk1 lctl dk /tmp/lctldk1
 Dumping temporary raw file to /tmp/lustre-log1793022271.124874
 Debug log: 1102 lines, 1102 kept, 0 dropped, 0 bad.
 # grep lustre-log /tmp/dk1
 124874 stat("/tmp/lustre-log1793022271.124874", 0x7ffd54c23c30) = -1 ENOENT
 124874 openat(AT_FDCWD, "/tmp/lustre-log1793022271.124874", O_RDONLY) = 3
 124874 unlink("/tmp/lustre-log1793022271.124874") = 0

With this patch:
 # strace -e file -f -o /tmp/dk1 lctl dk /tmp/lctldk1
 Dumping temporary raw file to /dev/shm/lustre-log1793022256.124869
 Debug log: 43896 lines, 43896 kept, 0 dropped, 0 bad.
 # grep lustre-log /tmp/dk1
 124869 stat("/var/tmp/lustre-dbg1793022256.124869", 0x7ffc550d7650) = -1 ENOENT
 124869 openat(AT_FDCWD, "/var/tmp/lustre-dbg1793022256.124869", O_RDONLY) = 3
 124869 unlink("/var/tmp/lustre-dbg1793022256.124869") = 0
