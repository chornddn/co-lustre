LU-20055 llite: Disable vfs leases

Leases are used by nfs and applications that need certain guarantees
that I am not sure we can provide. All in-kernel cluster filesystems
(ceph/gfs2) disable them and only nfs4+ and cifs enable them.
As such I think we should follow suit and disable it on our end.
Add compatibility check since the option default flipped in current 7.x
Linux to mean "no setlease set = disable leases" but all current
RHEL releases supported (8, 9, 10) since kernel 3.18 have the opposite
meaning of "no setlease set = enable leases by default".
