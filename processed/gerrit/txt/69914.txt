LU-12328 llite: move a failed DIO read to the next mirror

A no-delay read RPC that fails completes with -EAGAIN
(brw_interpret()), and cl_io_loop() then restarts the read on the
next mirror.  For an O_DIRECT read the error only arrives in
ll_file_io_generic(), after cl_io_end(), from
cl_sync_io_wait_recycle().  Only EC files restart there, as
CIT_EC_RD, so an O_DIRECT read of an FLR file returned -EAGAIN to the
application when the OST of its mirror died with the RPC in flight:
once LNet gave up on the transfer, 50 s after an OSS powered off,
without the other mirror ever being tried.

Restart the read there too, unless every mirror was tried, so
lov_io_mirror_init() moves to the next one.  The DIO aio is reused:
clear the error that cl_sync_io_wait_recycle() leaves in its anchor.

Add OBD_FAIL_OSC_NDELAY_READ_FAIL to fail a no-delay read RPC on the
client, and sanity-flr test_33e, an O_DIRECT read of an FLR file
whose first read RPC fails that way.
