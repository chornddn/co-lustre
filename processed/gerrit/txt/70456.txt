--- Commit Message ---
LU-21061 llapi: keep new dirs of a migrated tree in the pool

After "lfs migrate -m -p POOL DIRECTORY", new subdirectories of
DIRECTORY can still be created outside the pool.  The MDTs set POOL
only in the default directory layout of a plain directory they move,
so DIRECTORY keeps its old default when it is already on an MDT of
the pool, and loses it when it is migrated to a striped directory.

In llapi_migrate_mdt(), once the tree is migrated, set POOL in the
default directory layout of DIRECTORY, keeping the rest of it apart
from an MDT index outside the pool, or give it a single stripe on any
MDT of the pool if it has none.
