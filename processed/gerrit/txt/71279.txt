--- Commit Message ---
LU-20687 libcfs: report a bad pointer in container_of_safe()

container_of_safe() returns an ERR_PTR() or NULL pointer unchanged.
No caller should ever pass one, but today this is silent and the bad
pointer is only noticed later, far from the cause.

Print an error and call dump_stack() when the pointer is bad.
Always use the libcfs macro instead of the one that some kernels
provide, so the check is present on every kernel.
