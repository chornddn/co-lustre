LU-20107 nrs: one ceiling per CPT for both scheduler heads

A global rule divides its rate over the scheduler heads that the start
command reaches. A command for both queues reaches two heads for each
CPU partition. The node tier change therefore divides the rate over
2 * ncpts. The ceiling holds. But the high priority head takes an I/O
RPC only under a blocking lock callback. Half of the node rate idles
in the common case.

A divisor of the partition count alone gives the other defect. The two
heads keep two clocks, so the pair can pass twice the partition share.
A limit rule must never pass its rate.

Give the node class one clock pair for each CPU partition: a limit
clock and a reserved clock. Both heads of a partition read and
advance that pair, and the divisor goes back to the partition count.
The high priority head still wins a tie, because
ptlrpc_server_allow_high() polls it first. Each pair takes a cache
line of its own, so one partition does not move the line of another
partition.

The reserved clock keeps the lag bound of the mClock reservation. A
backlogged class still wakes at most NRS_MCLOCK_RESVD_LAG_MAX behind
the current time. An idle class still wakes at the current time.
The bound now holds for the head pair, not for each head alone.

A re-key of a shared clock moves the class bucket in its tree. The
peek of the mClock trees therefore reads the minimum again, and the
TBF dequeue reads the heap root again. A throttle arms the whole
head, so it must never read a bucket that the re-key moved.

Add sanityn/test_77xj. The test measures one job under real high
priority traffic. It bounds the rate of the job by the node rate. It
also holds that rate to at least 70% of the partition share. A divisor
of the head count gives half the share and fails the test. The test
runs the same bounds against a rule that names the node rate as a
reservation.

The test first runs a plain rule as an environment probe. That rule
gives each head its own clock, so its rate is not a bar for the global
rule. A node that cannot reach the ceiling skips the test.

Documentation/man4/nrs_policies.4 gains a section for the node tier
keys of the classful policies. The section names the "global=1" key,
the nrs_hsch entry, and the new divisor of the node rate.

A rate change on a global rule uses the same divisor as the start.

This change replaces the 2 * ncpts divisor of the node tier change. It
stands on its own so that it can be reviewed apart, and can be
squashed into that change.
