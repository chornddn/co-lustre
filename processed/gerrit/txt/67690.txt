--- Commit Message ---
LU-20552 mdd: handle SEL and DEFINED magics in lmm oi/gen helpers

mdd_lmm_oi() and mdd_lmm_gen() only recognized LOV_MAGIC_COMP_V1.
Layouts with extension components use LOV_MAGIC_SEL (same composite
blob), so mdd_set_lmm_oi() during MDT migrate (mdd_xattrs_migrate_prep)
was a silent no-op and left the old MDT FID in lmm_oi.

Also recognize SEL in mdd_lmm_gen(). Mask LOV_MAGIC_DEFINED there so
generation updates succeed when swap applies a layout onto a layout-less
file (mdd_swap_layouts ORs that bit on the incoming LOV before
mdd_set_lmm_gen(); a two-way swap of existing layouts does not).
mdd_lmm_oi() masks DEFINED only for symmetry (its callers never pass it).
