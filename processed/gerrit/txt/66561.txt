LU-20344 lnet: rename lnet_push_update_to_peers()

In preparation for reachability-scoped discovery, generalize the peer
update helper. A following patch makes it re-ping peers (not only send
LNet Push messages) when a local configuration change in REACHABLE
mode may expose newly reachable NIDs, so the 'push_update' name and
the opaque 'int force' argument no longer describe what it does.

Rename it to lnet_resync_peers() and replace the 'force' int with an
enum lnet_peer_resync_reason (LNET_RESYNC_LOCAL_CFG /
LNET_RESYNC_PEER_STATUS) so the call sites read self-descriptively.
No functional change.
