--- Commit Message ---
LU-17501 tests: count CPU partitions in conf-sanity 200

On a node with 2 NUMA nodes, conf-sanity test_200c fails:

    CPU partitions not 2, found: 1

The cpu_partition_table output has 2 lines.  The test counts them
with "echo $table | wc -l".  The unquoted $table joins the lines
into one, so the count is always 1.  A VM with 1 NUMA node expects
1 partition, so the bug does not show there.

Quote the table in each partition count in test_200b and test_200c.
