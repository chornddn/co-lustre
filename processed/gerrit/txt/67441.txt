LU-19602 clio: keep mirror DIO tails out of page cache

A master client against 2.15 servers LBUGs in
__osc_lru_del() during sanity-flr test_70a, or fsx there
reads bad data.

I/O to a designated mirror, as "lfs mirror verify" does,
must be direct: the page cache is shared with normal I/O,
which takes its pages to belong to the mirror it uses
itself. Since LU-17525, direct I/O that is not page aligned
falls back to buffered I/O when a server cannot take
unaligned DIO, and a verify of a file with an unaligned size
reads its end with an unaligned length. Against 2.15 servers
that read leaves pages of the verified mirror in the cache,
stale ones included. Normal reads then return that data, and
a write to such a page queues it through the OSC of the
mirror being written, not the OSC of the page's own object,
and the LRU accounting split between the two underflows.

For designated mirror I/O to such servers, send an I/O from
a page aligned file offset into a single page aligned
buffer, whose only unaligned part is its length, as aligned
direct I/O, as before unaligned DIO, rather than fall back
to buffered I/O.

Also account an LRU page on the OSC of its own object when
it is used, put back on the LRU and deleted, so a page
queued through another OSC cannot underflow the counters,
and warn when one is.

Patch Set 7:

Rebased and updated this since LU-19602 is a 2.18 blocker. The root cause is "lfs mirror verify" against 2.15 servers: its unaligned tail read falls back to buffered I/O (LU-17525), leaving pages of the verified, possibly stale, mirror in the page cache, which later writes commit through another OSC. This patchset sends those tail reads as plain DIO and keeps your LRU accounting on the page's own OSC as a backstop. Against 2.15.8 servers locally, unpatched master hits the LBUG or fsx bad data on every test_70a run, and this passed 15 in a row. The interop sessions are optional because LU-20770 times them out until 69145 lands; 69506 changes the same fallback in ll_direct_IO(). Oleg, take it back over if you want.
