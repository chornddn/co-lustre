DRAFT LU-21180 kunit: add shared mock_tgt lu_tgt_desc helper

Add mock_tgt.ko, a KUnit helper module providing a mock target (a
dt_device + obd_export + struct lu_tgt_desc, as found in a
lu_tgt_descs table's ltd_tgt_pool/ltd_qos) with canned statfs
replies, an unavailability state (down, full, read-only, no create,
degraded, no precreated objects) and OSS/MDS node grouping. struct
lu_tgt_desc is common infrastructure used by both LOD (OST targets)
and LMV (MDT targets), so this mock is written against that shared
API rather than anything LOD- or LMV-specific, letting several test
modules share one fake target implementation instead of each
hand-rolling its own.

No test consumes it yet; later test commits depend on mock_tgt.ko.
