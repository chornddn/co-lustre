--- Commit Message ---
LU-20261 pcc: set file ra_pages with 0 when open a Lustre file

When open a Lustre file with PCC enabled on a client, it needs to
set the ra_pages with 0 explicitly to avoid the kernel readahead
occurring which Lustre does not support, especially when the user
is using PCC mmap I/O.

--- Message (Andreas Dilger, 2026-10-21 01:30:16.000000000) ---
Abandoned

Abandoned: this has no effect. do_dentry_open() calls file_ra_state_init() after the filesystem ->open() returns (v4.18, v5.14 and mainline), so f_ra.ra_pages set in pcc_file_open() is always overwritten. Master already sets ra_pages = 0 in the PCC read, splice and mmap paths for this reason, see the comment in pcc_inode_mapping_reset().
