--- Commit Message ---
LU-20499 tests: fix "No label for mdsN" when running auster on existing filesystem

- `setup_if_needed()` never called `init_facets_vars` when skipping
setup (`-N` flag) or when the filesystem was already mounted, leaving
`mdsN_svc`/`ostN_svc`/`mgs_svc` variables unset
- `convert_facet2label()` then failed with `"No label for mds1!"` for
any test that looked up a service label
- Fix: call `init_facets_vars` in both early-return paths (the `-N` path
and the already-mounted path); also move the `! do_setup` check after
the `nfs_client_mode` guard to preserve existing guard ordering
