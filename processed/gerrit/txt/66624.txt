--- Commit Message ---
LU-20360 utils: fix tunefs.lustre dropping mountfsoptions

tunefs.lustre exits rc 0 without writing when --mountfsoptions (-o)
is the only option given, silently dropping the new mount options.

The -o value lands in @mountopts and is copied into ldd_mount_opts
only after the "no change" memcmp shortcut from LU-19740 runs, so
@mop still matches disk and the write is skipped. Another ldd-
modifying option (e.g. --param) hides the bug by changing @mop.

Skip the shortcut when mount options were given, so the later
ldd_mount_opts update is always written. Add conf-sanity test_88a.
