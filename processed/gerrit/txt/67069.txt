--- Commit Message ---
LU-20451 llapi: keep existing file on restricted setstripe

When setstripe is restricted, the SETSTRIPE ioctl returns -EACCES
and llapi_file_open_param()/llapi_file_create_foreign() remove the
file to retry with the default layout, deleting an existing file.

Create with O_EXCL and remove only a file created here.  Leave an
existing file untouched and return -EEXIST.  For a dangling symlink,
remove the created target only while it has no layout.  Ignore
ENOENT from remove() for the 'lfs migrate' volatile file and omit
its name from the warning.  Share this handling between both
functions in one helper.

Add sanity test_27W.
