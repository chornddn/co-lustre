--- Commit Message ---
DRAFT LU-21180 lod: add kunit test for failure-domain checks

Export lod_fd_check_ec_allowed() and lod_fd_check_flr_allowed() for
direct testing.

Add lustre/kunit/lod_fd_test.c, covering the failure-domain collision
checks used while selecting OSTs for EC and FLR (mirrored)
components, per Documentation/failure-domain.txt: a candidate OST
must not share a failure domain with another stripe already placed
in the same raid set (or whole component, without overstriping), nor
with the linked data component's stripes when allocating parity
(lod_fd_check_ec_allowed_test); nor with another stripe already
placed in the same component, nor with an overlapping component in a
different mirror (lod_fd_check_flr_allowed_test). Five mock_tgt
targets back these tests, with failure domains 1, 2, 1, 0 (none) and
9, so collisions and the "no domain" passthrough can both be
exercised.
