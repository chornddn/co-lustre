--- Commit Message ---
LU-20487 tcu: allow getxattr on virtual STCU objects

With TCU + remote dir, a concurrent trash move/destroy can clear
LOHA_EXISTS while a client close/getxattr is in flight. This will
cause object existence assertion failure in mdt_getxattr().

To fix this issue, check lu_object_accessible() in mdt_getattr()
instead and return -ENOENT when the object is neither existing nor
virtual.
