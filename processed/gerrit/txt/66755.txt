--- Commit Message ---
LU-9680 utils: Netlink user land enhancements

Add the ability to query kernel side the Netlink family protocol
to our YAML interface. This allows user land utilities to query
the protocol layer to know if the kernel support what is sent.

While working with flow sequences a few issues came up. One issue
is that we don't handle empty YAML flows. Add that support. Second
for NLA_NUL_STRING handling we can instead of allowing a single
key table entry update update it to hanlde multiple updates.
