--- Commit Message ---
LU-20984 obdclass: check Netlink request fits in the message

The lustre Netlink family's start and command handlers walk the
nested attributes of a request using the length stored in its
first attribute header, which was never compared with the length
of the message received, so a malformed request could make the
parser read past the end of the message.

Check the first attribute with nla_ok() against the message length
before walking it.
