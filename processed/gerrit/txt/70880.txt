--- Commit Message ---
LU-21217 socklnd: use sendpage where TCP still has it

socklnd picked its zero-copy send method by whether
MSG_SPLICE_PAGES is defined. Upstream added the flag in the
same release that taught TCP to honour it and removed
->sendpage. RHEL 9 defines the flag for an rxrpc backport, but
its TCP ignores it and still has ->sendpage, so on EL9 every
"zero-copy" send was an ordinary copy, one page per call, that
still paid for the ZC-ACK round trip.

Test for ->sendpage in struct proto at configure time and use
it whenever the kernel has it.
