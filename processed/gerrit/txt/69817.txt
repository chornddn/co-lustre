--- Commit Message ---
LU-7426 obdclass: read an indexed llog with no records

An indexed llog whose index is set up but which has no record yet
ends right after its index blocks. llog_osd_idx_read_header() took
that end of the file for a short header and failed with -EINVAL, and
left lgh_last_idx at 0 instead of after the index blocks, where the
next record goes.

Such an llog appears once a remote one gets its index when it is
created: the next llog a catalog keeps ready has no record. MDT
recovery then retried reading its update logs on another MDT forever,
as in replay-single test 80a.
