--- Commit Message ---
LU-21071 llite: mark writeback error seen in ll_fsync()

ll_fsync() waits for writeback with filemap_write_and_wait_range().
That clears AS_EIO but leaves the error in mapping->wb_err unseen,
so every later open samples a zero f_wb_err and
filemap_check_wb_err() returns the same old error again on each
open, until the inode leaves the cache. knfsd checks it on every
filecache close and resets its write verifier each time, so NFS
clients resend all uncommitted writes every few seconds.

Call file_check_and_advance_wb_err() after the wait. It marks the
error seen and reports it once to each open file description. The
AS_EIO result keeps its precedence, so fsync() still returns -EIO
for the first caller.

Add sanity test_118o.
