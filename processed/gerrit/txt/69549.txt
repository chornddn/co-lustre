--- Commit Message ---
LU-20916 dkms: detect --enable-gss as last configure option

The DKMS configuration checks for "--enable-gss" in the configure
options using the regex '--enable-gss[^-]'. This requires a character
after "gss", so it fails to match when "--enable-gss" is the last
argument in the options string. As a result, ptlrpc_gss is silently
omitted from the DKMS module list, and loading it later fails with:

  modprobe: FATAL: Module ptlrpc_gss not found in directory
  /lib/modules/<kernel-version>

Change the regex to '--enable-gss($|[^-])' so that it also matches at
the end of the string, while still excluding longer options such as
"--enable-gss-keyring".

Apply the fix to both debian/dkms.conf.in and
lustre/scripts/dkms.mkconf.
