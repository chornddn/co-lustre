--- Commit Message ---
LU-20996 mgs: return count from ir_timeout_store()

ir_timeout_store() returns the result of kstrtou64(), which is
0 on success. A sysfs store function must return the number of
bytes that it used. Thus a write to mgs.MGS.ir_timeout sets the
value, but lctl set_param reports "wrote only 0" and EINVAL.
The procfs handler had the same defect before the sysfs move.

Return count when the parse succeeds.

ir_timeout is a time64_t, but kstrtou64() takes a u64 pointer.
A value above S64_MAX thus becomes a negative timeout. Parse
the value with kstrtos64() and reject a negative value.
