LU-20630 tests: compare lnetctl Multi-Rail case-insensitively

lnetctl renders the Multi-Rail flag as "false"/"true" through the
Netlink path (LNet genl peer support, 8a0fdfa0b2, 2.16+) but as
"False"/"True" through the legacy cYAML path used when the peer's
kernel does not implement that command.  sanity-lnet test_238 reads
the flag from ${ROUTERS[0]}, so a router running 2.15 makes its exact
comparison against lowercase "false" fail:

  test_238: Expect 'Multi-Rail: false', found False

The setup_health_test guard compares against "False" instead, so the
file already disagrees with itself.  Compare both case-insensitively.
