--- Commit Message ---
LU-21180 lod: prepare lod for kunit testability

KUnit tests for LOD need access to internal helpers that are
currently static, and need to redirect a few calls that have side
effects (starting kernel threads, touching real storage) that cannot
run under a unit test.

Export the helpers that the new KUnit suites call directly, and add
KUNIT_STATIC_STUB_REDIRECT() to the handful of functions tests need
to stub out, splitting lod_sub_start_recovery_thread() out of
lod_sub_init_llog() so it can be redirected independently of its
caller.

This patch only prepares the module for testing; the tests
themselves land in later patches.
