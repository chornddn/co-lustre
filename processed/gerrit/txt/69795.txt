LU-20988 utils: fix 'lfs find --foreign' on directories

find_check_foreign() tests a directory's LMV the wrong way round.
A foreign directory is taken as not foreign, so --foreign skips it
and '! --foreign' prints it. A striped directory, whose LMV is not
foreign, is taken as foreign and matched by --foreign.

A plain directory has no LMV and is decided before this check, so
only foreign and striped directories are affected.

Restore the negation lost when the test moved to lmv_is_foreign().
Add sanity test_27Kf for both kinds of directory.
