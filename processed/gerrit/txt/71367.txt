LU-7880 utils: show target load with lfs df --stats

Add "lfs df --stats" to print the read and write bandwidth and
RPCs/s that each MDT and OST returns in statfs, with "-v" also
showing the peak values.  The values can also be selected with
"lfs df --output=read_bw,write_bw,read_ops,write_ops" and the
*_max fields.  Targets that do not return the stats are shown
with "-", and the summary line is the sum over all targets.

llapi_obd_fstatfs() requests the full struct obd_statfs only when
the caller passes LL_STATFS_PERFSTATS, and retries without it on
older client modules that only accept the original size.

Also check the number of fields given to "lfs df --output", which
could overflow the field_order[] array, and size it for all fields.
Sort the "lfs df" options by their short option.

Add sanity test_861 to check that the stats change with IO.
