LU-20276 tests: Reclaim space before/after running sanityn test

test_56b causes OOM in test_70/71 in 1/40 run since
using ZFS 2.4. This patch add function 'zfs_wait_free_osts'
to reclaim free space in function 56a and 56b before they
end.

This patch also enables test_56b. To check if OOM is
triggered after zfs_wait_free_osts function.

This patch bumps ZFS version to 2.4.4
