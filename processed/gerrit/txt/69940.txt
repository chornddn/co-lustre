LU-21016 llite: do not switch hybrid IO to DIO on ZFS

Hybrid IO switches large buffered IO to direct IO. On ZFS
each direct write RPC forces a transaction group sync, so
with anything but fast storage hybrid IO is far slower than
the buffered IO it replaces. Reads do not sync and still
switch.

Do not switch writes when any initialized component of the
file has a stripe on a ZFS OST. ZFS OSTs are recognized by
the ocd_maxbytes they report at connect, MAX_LFS_FILESIZE,
which ldiskfs does not approach, so no server change is
needed. osd-wbcfs reports the same and is treated alike. The
OSTs are classified when the layout is unpacked, so the write
path tests a flag per component.

Add llite.*.hybrid_io_to_zfs, off by default, to allow the
write switch on ZFS anyway for sites with fast storage.
sanity 119k sets it on ZFS to keep counting switches, and
119t checks the default and the override.
