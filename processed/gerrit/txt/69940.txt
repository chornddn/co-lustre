--- Commit Message ---
LU-21016 llite: do not switch hybrid IO to DIO on ZFS

Hybrid IO switches large buffered IO to direct IO. On ZFS a
direct write does not complete until its transaction group
commits, so each one waits out the commit interval, which is
seconds. For large writes on ZFS, hybrid IO is far slower
than the buffered IO it replaces. Reads do not wait on a
commit and still switch.

Do not switch writes when any initialized component of the
file has a stripe on a ZFS OST. ZFS OSTs are recognized by the
ocd_maxbytes they report at connect, which is
MAX_LFS_FILESIZE and which ldiskfs does not approach, so no
server change is needed.

Add llite.*.hybrid_io_to_zfs, off by default, to allow the
write switch on ZFS anyway for sites whose commits are quick.
sanity 119k sets it to keep counting switches, and 119t
checks the default and the override.
