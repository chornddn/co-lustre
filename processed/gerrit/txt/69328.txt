LU-20741 lfs: find remote file and directory

This patch adds two new features to lfs-find :
* --remote: allow to filter files and directories that are not on the
            same MDT as their parent directory
* New printf format:
    * %LR: print the MDT index of the parent directory
    * %Lm: print the MDT index of the file/directory

The goal of these new options is to provide users a way to identify
files and directories that have an `agent` inode. These inodes are
needed to identify on which MDT the file is stored.

Unfortunately it is not visible from the filesystem and this lead to
an inconsistency between what the user can see in its quota and the
number of files he can find with `lfs find`.

By using `--remote` users will be able to identify such files and make
this incosistency more understundable.

BTW, the patch also fixes an indentation issue on lfs-find manpage.
