LU-21092 gss: make lgssc an internal key type

Keys of the lgssc type are only meant to be requested when it needs
a new GSS context. Prefix the key type name with a dot, so that the
keys subsystem handles it as an internal key type, and update the
request-key rule accordingly.

request-key from keyutils before 1.6 only opens
/etc/request-key.d/<key type>.conf. keyutils 1.6 and later read every
*.conf file in request-key.d and match the key type inside the rule,
but skip file names starting with a dot. So make lgssc.conf the rule
file, and add a .lgssc.conf symlink to it, for older keyutils. Newer
keyutils ignore the symlink, so the rule is never matched twice.
