LU-21180 fld: add kunit fld_cache_test

The FLD sequence-range cache has no in-kernel unit coverage for
insert, lookup, delete and flush after the interval-tree rewrite.

Add a KUnit module that builds fld_cache.c in, so fld.ko does not
need to export the cache helpers.  It covers hits and misses at range
edges, adjacent ranges, every kind of duplicate or overlapping insert,
rejection of empty and wrapping ranges, ranges at the u64 limits,
many ranges inserted out of order and partly deleted, and hit/miss
statistics.

Add a HAVE_KUNIT configure check.  The module is built only when the
kernel has KUnit enabled; otherwise the build goes on without it.

Add sanity test_55d to load the module and check the suite result.
It skips if the module was not built or KUnit is disabled.

Add lustre/kunit/ku to find and run the KUnit modules affected by
the changed files, using the KUNIT.list files.
