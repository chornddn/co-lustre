--- Commit Message ---
LU-18687 lnet: iterate interface addresses with the kernel API

DECLARE_CONST_IN_IFADDR() and endfor_ifa() exist only in the
lustre_compat inetdevice.h shim, so the callers do not build against
the kernel's own header.

Declare the cursor directly and drop endfor_ifa().  For kernels older
than v5.3, backfill in_dev_for_each_ifa_rtnl() and
in_dev_for_each_ifa_rcu() as plain loops over ifa_list instead of
mapping them to for_ifa().
