--- Commit Message ---
LU-9680 utils: count free buffer space down in value list

yaml_parse_value_list() writes each YAML value into the parse buffer
and adds its length to the free space count. The count must go down.
After each value the count is too large by twice that length. The
snprintf() bound then lets writes past data->end.

Subtract the length of each value from the free space count. The
unwind label moves data->buffer back, so add that length back.
