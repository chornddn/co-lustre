LU-19915 mgc: attach local storage per cld

Attach local oid storage per cld to store llog config files, so that
these llogs are kept in sync with MGS0 on all MDTs/OSTs.  This is for
fault-tolerant MGS.

Add struct config_llog, which contains the logname and refcount.  The
llog is shared among all clds with the same logname.  The refcount is
incremented when a cld is added to the list, and decremented when the
cld is removed from the list.  The llog is freed when the refcount
reaches zero.

<fsname>-sptlrpc is special, which should be processed on a host only
once, add cl_processed for this.

Remove cl_mgc_mutex to allow target start in parallel.

Update sanity-scrub test_11 because params config may be recreated.
