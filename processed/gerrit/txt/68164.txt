LU-20587 lnet: expand Netlink support for more peers

Currently the LNet Netlink peer interface uses the default size
of 64K for its struct sk_buff. This limits the number of peers
that can be reported with the Netlink layer and this leads to
crashes. To avoid crashes and EMSGSIZE errors we change two
things. One is we set the cb->min_dump_alloc to the size of the
message for the peer with the most peer_ni otherwise we get an
EMSGSIZE error. The second is we check for the sk buffer overflow
and handle it gracefully by returning msg->len that tells the
Netlink layer to handle multiple skbs.

The peer NI code had deep indentation so refactor the code. Make
it generic so it can be shared with LNet NI dump code.

Use Andrew Perepechko new sanity-lnet to valid the work.
