--- Commit Message ---
LU-17519 lnet: automatically remove outdated peers

When a peer is in recovery list, it has a recovery limit.
del_on_recovery_limit has been added to control if an outdated peer
will be simply removed from the recovery list or if it will also be
removed from the peer list. A peer will be removed only when all NIs
age out.

It is important to note that it works only for peers that haven't been
configured manually.

The default value is to keep the peer.
