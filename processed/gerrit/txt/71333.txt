LU-21099 build: include workqueue.h by its kernel path

The in-kernel build of Lustre fails with:

  fs/lustre/obdclass/hash.c:87:10: fatal error:
  'lustre_compat/linux/workqueue.h' file not found

copy-builtin leaves include/lustre_compat behind, since it only
backfills newer kernel APIs on older kernels.  The headers there
shadow the kernel ones through the include path, so the callers
must name the kernel header and not the compat directory.

Include <linux/workqueue.h> in the four files that took WQ_PERCPU
from the compat path.
