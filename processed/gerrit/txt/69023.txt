--- Commit Message ---
LU-18687 build: remove some lnet abstractions for Linux kernel tree

Dropping the current LNet tree without any compat macros breaks the
native build. Resolve those build issues with the following:

1) HAVE_MODULE_LOADING_SUPPORT doesn't exist upstream so instead
   replace it with CONFIG_LUSTRE_FS_COMMON_MODULE and
   CONFIG_LNET_MODULE which works with the if IS_MODULE macro.

2) Saw build issues with LIBCFS_DEBUG not defined which is the
   case in the Linux kernel. We need a way to setup in up but
   for now handle not have LIBCFS_DEBUG

3) Move param_set_uint_minmax() to the compat layer since it
   was colliding.

4) We have a bunch of ifdef to handle missing headers. Make
   the headers in compat layer so we can drop those ifdefs.
