--- Commit Message ---
LU-18664 target: set proper kthread state

The function distrubte_txn_commit_batchid_update() is called in
an atomic context from distribute_txn_commit() while it is in an
idle state.

In distrubte_txn_commit_batchid_update there are two locations
that perform memory allocations that cannot sleep:
  - allocation of distribute_txn_bid_data
  - calling dt_trans_create
  - calling dt_declare_record_write

Get the current state at task start and switch to TASK_RUNNING,
if the task is not current running. Restore previous task state
once the allocations are completed.
