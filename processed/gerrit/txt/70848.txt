DRAFT LU-21180 lod: add kunit test for stripe_count_min/is_tgt_used

lod_stripe_count_min() computes the minimum number of unique OSTs an
allocator must place for a component before falling back (EC geometry
shrink, or a partial plain allocation); lod_qos_is_tgt_used() checks
the per-thread "targets used so far" scratch array an allocator fills
via lod_qos_tgt_in_use(). Both were untested.

Add lod_qos_helpers_test.c: plain, default-stripe, EC-data single/
multi raid-set (with and without overstriping) and parity cases for
lod_stripe_count_min(), and an unused/used/out-of-range/stripes-limit
case for lod_qos_is_tgt_used().

Export both functions, needed by the new test module, and register it
in lustre/kunit/Makefile, KUNIT.modules_list and lod/KUNIT.list.
