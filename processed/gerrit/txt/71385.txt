LU-18687 build: remove unused configure checks

Several configure checks defined macros that no code tested, so
every configure run compiled test programs for nothing.

Remove the checks for HAVE_CACHE_DETAIL_WRITERS,
HAVE_LINUX_BIO_INTEGRITY_HEADER, HAVE_EXT4_INFO_DQUOT,
HAVE_FSCRYPT_SET_CONTEXT, HAVE_NLA_GET_S32 and HAVE_NLA_GET_S64.

Remove the unused HAVE_LOCKS_LOCK_FILE_WAIT, HAVE_LM_GRANT_2ARGS,
HAVE_GENERIC_FILEATTR_HAS_MASK_ARG, HAVE_MEMDESC_FLAGS_T and
HAVE_OPENSSL_GETSEPOL from checks that also define a macro that is
still used.

Remove the --disable-fail-alloc configure option.  It only defined
RANDOM_FAIL_ALLOC, which nothing tested, so the option had no
effect.  Also remove its fail-alloc Debian build profile.
