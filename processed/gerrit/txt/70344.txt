LU-21100 lfs: find --device --bookmark

Add --bookmark FILE to lfs find over a target.  If FILE exists the
scan resumes from it.  The scan saves its place in FILE as it goes,
after flushing what it printed, and replaces the file whole so a
crash leaves an old bookmark or a new one.  A run that reads the
whole target removes FILE, so the next run starts again.  Only one
target can be named.

conf-sanity 300a checks that a whole run with --bookmark answers the
same and leaves no file, that a run killed part way and run again
misses nothing, and that a damaged bookmark and --bookmark without a
target are refused.

Test-Parameters: trivial
Test-Parameters: testlist=conf-sanity env=ONLY=300a
