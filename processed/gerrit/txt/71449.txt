--- Commit Message ---
LU-21328 efalnd: Register the MR over the DMA mapped entries

The memory registration was given the number of fragments before DMA
mapping instead of the number of entries the mapping returned, as
the API expects and as o2iblnd does.

In practice this has no effect today. Without an IOMMU, DMA mapping
never merges fragments, so both counts are the same. With an IOMMU,
the mapping can merge fragments, but it marks every unused entry
with an invalid address, and the conversion to pages stops at the
first such entry, so the registration still covers only the mapped
entries. Other mappings, such as GPU memory, may not mark unused
entries this way.

Register only the entries the DMA mapping returned.
