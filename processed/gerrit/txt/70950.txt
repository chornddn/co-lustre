LU-21228 lfs: find --report trees and owners

Add tables of the users, groups and projects that own the most
objects and file bytes, and of the largest whole trees.  A tree
counts every entry and file byte below a directory, for directories
down to --report-depth levels below the root or a walk's start path,
3 by default.  --report-top sets how many rows each table lists, 20
by default.  Programs set fp_report_depth, and the top argument of
llapi_find_report() now limits every table.

A target scan reads every object's project ID.  A walk reads one only
for --projid, -printf or -ls, so its project tables list only those.
