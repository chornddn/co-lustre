--- Commit Message ---
LU-12669 ec: tidy the checks for reads that wait for OSTs

ll_file_io_generic() keeps the read that waits for the stripes' OSTs
from falling back to CIT_EC_RD by clearing io->ci_cross_ec before the
DIO fallback check.  Test ec_wait in that check instead, so that
ci_cross_ec keeps its meaning for the whole IO.

lov_io_ec_rd_start() prints a console warning with rc = -EIO when a
raid set has more unavailable stripes than parity, although the read
then waits for the OSTs.  Since waiting is not an error, print a debug
message instead.
