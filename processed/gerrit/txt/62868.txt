LU-12187 llite: enable erasure coding by default

Erasure coded layouts needed the mdt_enable_flr_ec and
lustre.enable_flr_ec module parameters, and LFS_EC_OK set for lfs.
The client module parameter could not be changed centrally or per
filesystem, and turning EC off on a client also stopped it from
negotiating parity, so it could not rebuild or resync EC files.

Enable EC by default, and remove the module parameters and the
LFS_EC_OK check.  The client always negotiates parity with the MDS,
which advertises it by default in mdt.*.layout_pattern_types.
Make llite.*.enable_erasure_coding, now on by default, the
per-filesystem switch: at 0 the client refuses explicit EC layouts
and does not rebuild data from parity when a read fails, which then
waits for the OST as for a file without parity.  It can be set for
all clients with "lctl set_param -P".  Add conf-sanity test_163f
and sanity-ec test_72a for the switch.
