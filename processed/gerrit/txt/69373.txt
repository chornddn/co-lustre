--- Commit Message ---
LU-20815 mdt: return lookup lock on symlink open

Open of a symlink does not return any lock to the client, so
the symlink dentry is never revalidated and every open of the
same symlink sends an open intent RPC to the MDS.

Try LOOKUP|UPDATE|PERM ibits in PR mode for symlink on open and
return the lock to the client, so repeated open of the symlink
can be resolved on the client side.

Add sanity test_17r to verify it.
