LU-21005 nodemap: add servergroup property

Add new nodemap property 'servergroup', off by default. It marks a
nodemap whose members are Lustre servers. When nodemap is active,
targets reply with EPERM to server-only request types that are sent
from peers that belong to a nodemap with this property set to 0.
Requests received on the loopback NID 0@lo can only come from the
server node itself, so they are always accepted.

The servergroup property can be set on regular nodemaps and on the
default nodemap, but not on dynamic nodemaps, and it is never
inherited by new nodemaps. Nodemaps created with an older Lustre
version have it off after upgrade, which changes the behavior of
existing deployments until servergroup is set on the nodemap holding
the server NIDs.

Update lctl-nodemap-modify man page, and add nodemap.servergroup man
page.

Add sanity-sec test_107 to exercise this new property.
In test-framework, set servergroup on the default nodemap and on the
SSK server-to-server nodemap, so that existing tests activating
nodemap keep working with DNE.
