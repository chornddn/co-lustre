--- Commit Message ---
LU-20797 llite: add SET I/O scope ioctl

FLR designated-mirror I/O is tied to LL_IOC_FLR_SET_MIRROR(long)
and cannot name a stripe or an object. Add LL_IOC_SET_IO_SCOPE and
struct ll_ioc_io_scope.

The enum defines FILE, MIRROR, STRIPE, and OBJECT. This patch
implements FILE and MIRROR. STRIPE and OBJECT return -EOPNOTSUPP
and are not stored. Clearing is a SET of an all-zero FILE scope,
the same as SET_MIRROR(0). llapi_io_scope_clear() is that SET.

SET_MIRROR remains an alias for {MIRROR, id}, so llapi_mirror_set()
is unchanged. Non-FILE scopes require O_DIRECT. Unused identity
fields, flags, and padding must be 0.

fd_io_scope replaces fd_designated_mirror. ll_io_set_scope()
copies a MIRROR scope into ci_designated_mirror.

sanity-flr test_213 covers the reserved scopes, a FILE set, and
mirror resync through the SET_MIRROR alias.
