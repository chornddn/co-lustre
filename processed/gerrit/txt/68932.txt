LU-20718 lod: scrub stale EC fields from old layouts

Before EC was introduced, servers wrote lcme_timestamp only for
NOSYNC components, memset only the layout header and reused the EA
buffer, so every other component was persisted with stale bytes in
what EC now reads as lcme_time_and_id and the EC stripe counts.  An
MDS upgraded from such a server hands those bytes to every client,
and trusts a stale stripe count on an uninstantiated component: it
instantiates it as an EC component or fails the write with -EINVAL.

Zero the EA before packing it.  Wherever a layout is parsed, clear a
timestamp outside a plausible range, and the link id and stripe
counts of a data component that no parity component, which such a
server never wrote, links to; the layout is clean the next time it
is written.  Apply the same to the EA returned by lod_xattr_get().
