--- Commit Message ---
LU-21023 mdt: end the migrate lease before locking the source

lfs migrate takes a lease on a regular file, and the migrate request
carries it to close. The client cancels its copy locally and sends no
cancel, so the MDT has to. It did that in mdd_migrate_close(), after
taking the source lock, whose OPEN bit conflicts with the lease. If
an open had already got the lease's blocking AST acked, nothing else
would cancel it: the migration waited on its own lease until the
client was evicted.

End the lease in mdt_migrate_lease_end() before any lock is taken.
A lease that was canceled, or that another open is waiting on, is
broken: the migration returns -EAGAIN and the client retries with a
new lease. mdd_migrate_close() only closes the file.
