LU-20359 idl: reserve certified maintenance constants

Reserve wire constants for bounded/certified maintenance recovery.

New RPC opcodes for server->client notification:
- LDLM_MAINTENANCE = 108 - quiesce client to minimize recovery time
- LDLM_MAINT_HINT = 109 - server notification to client of liveness

RPC flags:
- MSG_MAINT_DRAINED = 0x0800 - client has flushed dirty data backlog
- MSG_MAINT_HINT_CAPABLE = 0x1000 - client can receive liveness hint

Flag for `last_rcvd` file to indicate fast maintenance mode:
- OBD_INCOMPAT_MAINT = 0x800

FID for `maint_data` file:
- MAINT_DATA_OID = 4127 - contain list of clients to recover

New fail_loc constants for fault injection during testing:
- 0x330-0x332, 0x41b, 0x538-0x539

Add wirecheck.c/wiretest.c for newly defined wire constants.
Add missing MSG_CLIENT_BANNED, MSG_PACK_UID_GID, MSG_PACK_PROJID.

Change CHECK_VALUE_X() definition to avoid new compiler warnings,
but do not re-generate whole file to avoid massive useless churn.
