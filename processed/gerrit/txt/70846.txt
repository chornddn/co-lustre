DRAFT LU-21180 lod: add kunit test for parse config

lod_qos_parse_config() turns a suggested striping buffer (plain
V1/V3, or composite COMP_V1) from an application or the per-directory
default into the object's ldo_comp_entries[], applying filesystem
defaults and validating it via lod_verify_striping(). It was
untested.

Add lod_parse_config_test.c, covering a NULL buffer (no-op), a plain
V1 suggestion with filesystem defaults filled in, a V3 suggestion
naming a pool, a two-entry COMP_V1 composite layout, and an
unrecognized magic (rejected, no striping left behind). The function
never instantiates stripe objects itself, so the test context is
lightweight, reusing the same in-memory lod_device/lod_object setup
as lod_verify_test.c, with no dt_object/thandle mock needed.

Export lod_qos_parse_config(), needed by the new test module, and
register it in lustre/kunit/Makefile, KUNIT.modules_list and
lod/KUNIT.list.
