LU-21184 lod: zero the whole EA when packing a layout

lod_generate_lovea() packs layouts into a per-thread buffer, which is
reused by the next layout packed in the same thread, but it cleared
only the 32-byte header. A field that is not written for a component
keeps the bytes of an old layout: lcme_compr_type is written only for
a component with LOV_PATTERN_COMPRESS, so a DoM component can keep the
compression type of a compressed layout packed before. That value is
stored on disk with the layout, and the next HSM release fails:

  lod_verify_striping: compression is not supported on DoM components
  mdt_hsm_release: cannot open orphan file: rc = -22

Clear the whole destination buffer instead of the header only, so
every byte of the packed EA is initialized.
