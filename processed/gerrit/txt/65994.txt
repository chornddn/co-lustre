LU-19276 llapi: add llapi_name_is_valid() helper

Add new llapi_name_is_valid() helper function to check if names
contain only alphanumeric and a few extra characters, and are
within the required length.  Use in mkfs_lustre.c::parse_opts()
lfs_arg_insane(), lqa_arg_insane(), and llapi_pool_name_is_valid()
to avoid code duplication.

The helper function llapi_name_verify() checks the return codes
and prints an error message.  This removes code duplication between
lfs_arg_insane() and lqa_arg_insane().

Add llapi_name_is_valid.3 and llapi_pool_name_is_valid.3 man pages.
Update commit for llapi_pool_pin*.3 man pages and sort in Makefile.
