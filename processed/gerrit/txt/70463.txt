--- Commit Message ---
LU-20434 build: include linux/fs.h in file_kattr probe

Since kernel v7.0 (commit 0e6b7eae1fde "fs: add FS_XFLAG_VERITY for
fs-verity files"), linux/fileattr.h references struct fsxattr, the
FS_XFLAG_* constants and struct mnt_idmap without including
linux/fs.h itself. The LC_HAVE_FILE_KATTR probe compiles with -Werror
and only includes linux/fileattr.h, so it fails on every kernel that
actually has struct file_kattr. configure then defines file_kattr as
fileattr, a struct that no longer exists on those kernels.

Include linux/fs.h before linux/fileattr.h in the probe.
