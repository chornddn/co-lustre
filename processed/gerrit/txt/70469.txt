LU-20287 tests: handle IDIF FIDs in ost_fid2_objpath()

sanity test_39v failed in every interop session with 2.15 servers
with "OST0 uid:gid : != 500:500".  A 2.15 OST gives MDT0 objects
IDIF FIDs like [0x100000000:0x42e:0x0], which ost_fid2_objpath()
turned into O/100000000/d14/42e, so debugfs could not find the
object to check its owner.

An IDIF FID holds the OST index and the high 16 bits of a 48-bit
object id in its sequence, and the object is stored in O/0 under
its decimal object id.  Return that path for an IDIF FID, so 39v
and the other callers of ost_fid2_objpath() work with such OSTs.

Test-Parameters: trivial
Test-Parameters: testlist=sanity serverversion=2.15 env=ONLY=39v
