LU-19921 ptlrpc: update nodemap for gssiam

Export and add a few functions for gssiam.

- Export nodemap_lookup_unlocked(), nodemap_getref().
- Add nodemap_gssiam_projid_update() to update the
  projid on the nodemap.
- Add identity to nodemap.
- Add project ID check in nodemap_check_resource_ids() for
  GSSIAM-managed nodemaps in addition to the existing UID/GID
  squash checks.
- Migrate dynamic nodemap from old config to new config
  during nodemap_config_set_active().

Additionally, address several robustness and cleanup items:
- Add a nodemap_unlink() helper to safely remove a partially
  registered nodemap from global hashes, and use it to clean up
  on lprocfs_nodemap_register() failure in nodemap_add().
- Add an nm_pde_data NULL guard in nodemap_del() to prevent null
  pointer dereferences, and remove a redundant/unnecessary
  CDEBUG_LIMIT log.
- Skip saving dynamic nodemaps in nodemap_save_config_cache()
  as they should not persist across config updates.
- Introduce OBD_STRDUP macro in obd_support.h to duplicate
  strings with length checks, and use it in
  nodemap_set_identity().
- Include <linux/atomic.h> in lustre_nodemap.h for atomic
  operations on config counts.

- Hold active_config_lock around nm_identity reads in procfs to
  prevent race with concurrent nodemap_set_identity() updates.
- Check exp->exp_connection against NULL in nm_member_exp_revoke()
  to avoid NULL dereference when switching unconnected exports.
- Remove duplicate nm_member_exp_revoke() call in
  nm_member_reclassify_nodemap(), as __nodemap_member_switch()
  already revokes locks when needed.
