LU-19921 ptlrpc: update nodemap for gssiam

Export and add a few functions for gssiam.

1. Export nodemap_lookup_unlocked(), nodemap_getref().

2. Add nodemap_gssiam_projid_update() to update the
projid on the nodemap.

3. Add identity to nodemap.

4. Add project ID check in nodemap_check_resource_ids(), which
only check project ID and ignore uid and gid.

5. Migrate dynamtic nodemap from old config to new config
during nodemap_config_set_active().

6. During nodemap export reclassify, even the export does
not have active connection, it should be migrated to new
config, otherwise it may cause export/nodemap not being
released finally.
