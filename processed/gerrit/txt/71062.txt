LU-17559 build: fix deb repackaging of multiple LNDs

With --enable-multiple-lnds, debian/repackage-multiple-lnds.sh
does not split the LNDs into correct lustre-lnet-module-*
packages:

- it enters debian/tmp/re-pkg/<package>/DEBIAN, which nothing
  creates, so no LND package is built; create it, starting from an
  empty debian/tmp/re-pkg.
- it runs outside fakeroot, so the packages it builds are owned by
  the building user; pass --root-owner-group to dpkg-deb --build.
- with only the in-kernel o2iblnd built, ko2iblnd.ko is a symlink
  that it packages as an empty lustre-lnet-module-o2iblnd; only
  package a regular file, and drop the symlink once the in-kernel
  package provides ko2iblnd.ko.
