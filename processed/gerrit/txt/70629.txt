LU-20797 utils: add llapi_io_object read and seek helpers

Add userspace helpers for OBJECT-scope O_DIRECT pread and lseek:
llapi_io_object_read, llapi_io_object_seek, and
llapi_io_object_data_seek. Each follows the set-op-clear pattern
used by llapi_mirror_read / llapi_mirror_data_seek. The caller
fills an LL_IO_SCOPE_OBJECT target (ios_comp_id + ios_stripe_idx);
pos is an object offset.

Object size is SEEK_END with pos 0 via llapi_io_object_seek(),
not fstat: getattr stays on the file and does not go through the
fd scope. That is enough for migrate_stripe copy (LU-20541) once
the read side switches to object SEEK_DATA + pread; file st_size
and layout geometry remain separate for dest sizing and append
clamps.

Route io_scope OBJECT -r/-k through those helpers instead of
raw pread/lseek on a sticky scope, add -d for data_seek, and
cover it in sanity-flr test_214c.
