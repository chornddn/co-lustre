LU-20107 nrs: server node tier classful hierarchical scheduling

This patch implements per-server node parent class bucket for the
hierarchical scheduling.
Each flow classification for a service (ptlrpc_service) on an
individual server node has a parent class bucket.
The leaf class buckets are the same as before which can be
managed by CPT tier TBF or mClock scheduler.
The node tier class buckets can be useed to coordinate and manage
the bandwidth allocation among various CPT tier scheduler.

It also provides a "nrs_hsch" sysfs entry for each ptlrpc service
to configure the node tier global rules and class buckets:
i.e.
lctl set_param ost.OSS.ost_io.nrs_hsch=
"<mclock|tbf> [reg|hp] start rulename projid={100} rate=100 \
 root=0 node=0"
lctl set_param ost.OSS.ost_io.nrs_hsch=
"<mclock|tbf> [reg|hp] stop rulename"

The global rate of the node tier will firstly be assigned equally
to each CPT tier rule.
And each CPT tier rule has a shared class bucket associated to
the NRS rule and will not managed via class bucket LRU mechanism.

Add a test case sanityn/test_77wa to verify the sysfs interface
works as expected.
