LU-19768 obdclass: add table-driven netlink framework

Introduce a reusable table-driven netlink handler framework
(lustre_nl_ctx) that factors out the common start/dump/done
pattern shared by commands that iterate OBD devices.

Each command supplies a descriptor with collect, pack_msg, and
setup / release callbacks.

Also fix several bugs in the existing stats dump path:
- Add missing nla_put return-value checks
- Fix an off-by-one in key-list sizing
- Fix a typo ("togther" -> "together").
