LU-21085 ptlrpc: unlink the request MD on request timeout

When a request times out, ptlrpc_unregister_reply() unlinks only the
reply MD. A request that waits in LNet for a credit or for discovery
keeps its MD busy. The import cannot try the next NID until the
request leaves the LNet queue. An aborted request (rq_err) and a
request marked for resend (rq_resend) wait in the same way.

In these cases, also unlink the request MD. LNet then cancels the
queued request. ptlrpc uses no reply to the old send. A resend sends
the request again, and an abort completes it with its rq_status.
Thus request_out_callback() does not set rq_net_err for a failed old
send of these requests. Otherwise ptlrpc_expire_one_request() counts
an import timeout. For a request with rq_send_state other than FULL,
such as CONNECT, it also replaces the abort status with -ETIMEDOUT.
Do not unlink in other cases: a request with a reply would fail.

Add recovery-small test_165 and test_166.
