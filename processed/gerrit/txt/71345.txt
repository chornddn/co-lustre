--- Commit Message ---
LU-18635 target: reject zero-length bulk niobufs

A bulk read or write request carries an array of niobufs, each
describing a byte range of the target object.  The OST I/O prep and
commit paths expect every niobuf to be non-empty and to map to at
least one page.

Validate the niobuf lengths in tgt_io_data_unpack(), next to the
existing ioobj and niobuf count checks, and return an error for a
zero-length niobuf before the request reaches the backend.
