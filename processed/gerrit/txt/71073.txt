LU-20740 kernel: RHEL 9.9 server support

This patch makes changes to support RHEL 9.9 release
with kernel 5.14.0-741.22.1.el9_9 for Lustre server.

RHEL 9.9 moves d_alias in struct dentry into an anonymous
union, so add rhel9.9/ext4-lookup-dotdot.patch using
dentry->d_alias instead of dentry->d_u.d_alias.
