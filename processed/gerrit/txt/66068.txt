LU-19781 lnet: Improve load/unload lustre module time

If we have large number of LNET configured, it takes a long time
to load and unload the module.
We can parallelize the shutdown sequence by splitting it into two
parts. This way all the NI can shutdown in parallel instead of
serially.

$lnetctl net show | grep type | grep -v lo | wc -l
126

$ time lustre_rmmod

real	2m13.673s
user	0m0.416s
sys	0m0.150s

After this change:
$ time lustre_rmmod

real	0m1.781s
user	0m0.217s
sys	0m0.062s
