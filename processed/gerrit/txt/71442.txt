LU-21329 rustreapi: gate the volatile calls on the bindings

rustreapi does not build against 2.17.50-2.17.58 headers:
"cannot find function `llapi_file_open_volatile_param`".  LU-18842
gated its volatile calls on LUSTRE_2_18, which lu-version sets for
any 2.17.50 or later, but the calls first ship in 2.17.59.

As LU-20663 does for the stripe pattern union, probe the generated
bindings for llapi_file_open_volatile_param() instead of the
version.  The calls are in rustreapi, so lustreapi-sys passes the
result on as links metadata, which rustreapi's build.rs turns into
the has_file_open_volatile cfg.

Fixes: a67f003e5bb6 ("LU-18842 llapi: create volatile file with a layout")
