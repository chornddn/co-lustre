LU-21233 lfs: print the volatile FID in --stats output

`lfs mirror extend` and `lfs migrate` copy data through a volatile
file, so OSTs log the copy's writes under a FID that has no name and
that nothing outside lfs knows. A tool watching the copy cannot tell
those writes from application I/O.

With `--stats`, print the volatile FID as a quoted YAML item right
after the file name, before the copy starts:

/mnt/lustre/f:
- { volatile_fid: "[0x200000401:0x8:0x0]" }
- { seconds: 1, rmbps: 16, wmbps: 16, copied: 16, total: 64, ... }
