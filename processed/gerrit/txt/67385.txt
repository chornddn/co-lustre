LU-20232 build: dkms-deb should only build dkms packages

Make the lustre-client-modules-dkms package Architecture: all,
since the DKMS package ships source and builds modules on the
target host rather than shipping prebuilt binaries.

Build only the arch-independent packages (source + DKMS) for
the dkms-debs target by passing -g to dpkg-buildpackage, and
trim the mv list to the packages that are actually produced.

Neither package needs a configured or built tree: both ship the
source as-is, and the UAPI headers the DKMS package installs are
not generated. Copy them with dh_install instead of running a
full "make install" into a temporary DESTDIR, which compiled the
whole tree under fakeroot just to extract a few headers. With
that, build-indep is empty, the source and DKMS binary rules no
longer depend on configure-stamp, and the systemd and int_o2ib
build profiles only consumed by configure are dropped from the
dkms-debs target.

Test-Parameters: trivial testgroup=full-dkms
