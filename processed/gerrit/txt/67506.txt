LU-0000 tests: drop truncate on object drop

originally osd's preallocation put inode on the orphan list only
to pass few tests checking filesystem's consistencty (e2fsck) -
because e2fsck can't handle orphan list properly. but this is
not needed in production and probably can be made optional like
we do for credits check.

enable truncate-on-drop for sanity-lfsck and sanity-scrub
