LU-930 misc: fix file patterns in MAINTAINERS

Many F: patterns in MAINTAINERS match no file on master,
because the files moved or were removed. The
get_maintainer.pl script then misses those files.

Change the patterns for these moves:
- Man pages: lustre/doc/ to Documentation/man<N>/.
- UAPI headers: lustre/include/uapi/ to include/uapi/.
- User headers: lustre/include/lustre/ to include/lustre/.
- libcfs: to lnet/libcfs/, lib/libcfs/, include/libcfs/
  and include/linux/libcfs/. The compatibility code is
  now in lustre_compat/ and include/lustre_compat/.
- Encryption: libcfs crypto to lustre_compat/fs/crypto/.
- Build: autoconf files to config/, kmp files to rpm/.

Fix the patterns for files with a new name or a wrong
name. These are dt_object.h, range_lock.h,
liblustreapi_param.c, lsvcgss, obd_sysfs.c,
lustre_nrs*.h and the pacemaker resource agents. The
lctl-pcc and lctl-lcfg man pages also change. Remove
the patterns for build/ and lustre_patchless_compat.h,
which no longer exist.

Add the Data-on-MDT code files mdt_io.c and mdc_dev.c,
and the write barrier code that snapshots use.

Each F: pattern now matches at least 1 file.
