--- Commit Message ---
LU-18806 tests: except sanityn/80a for older clients

Clients older than v2_16_53-41-g8a5e155235 run a sanityn test_80a
that expects "lfs migrate" of a directory with an open file to fail.
MDSes with that change skip the open file and complete the migration,
so 80a fails in interop testing with those clients, e.g.
"migrate open files should failed with open files".

Add lustre/tests/except/sanityn.ex so that older clients skip 80a.

Test-Parameters: trivial
Test-Parameters: testlist=sanityn mdtcount=2 env=ONLY=80a
Test-Parameters: testlist=sanityn mdtcount=2 env=ONLY=80a clientversion=2.15
