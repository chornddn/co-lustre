LU-20869 tests: speed up sanity test_398m

The test checks that parallel DIO reports an error when an OST
fails the bulk RPC. With the fail_loc set, every bulk RPC
returns -EIO and the client resends 10 times (resend_count)
with a growing backoff, so each of the four expected-failure
dd runs takes close to a minute.

Set osc.*.resend_count to 1 for the test and restore it with
stack_trap, as sanity 77f does. The dd runs still fail with the
error, only the retry backoff is gone.

On a VM the test took 75s, 45s and 65s before and 8s, 7s and
6s after. CI averages 235s over 17259 runs per 30 days; saving
about 220s per run is about 1050 hours per 30 days.
