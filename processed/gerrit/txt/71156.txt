LU-20939 ldiskfs: skip mb buddy load for prealloc at umount

When we umount and evict the inodes, we discard the inode preallocations.
During this process the group mb buddy is updated, which means we
need to load the buddy.

However if we have many inodes and the group bitmaps have already got
evicted from memory, loading the buddy means we need to read the
block bitmaps, creating many small IOs and stall the umount.
During umount this is unnecessary as the mb buddy info is in memory
only and will be dropped right after.
Before evicting inodes both generic_shutdown_super() and osd_umount()
do sync_fs() so there should be no more block allocations.

Check if we are tearing down the superblock, if so skip loading the
mb buddy, just discard the prealloc info in
ext4_discard_preallocations().
