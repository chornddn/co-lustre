LU-11962 lfs: find files with a foreign component

"lfs find --foreign" only matches a file whose whole layout is
foreign, and "lfs find -L foreign" never matches, since the layout
check skips foreign entries.  There is no way to find the files that
have a foreign mirror component, as PCC-RO adds.  For directories,
"lfs find --foreign" matches the wrong ones, since the foreign LMV
check is inverted, and "lfs find ! --foreign" prints every unstriped
directory without checking the other options, such as -type f.

Match a composite layout in find_check_foreign() if it has a foreign
component, of the requested type if given, and match foreign layouts
and components with "-L foreign" in find_check_layout().  A file whose
whole layout is foreign now also matches a negated pattern, such as
"! -L raid0".  Fix the foreign directory check, and remove the
shortcut that printed an unstriped directory for "! --foreign".

Add sanity test_56ya for foreign files and directories, and
sanity-pcc test_21ba to find a file attached to PCC-RO.
