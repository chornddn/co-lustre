--- Commit Message ---
LU-21120 tests: re-disable sanityn test_32b

sanityn test_32b measures lockless I/O, which is only entered after
the server returns -EUSERS in response to LDLM_FL_DENY_ON_CONTENTION.
LU-14838 removed the client support that sets that flag, so the
server never returns -EUSERS and lockless_write_bytes remains zero.
LU-12550 later re-enabled test_32b while rewriting contention
detection, so an old server plus a current client now runs the test
and fails instead of exercising lockless I/O.

Remove test_32b(). Delete the entire test function.

Fixes: 73f14d6c16d ("LU-12550 ldlm: contention detection")
