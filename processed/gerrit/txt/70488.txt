--- Commit Message ---
LU-21120 tests: skip sanityn test_32b on interop clients

sanityn test_32b measures lockless I/O, which is only entered after
the server returns -EUSERS in response to LDLM_FL_DENY_ON_CONTENTION.
The test guard checks only OST1_VERSION, so an old server plus a new
client runs the test even though the new client does not set that
flag and lockless_write_bytes stays zero.

Require both OST1_VERSION and CLIENT_VERSION to be older than 2.17.53
before running the test. This preserves the existing old-server-only
coverage and skips the interop combination that cannot trigger the
measured path.
