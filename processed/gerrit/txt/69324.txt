--- Commit Message ---
LU-20851 osp: wake up precreate if status changes.

OSP begins with precreate status = -EAGAIN and the precreate thread
is waiting for the status to change to start precreation activity.
the status is changed by statfs updates which. so it's possible that
enters wait queue for 5s, but osp_statfs_interpret() doesn't wake it
up, so we lose 5s after mount.

the precreate thread waits for opd_pre_status == 0, so wake it up
whenever the status changes, e.g. -EAGAIN after mount or -ENODEV
after reconnect.
