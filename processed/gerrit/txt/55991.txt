--- Commit Message ---
LU-18128 lov: fiemap returns EINVAL past EOF

A FIEMAP request that starts past EOF of a non-empty file fails with
EINVAL in lov_object_fiemap().  This is not consistent with ext4,
with Lustre for an empty file, or with the FIEMAP documentation of
the kernel (Documentation/filesystems/fiemap.rst).

Return 0 mapped extents instead, as ll_do_fiemap() does for an empty
file.

Add a --start option to checkfiemap and sanity test_130j, which maps
a 1 MiB file from 2 MiB on and expects no extents.
