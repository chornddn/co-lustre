--- Commit Message ---
LU-18859 quota: don't LBUG on invalid default quota request

qmt_get() asserted that a request for default quota always carries
id 0:

  LASSERT( !is_default || id->qid_uid == 0 )

A client can reach this path with a non-zero id, for example via
llapi_quotactl() with LUSTRE_Q_GETDEFAULT. That said, an
unpreveleged user could LBUG the MDS. Return -EPROTO to the client
instead of asserting on the server.

Fixes: 530881fe4ee2 ("LU-7816 quota: add default quota setting support")
