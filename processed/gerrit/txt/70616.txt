LU-10499 pcc: set PCC copy mode by cache type

PCC created every cache file with mode 0000, whether it was a
PCC-RO copy that can be dropped at any time, or a PCC-RW copy that
may hold the only copy of the file data.  A tool that purges files
from the PCC backend could not tell the two apart.

Set the mode of a PCC-RW copy to 0600 when it is attached or
created, so that a purge tool can skip files with write permission.
A PCC-RO copy keeps mode 0000.  A PCC-RO attach does not change the
mode of the PCC file, so that a reused PCC-RW copy, which may still
be the HSM archive copy of the file, keeps its write permission.

Users still cannot access the PCC files directly, since the PCC
directories are created with mode 0000.

Add sanity-pcc test_46b to check the PCC copy mode.
