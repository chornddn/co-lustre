LU-21061 lmv: track MDT pool members on clients

To place new directories on the MDTs of a pool, a client needs to
know which MDTs the pool lists.  The config log only has pool
records for the client LOV, and LMV has no pool operations.

Add o_pool_new/del/add/rem to LMV, keeping the MDT members of each
pool and ignoring OST members.  When class_process_config() applies
a pool record to a "-clilov" device, apply it to the "-clilmv"
device of the same mount too, as is done for LCFG_ADD_MDC.  Give
each pool a reference count, so that a user can keep a pool that
pool_destroy takes off the list.  Nothing uses these pools yet;
directory placement follows.

Test-Parameters: trivial mdscount=2 mdtcount=4 testlist=ost-pools
