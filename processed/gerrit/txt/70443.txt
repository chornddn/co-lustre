LU-21061 lod: keep MDT pool members apart from OSTs

A pool can only list OSTs.  lod_pool_add() looks the target up in
lod_ost_descs only, and every OST allocation path reads pool_obds,
so an MDT index there would be taken for an OST index.

Keep MDT members in a separate pool_mdts list, and the local MDT,
which has no lod_mdt_descs entry, in pool_local_mdt.  Choose the
list from the target name in lod_pool_add() and lod_pool_remove(),
and list MDT members after the OSTs in lod.*.pools.<pool>.

The MGS still refuses MDT names, so nothing changes for users yet.
