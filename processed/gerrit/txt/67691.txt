--- Commit Message ---
LU-20534 mdd: detect DoM on SEL layouts in mdd_lmm_dom_size()

mdd_lmm_dom_size() only matched LOV_MAGIC_COMP_V1, so a DoM component
paired with an extension component (lcm_magic == LOV_MAGIC_SEL) was
treated as non-DoM. That skipped the LA_SIZE workaround in mdd_attr_set,
missed dom_stripe in mdd_xattr_split, and let full layout swap proceed
without the DoM guards.

Recognize SEL (and mask LOV_MAGIC_DEFINED) so DoM detection matches the
actual composite layout. Independent of single-stripe swap, which skips
mdd_dom_fixup() for SINGLE_STRIPE.
