LU-19712 mdd: enforce pool pins on layout changes

The lustre.pin pool constraints were only checked by lfs, so
any other tool, llapi caller or older client could migrate,
mirror or split a pinned file off its pools.

Check them in MDD for these layout changes:
- a layout swap must keep a whole mirror on each pinned pool
  that has one; an exclusive pin needs every component on a
  pinned pool, and no component may use a denied pool;
- a mirror merge or component add may only add components
  that an exclusive pin or deny entry allows;
- a mirror split or component delete must not remove the
  last whole mirror on a pinned pool.
The volatile side of a migrate, the victim of a mirror
merge, HSM release or restore, and a pool spill when a
component is instantiated are not checked.
Setting mdd.*.enforce_pool_pin=0 (default 1) turns the
checks off.

test_157j and test_157k bypass the lfs checks, through lfs
swap_layouts and a new llapi_pin_layout_test helper, so only
the MDT can refuse the changes.
