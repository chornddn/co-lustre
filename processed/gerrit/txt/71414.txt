--- Commit Message ---
LU-18317 libcfs: parse IPv6 o2ib NIDs in userspace

The kernel nidstrings.c learned to parse IPv6@o2ib NIDs, but the
O2IBLND entry in the userspace copy, lib/libcfs/nidstrings.c, still
has no nf_str2addr_size/nf_addr2str_size handlers.  libcfs_strnid()
then falls back to the IPv4-only parser, so lnetctl rejects any
IPv6 o2ib NID:

  # lnetctl ping fd00:122::169@o2ib
  descr: "Unable to parse nidlist: invalid NID in nidstr"

Add the IP size handlers to the userspace O2IBLND entry, matching
SOCKLND and the kernel table.
