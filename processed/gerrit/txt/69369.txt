LU-20076 tests: check facets are up with one lctl dl per node

facet_up() runs "lctl dl" on the facet's node each time it is called.
facets_up_on_host(), used by affected_facets() for every failover
with FAILURE_MODE=HARD, calls it once for each facet on the same
node.  set_mdt_qtype() and set_ost_qtype(), used by sanity-quota
setup, call it once for every MDT or OST, which on a large config is
one remote command per target each time.

Add facets_up() to run "lctl dl" once on each node of a facet list
and check every facet's label in its output, and use it in these
three places.

Remote "lctl dl" commands with 2 MDTs and 2 OSTs on one node:

                         before  after
  set_ost_qtype u           2      1
  set_mdt_qtype u           2      1
  facets_up_on_host         4      1

With N targets on one server node, the remote "lctl dl" commands go
from N to 1.
