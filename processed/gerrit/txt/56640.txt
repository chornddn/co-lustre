LU-18166 pcc: add option --rmdir to cleanup FID directories

"lctl pcc clear|del" removed the PCC copies from the PCC backend,
but left their FID hash directories behind, empty.

Add the option --rmdir to "lctl pcc clear|del" to remove the empty
directories in the PCC backend after the scan, in reverse scan order
so that each directory is removed after its subdirectories.  The top
directory of the PCC backend, which is the configured backend path,
and its "shadow" and "lost+found" directories are kept.

"lctl pcc clear|del" also removes the PCC backend from the client.
Add the option --keep-conf to only clean up the PCC cache and keep
the PCC backend configured, so that "--keep-conf --keep-data --rmdir"
only removes the empty directories.  Reject --keep-conf --keep-data
without --abort or --rmdir, which would do nothing.

Add sanity-pcc/test_111 to verify both options, with the posix_v2
and the nested posix_v1 directory layouts.
