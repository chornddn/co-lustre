LU-20981 libcfs: honour CPT exclusions in io tables

With a single CPT on a multi-NUMA host, ost_io and mdt_io build a
per-node CPT table with cfs_cpt_set_node(), which adds every core of
the node. Cores left out by cpu_pattern, whether by a single-CPT
inclusion such as 0[0-6] or an X[...]/C[...] exclusion, are added
back, so the io threads still run on them.

Add cfs_cpt_table_alloc_by_node(): one partition per NUMA node of
the source table, holding only the CPUs that table contains. Use it
in ofd_oss.c and mdt_mds.c.

Add conf-sanity 200f to exclude one CPU and check that no
ll_ost_io/mdt_io thread may run on it. load_lnet() now keeps the
caller's MODOPTS_LIBCFS so remote servers receive it, and
cleanup_200 always restores it.
