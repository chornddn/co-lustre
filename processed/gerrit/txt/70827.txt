--- Commit Message ---
LU-21191 tests: wait for admin sync in fops_test_setup

fops_test_setup() sets c0 admin and trusted to 1 so the test
directory can be created as root, then restores both, but only
waits for trusted_nodemap to sync. In sanity-sec test_21 trusted
is already 1, so that wait passes before the admin change reaches
the other MDS, and creating the directory on a remote MDT fails
with EPERM because root is still squashed there. The test then
fails with "cannot chmod mapped_trusted_noadmin".

Also wait for admin_nodemap whenever admin is not already 1.

Test-Parameters: trivial testlist=sanity-sec env=ONLY="16 17 18 19 20 21 22",ONLY_REPEAT=4 mdscount=2 mdtcount=4
