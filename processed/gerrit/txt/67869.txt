--- Commit Message ---
LU-20507 tests: don't require IPv6 on the fake interface

setup_fakeif() adds an IPv6 address to the fake interface and
treats a missing address as a fatal error. A node that sets
net.ipv6.conf.default.disable_ipv6 gives every new device
disable_ipv6=1, so the add fails and each test that calls
setup_fakeif() in the default namespace fails with
"Failed setup test1pg". The namespace callers still pass,
because a new namespace starts from the kernel defaults.

The suite already adapts to a node without IPv6: it selects
"IPv4 mode" and the tests that need IPv6 skip. Record that in
HAVE_IPV6 and let setup_fakeif() follow it.

Test-Parameters: trivial
