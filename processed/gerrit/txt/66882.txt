LU-20211 mdt: trunc(0) with layout swap on degraded stripes

When truncate(0) hits a supported file with stripes on inactive
or degraded OSTs, move the old layout onto a volatile victim and
recreate a fresh layout on the file from currently active OSTs.

Extend the layout API with MD_LAYOUT_UNAVAILABLE (detect stripes on
inactive/degraded OSTs) and MD_LAYOUT_INSTANTIATE (allocate a fresh
layout from a source pattern).  Teach lod_generate_lovea() to emit
uninstantiated LOVEA templates for instantiation, and trigger layout
replacement from mdt_reint_setattr() when size is truncated to zero.

mdt_orphan_open() reused stale mti_spec and triggered an undeclared
job xattr set LBUG in sanity/27xt. Reset mti_spec for internal orphan
creates and declare job xattr credits in mdd_declare_create_object.

Add sanity/test_27xt.
